AquaRush 配送版 v1.0.0

页面说明

所属端：送水工端 App（delivery-app，Expo React Native，暗色）

入口：未登录由路由守卫（Stack.Protected）渲染本页；冷启动校验本地会话失败时回退。

跳转：登录成功按角色分流——送水工（DELIVERY_WORKER）→ 任务首页；管理员（ADMIN/SUPER_ADMIN）→ 经营看板 / 工作台首页。

布局结构

  1. 品牌区：logo（渐变底字母标记）+ 端名「AquaRush」+ 副标题「送水配送·运营管理」
  2. 欢迎语：「欢迎使用 AquaRush 配送与运营平台」
  3. 错误提示区（仅错误时显示）：红色 tint 胶囊「登录失败，请检查用户名和密码」
  4. 输入区：用户名 + 密码（暗色输入框）
  5. 记住账号开关（默认开启）
  6. 主按钮「登录」（提交中「登录中...」）
  7. 用户协议 / 隐私政策链接；底部版本号

关键交互

  1. 启动读取本地会话（token + userInfo），有效则保持登录态（useAuth isHydrating），不闪现本页。
  2. 输入账号密码 → POST /api/auth/login（与后台同源）→ 存 token + userInfo → 按角色 replace 分流。
  3. 401 / 会话失效 → 清本地凭证并回登录页（R-AUTH-03）。
  4. 「记住账号」仅本地记住用户名，不缓存密码。

状态与规则

加载态：按钮「登录中...」+ loading 禁用；禁用态：提交中按钮禁用，防重复提交。

错误态：统一文案「登录失败，请检查用户名和密码」；字段级区分「账号不存在」「密码错误」（PRD 未细分，按语境拟定，字段级提示不改变统一主文案）。

空态：用户名 / 密码为空时提示「请输入用户名和密码」。

登录方式为账号密码（非微信登录）；送水工账号由管理员创建，无自助注册入口；未登录不可进入任务页。

设计要点 / 禁忌

送水工端完全不出现强调橙：主操作「登录」用品牌蓝（暗色态 --brand/--d-primary）；错误提示用 error 色，不用橙色。

暗色下输入框与文字对比度 ≥ 4.5:1；触达目标 ≥ 44px（夜间 / 手套操作）。

禁止设计授权弹窗页；禁止在登录页出现商品、优惠等消费者端元素。
