页面说明

所属端：送水工端 App（Expo React Native，暗色）

入口：「我的」页 / 任务页消息入口 + 未读角标。

跳转：点击消息 → 标已读 → 跳转任务详情 / 订单详情。

布局结构

  1. 导航栏：返回 + 标题「消息中心」+ 右侧「全部已读」
  2. 类型 Tab：全部 / 任务 / 系统（各带未读角标）
  3. 消息列表：类型图标 + 标题 + 摘要（2 行省略）+ 相对时间 + 未读红点
  4. 弱网降级说明条（轮询 30s + 离线补发）
  5. 实时推送横幅（WebSocket 新任务广播，前台浮层）

关键交互

  1. 进入消息中心 → 分页拉取本人消息（仅本人，R-AUTH-02）+ 下拉刷新。
  2. 点击消息 → 标已读 → 跳转关联详情。
  3. 「全部已读」→ 批量置已读 → 角标清零。
  4. WebSocket 长连接（/ws/notifications）推送即时触达，点击横幅跳转抢单。

状态与规则

类型：任务 / 系统；已读 / 未读（未读高亮 + 红点）；空态：「暂无消息」。

弱网降级（R-NTF-03）：定时轮询（默认 30s）+ 离线补发；推送与轮询按幂等键 = 订单号 + 事件类型 + 事件时间去重，不重复渲染（R-NTF-02）。

推送场景：新订单广播 / 被派单 / 订单取消 / 用户催单 / 配送超时 / 支付超时；锁屏 / 后台系统推送为目标形态（依赖推送凭证）。

设计要点 / 禁忌

未读高亮与角标实时联动；与实时推送同源（推送即时触达、消息中心可回溯）。

送水工端完全不出现强调橙：类型标签用 .tag-assign 蓝系，未读点用 error 色；横幅动作文字走 --d-primary-dark。

新订单广播需醒目但不得重复渲染；离线不丢消息；仅本人可见。
