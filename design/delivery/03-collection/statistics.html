页面说明

所属端：送水工端 App（Expo React Native，暗色）

入口：底部 TabBar「日报」/ 工作台统计区。

跳转：订单明细列表入口 → 历史订单（对应时间 Tab）；统计卡点击 → 历史订单对应 Tab。

布局结构

  1. 导航栏：标题「数据统计」+ 消息入口（未读红点）
  2. 时间范围切换（分段控件：今日 / 本周 / 本月）
  3. 统计卡（2×2）：完成订单数 / 收款金额 / 桶数 / 平均单值
  4. 柱状图（.bars）：每日订单量（近 7 天）
  5. 收款方式占比（.hbar）：现金 / 扫码 / 水票
  6. 订单明细列表入口
  7. 底部 TabBar：工作台 / 任务 / 日报 / 我的（选中「日报」）

关键交互

  1. 切换时间范围（今日 / 本周 / 本月）→ 重新取数渲染统计卡与图表。
  2. 点击统计卡 / 订单明细入口 → 跳转历史订单对应 Tab。
  3. 聚焦 / 下拉刷新重取数据；30 秒轮询刷新。

状态与规则

空态：无数据时各卡为 0、图为空；加载态：数据加载中；错误态：加载失败提示。

营收口径 = 当日已完成订单收款汇总（现金 + 扫码，水票以张数计）；与日报 / 对账三者一致（R-ORD-11）；金额分转元两位小数。

本周 / 本月按 completed_at 归属统计，跨周期订单以完成时间为准。

设计要点 / 禁忌

数值与图表统一走品牌蓝（--d-primary / --brand 梯度）；禁用强调橙，涨跌同色系不引入橙。

柱状图与横向占比条高度 / 宽度按真实占比等比例；数值用等宽字体。

图表容器在暗色下轨道底改用 --d-card-2，保证可见性；信息密度优先，触达 ≥ 44px。
