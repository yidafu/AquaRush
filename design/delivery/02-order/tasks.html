页面说明

所属端：送水工端 App（Expo React Native，亮/暗双模式，本页为亮色默认态）

入口：底部 TabBar「任务」

跳转：点击任务卡 → 订单详情与完成配送；「抢单」→ 就地状态流转

布局结构

  1. 导航栏：标题「任务」+ 在线/离线接单开关 + 消息入口（未读红点）
  2. 分段控件：未接单 / 已接单 / 配送中（各带数量角标）
  3. 任务卡片列表：订单号 + 状态标签 + 收货地址（含楼层）+ 商品摘要 + 距离/时间 + 操作按钮
  4. 加载更多区：「没有更多任务了」
  5. 实时推送横幅（新订单可抢单广播）
  6. 底部 TabBar：工作台 / 任务 / 日报 / 我的

任务卡片规格

订单号（等宽字体）+ 状态标签 + 地址（楼层必须醒目，影响配送费分档）+ 商品摘要 + 距您距离 + 下单时间。

操作按钮：待派单 → 「抢单」；待配送 → 「开始配送」；配送中 → 「查看 / 完成配送」。

催单订单（用户催单）以 warning 色文案加粗提醒，卡片描边高亮。

关键交互

  1. 进入 / 下拉刷新拉取任务
  2. WebSocket 长连接（/ws/notifications）实时刷新：新订单可抢单广播、被派单、订单取消、催单、配送超时、支付超时
  3. 抢单成功 → 任务移入「已接单」（待派单 → 待配送，与派单口径统一）
  4. 开始配送 → 待配送 → 配送中

状态与降级

空态：「暂无任务」；加载态：「加载中」。

弱网降级（R-NTF-03）：定时轮询（默认 30s）+ 离线补发；推送与轮询按幂等键去重，

幂等键 = 订单号 + 事件类型 + 事件时间，不得重复渲染（R-NTF-02）。

设计要点 / 禁忌

配送端完全不出现强调橙：主操作走品牌蓝（品牌蓝 --brand），「抢单」用品牌蓝而非橙。

信息密度优先：触达目标 ≥ 48px（夜间/手套操作）；亮色下文字对比度 ≥ 4.5:1。

新订单广播需醒目但不得重复渲染；离线不丢消息。
