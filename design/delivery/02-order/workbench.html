页面说明

所属端：送水工端 App（Expo React Native，亮色默认态）

入口：底部 TabBar「工作台」（原独立「统计」Tab 已移除，能力收敛至此）。

跳转：去接单 → 任务列表；代客下单 → create-order；提交日报 → 每日收款；历史订单 → history；统计卡点击 → 历史订单对应 Tab。

布局结构

  1. 导航栏：标题「工作台」+ 消息入口（未读红点）
  2. 问候卡：问候语 + 在线 / 离线接单开关
  3. 今日统计卡（2×2）：完成订单数 / 收款金额 / 待接单数 / 配送中数
  4. 快捷入口（四宫格）：去接单 / 代客下单 / 提交日报 / 历史订单
  5. 今日待办提醒：超时预警（error 色）/ 催单提醒（warning 色）
  6. 底部 TabBar：工作台 / 任务 / 日报 / 我的（选中「工作台」）

关键交互

  1. 进入工作台 getWorkbenchData 加载今日统计并渲染（单请求取回）。
  2. 在线 / 离线开关：离线后不再接收新订单推送，WebSocket 消息转通知栏；上线后补发。
  3. 点击统计卡 / 快捷入口跳转对应页面。
  4. 聚焦 / 下拉刷新重取数据；30 秒轮询刷新（弱网降级）。

状态与规则

营收口径：今日收款 = 当日已完成订单收款汇总（现金 + 扫码，水票以张数计），与日报 / 对账三者一致（R-ORD-11）。

空态：无数据各卡为 0；加载态：数据加载中；错误态：加载失败提示。

超时预警 = 超预计送达时间；催单提醒 = 用户发起催单事件（ORDER_URGING）。

设计要点 / 禁忌

主操作与关键数值统一走品牌蓝（--brand / --brand-dark）；禁用强调橙，预警用 warning 语义色、异常用 error 语义色。

金额一律「¥xx.xx」（分转元、两位小数），数字用等宽字体；信息密度优先，触达目标 ≥ 44px。

数字口径不可与日报 / 对账打架；离线状态须显式告知，不得静默丢单。
