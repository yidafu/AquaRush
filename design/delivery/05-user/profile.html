页面说明

所属端：送水工端 App（delivery-app，Expo React Native，暗色，tabBar 页）

入口：底部 TabBar「我的」；未登录由 PageContainer 重定向登录页。

跳转：历史订单 / 对账记录 / 每日收款 / 消息中心；关于我们 / 用户协议 / 隐私政策；退出登录 → 清本地登录态并重定向。

布局结构

  1. 导航栏：标题「我的」+ 消息入口（未读红点）
  2. 用户信息区：头像（首字母）+ 姓名 + 在线状态 + 工号
  3. 业绩卡：今日 / 本月两组（完成单数 / 收款额 / 好评率）
  4. 功能列表：历史订单 / 对账记录 / 每日收款 / 消息中心（未读红点）/ 收款方式偏好 / 修改密码
  5. 关于组：关于我们 / 用户协议 / 隐私政策
  6. 退出登录按钮 + 版本号「AquaRush 配送版 v1.0.0」
  7. 底部 TabBar：工作台 / 任务 / 日报 / 我的（选中「我的」）

关键交互

  1. 菜单项跳转对应页面；「收款方式偏好」展示当前默认收款方式（现金 / 水票 / 扫码）。
  2. 「消息中心」入口带未读角标，与 F-NTF-004 联动。
  3. 退出登录：弹窗确认「确定要退出登录吗?」→ deliveryAuthService.logout 清除本地登录态并重定向。

状态与规则

空态：workerInfo 为空时不渲染内容，由 PageContainer 重定向登录页；业绩口径：完成单数 / 收款额按 completed_at 归属，与日报 / 对账一致（R-ORD-11）。

好评率 = 平均评分折算；「在线状态」为静态字段（目标接入实时同步）。

去重约束：工作台已含的业务入口（每日收款 / 对账记录 / 历史订单 / 消息中心）在本页按评审需求保留，正式实现以工作台九宫格为唯一入口（2026 去重调整）——本稿依任务清单呈现全部入口。

设计要点 / 禁忌

送水工端完全不出现强调橙：主操作与选中态走品牌蓝（--d-primary）；退出登录为危险动作，用 error 色。

评分（切片要求）现状仅姓名 / 手机号，本页展示好评率并标注口径；头像无图时用首字母占位。

功能列表项触达 ≥ 44px；暗色下正文对比度 ≥ 4.5:1。
