页面说明

所属端：管理后台（目标形态）

入口：左侧菜单「用户管理 → 企业客户」

跳转：企业客户详情（基本信息 + 地址 + 月结账单 + 开票记录）

交叉：07-user.md §F-USR-022（客户管理）

布局结构

  1. 企业客户列表：企业名称 / 联系人 / 账期 / 信用额度 / 已用额度 / 开票状态 / 状态；操作 新建 · 编辑 · 额度调整 · 账单查看
  2. 企业客户详情：基本信息 + 绑定收货地址 + 月结账单 + 开票记录
  3. 新建 / 编辑弹窗：企业名称 / 税号 / 开票抬头 / 账期 / 信用额度

关键交互

  1. 建企业客户 → 设置账期（如月结 30 天）与信用额度 → 绑定收货地址
  2. 账期到期 → 后台生成账单（按客户 + 账期聚合已完成订单金额）→ 收款核销 → 更新额度
  3. 开票 → 按账单 / 订单生成发票记录 → 开票状态流转，退款触发红冲

状态与规则

空态：「暂无企业客户」；加载态：列表 / 保存 loading；错误态：保存 / 提交失败 message；禁用态：超出信用额度时下单拦截。

开票状态：未开票 / 已开票 / 已红冲。

约束：企业名称 / 税号必填；账期 ≥ 0 天、信用额度 ≥ 0。

设计要点 / 禁忌

本页为 ，缺口 G83。

管理端不出现强调橙：主操作用品牌蓝；已红冲 / 已超额度用语义 error 色，未开票 / 额度紧张用 warning 色。

企业客户身份由后台标记（非自助注册）；月结为资金类业务须评估风控与合规；金额一律 ¥0.00。

开放问题：账期上限与信用额度风控、坏账预警、账期逾期是否限制下单、拆单规则、开票粒度与退款红冲。
