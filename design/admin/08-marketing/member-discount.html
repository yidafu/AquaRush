页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 会员折扣；或客户分组详情（F-MKT-001）

跳转：配置保存后自动应用；正式并入 F-MKT-011 会员等级与权益

组件：Table、Form、InputNumber、Switch

布局结构

  1. 分组 / 等级列表：分组名 / 折扣率 / 生效范围 / 启用状态 / 操作（配置 / 停用）
  2. 配置弹窗：折扣率、生效范围、启用开关
  3. 折扣叠加边界说明（与分组价 / 特价 / 新人价按商品维度互斥）
  4. 效果预览：某商品折后价试算卡

关键交互

  1. 选分组 / 等级 → 配折扣率 → 保存 → 自动应用
  2. 停用 → 该分组不再享受会员折扣
  3. 折扣率超出范围时表单即时拦截

状态与规则

空态：无分组 / 等级时引导先建；停用态：停用后不再应用。

校验：「折扣率超出范围」（1%–99%）。

计价规则：会员折扣仅按未命中单价让利（分组价 / 特价 / 新人价）的商品小计生效，商品维度互斥；展示「会员折扣 -¥10.00」。

设计要点 / 禁忌

本页为规划中占位，正式形态并入 F-MKT-011 会员等级与权益（缺口 G80，含 G57 收敛）；画布内已用 tag-goal 标注目标区块。

管理端不出现强调橙：折扣率用品牌蓝强调，主操作用品牌蓝。

金额分存储（R-MON-01）、百分比两位小数；试算口径须与下单计价链一致。
