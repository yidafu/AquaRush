页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 积分

跳转：用户端积分中心；确认订单「积分抵扣」区

组件：Table、Form、InputNumber、DatePicker

布局结构

  1. 获取规则区：下单每 ¥1.00 得 N 分 / 评价得 N 分 / 签到得 N 分 / 邀请好友得 N 分（各带开关与数值）
  2. 有效期设置：按获取批次 / 滚动过期 + 过期提醒天数
  3. 兑换品配置：券 / 水票 / 配件 / 实物
  4. 抵扣比例与上限：如 100 积分 = 1 元，单笔抵扣 ≤ 应付 x%
  5. 积分明细查询入口 + 预算与发放统计

关键交互

  1. 配置 → 保存生效
  2. 订单完成计积分、退款扣回；兑换幂等
  3. 兑换 / 抵扣校验「积分不足以抵扣」「请勿重复兑换」

状态与规则

规则启用 / 停用；兑换记录唯一约束。

校验：「积分不足以抵扣」「请勿重复兑换」；文案「积分规则」「100 积分 = 1 元」。

口径：积分获取以已完成订单实付金额计；退款按比例扣回、赠出积分作废；积分不可提现 / 转让；过期提前提醒。

设计要点 / 禁忌

本页为规划中（缺口 G81）：获取 / 有效期 / 消耗 / 抵扣四区同屏可评审。

叠加顺序（积分抵扣与券 / 满减 / 会员折扣）为开放问题，需在规则区明示。

管理端不出现强调橙：获取 / 消耗标签用品牌蓝与中性色；金额分存储（R-MON-01）、百分比两位小数。
