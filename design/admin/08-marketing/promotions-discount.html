页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 满减 / 折扣

跳转：行「详情」→ 营销活动详情页（F-MKT-003/004/005/008/009 共用）

组件：Table、Modal、Form、InputNumber、Select、DatePicker、Switch

布局结构

  1. 顶部：「新建活动」按钮
  2. 活动列表：活动名 / 类型 / 档位 / 适用范围 / 时间窗 / 状态 / 参与订单数 / 操作
  3. 新建 / 编辑弹窗：活动名称、类型、多档位阶梯、适用范围、时间窗、启用
  4. 档位阶梯编辑器：可增删多行，行内删除 + 「增加档位」

关键交互

  1. 配置活动 → 保存上架 → 下单自动减免（无需领券）
  2. 修改档位 / 时间窗 → 新订单生效，已生成订单不受影响
  3. 停用 → 立即失效
  4. 用户端确认订单展示「活动已减 ¥x」行（order-confirm）

状态与规则

活动态：未开始 .tag-assign / 进行中 .tag-deliver / 已结束 .tag-done / 已停用 .tag-neutral，时间窗过期自动失效在列表状态体现。

校验：「档位金额需递增」「时间窗不合法」；文案「满 100 减 10」「活动已减 ¥x」。

规则：同一订单命中多活动取优惠最大者，不叠加；档位金额单位为分存储（R-MON-01）。

设计要点 / 禁忌

多档阶梯需可增删且实时校验递增互斥；档位「满 / 减」两列对齐，便于评审读数。

管理端不出现强调橙：主操作「保存并上架」用品牌蓝，删除档位用 ghost 中性按钮。

缺口 G55 已解决：满减 / 折扣已闭环，且与首单立减取最大的互斥规则在弹窗内明示。
