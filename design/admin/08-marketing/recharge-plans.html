页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 储值与套餐

跳转：套餐票种复用 water-tickets 形态；用户端充值页 / 我的资产；流水按日查询、日终对账

组件：Table、Form、InputNumber、DatePicker、Statistic、Tabs

布局结构

  1. Tabs：储值档位 / 套餐票种 / 流水查询
  2. 储值档位列表：档位金额 / 赠送金额或比例 / 启用 / 操作
  3. 套餐票种列表：套餐名（水卡 / 次卡 / 月卡）/ 面值 / 售价 / 赠送金额或次数 / 有效期 / 适用范围 / 状态
  4. 流水查询：充值 / 消费 / 退款流水表（用户 / 类型 / 金额 / 时间 / 渠道流水号 / 状态 / 对账状态）
  5. 资金类风控区 + 预付卡合规区

关键交互

  1. 配置档位 / 票种 → 保存上架 → 用户端充值页 / 套餐商城可见
  2. 充值回调按幂等键入账（本金 / 赠送分别入账）
  3. 流水按日 / 条件查询；日终对账生成差异报告
  4. 消费优先扣赠送、再扣本金（组合支付）

状态与规则

档位 / 票种：启用 .tag-ok / 停用 .tag-neutral；流水状态：成功 .tag-deliver / 失败 .tag-cancel / 挂起 .tag-warn；合规提示常驻。

校验：「充值档位必选」「未消费余额可退，已消费不可退」；单卡限额 ≤ ¥1,000.00、有效期 ≤ 365 天。

资金底线：幂等 + 对账 + 资损监控三件套不可砍；赠送余额分账且不可退。

设计要点 / 禁忌

本页为规划中（缺口 G79）；资金类页面必须标注「幂等 + 对账 + 资损监控三件套不可砍」与预付卡合规（有效期 / 退卡规则 / 限额 / 存管，赠送余额分账不可退）。

本金余额与赠送余额须分开展示；管理端不出现强调橙，主操作用品牌蓝，告警阈值用语义 warn / err 色。

金额分存储（R-MON-01）、展示两位小数；百分比两位小数。
