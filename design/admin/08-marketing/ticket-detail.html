页面说明

所属端：管理后台（React + Ant Design 5）

入口：桶水票列表行「详情」（/marketing/water-tickets/:id）

跳转：返回列表；核销订单可跳订单详情

组件：Statistic、recharts（折线 / 柱状图）、DatePicker.RangePicker

布局结构

  1. 顶部：返回入口 + 时间范围选择（默认近 30 天）
  2. 区间汇总卡：销售张数 / 销售金额 / 核销 / 退回 / 过期 / 当前可用
  3. 销售趋势图：入账张数 + 销售金额
  4. 使用情况图：核销 / 退回 / 过期
  5. 票列表：票号（等宽）/ 购买人 / 购买时间 / 状态 / 核销时间 / 核销订单 / 操作 + 筛选与导出

关键交互

  1. 切换时间范围 → 图表与汇总刷新
  2. 当前可用 = 未用 + 未过期退回
  3. 票号筛选精确匹配；导出按筛选生成文件

状态与规则

票状态：未使用 .tag-ok / 已使用 .tag-deliver / 已退票 .tag-cancel / 已过期 .tag-neutral。

空态：「暂无使用记录」；加载态：图表与表格 loading。

口径：图表与汇总卡口径一致；金额单位标注清晰（分存储、展示两位小数）。

设计要点 / 禁忌

票号用等宽字体（--font-num）便于线下核验与对账；汇总卡数字为视觉焦点。

管理端不出现强调橙：图表用品牌蓝 / 浅蓝渐变。

汇总卡金额以元展示（分转元）；不同状态口径需在卡片 delta 处标注来源。
