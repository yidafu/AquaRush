页面说明

所属端：管理后台（React + Ant Design 5）

入口：运营配置 → 运费规则；路由 operations/delivery-fee

下游：订单域消费（R-MON-02，F-ORD-001/020）；用户端确认订单页费用明细

状态：已实现 2026-08

布局结构

  1. 免费楼层配置：免费楼层（默认 4）+ 楼层为空免运费说明
  2. 楼层分档加价表：可增删档位，每档含起始楼层 / 结束楼层（可空 = 以上）/ 加价金额（元）
  3. 自提订单免运费开关
  4. 下单时快照落库说明（R-MON-02）+ 修改记录
  5. 费用试算器（输入楼层 → 实时试算）+ 边界用例速查；保存二次确认

关键交互

  1. 进入页面 → 回显当前规则（未配置时回显默认 免费 4 楼 + 默认分档）
  2. 修改（调整免费楼层 / 增删档位 / 改加价）→ 二次确认 → 保存 → 新订单按新规则计算
  3. 试算器输入楼层 → 实时试算配送费（平房 / 自提 / 各档位边界）
  4. 用户端确认订单页按所选地址楼层 + 规则展示运费 /「免配送费」（R-MON-02）

状态与规则

免运费场景：免费楼层及以下免运费；楼层为空（平房 / 无楼层信息）免运费；自提免运费；未配置回显默认并提示。

关键数据字段：免费楼层、分档（起始楼层 / 结束楼层 / 加价金额分）、审计记录。

校验：「运费金额无效」「档位区间重叠」；分档须按楼层升序、区间不重叠、各档加价 0-999 元 ≤ 2 位小数。

设计要点 / 禁忌

管理端不出现强调橙：金额用品牌蓝 / 语义色，主操作用品牌蓝，删除档位用语义 error 色。

保存二次确认须说明对已生成订单无影响：「确定保存新的配送费规则吗？修改将影响新订单，已生成订单不受影响」。

由单档改分档（解决 7 楼与 27 楼同价）；金额一律分存储、展示层转元（¥0.00 形式）。

缺口 G62：规则口径由订单域 R-MON-02 定义，本域仅提供配置能力；距离计费为开放问题。
