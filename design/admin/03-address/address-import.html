页面说明

所属端：管理后台（React + Ant Design 5）

入口：地址管理页「导入 Excel」打开的弹窗

跳转：弹窗内「下载模板」触发模板下载；确认导入后关闭并刷新地址列表

权限：PERMISSION_ADDRESS_WRITE

布局结构

  1. 文件选择区：上传控件（.xlsx / .xls）+「下载模板」按钮
  2. 解析提示区：解析中 / 表头缺失 / 行不完整 / 文件为空
  3. 校验预览表：行号 / 收货人 / 地址 / 校验结果 / 失败原因
  4. 导入按钮：带条数「导入 (N 条)」，无数据时 disabled
  5. 底部说明区：表头要求 + user_id 为 null 提示
  6. 第二状态：导入结果反馈 + 失败明细 + 导入留痕记录

关键交互

  1. 选择文件 → 解析 Excel → 表头校验（缺列 Alert「缺少必要的表头字段: …」）
  2. 行完整性校验（空行 Alert「有 N 行数据不完整，请检查」）
  3. 校验通过 / 失败逐行标注，失败行不导入
  4. 点「导入」→ 提交并返回成功 / 失败条数与失败明细
  5. 「下载模板」生成标准模板「地址导入模板.xlsx」；失败明细可单独下载

状态与规则

空态：Alert「Excel 文件为空」；加载态：Alert「正在解析 Excel 文件...」；错误态：「解析 Excel 文件失败，请确保文件格式正确」「加载 Excel 解析库失败」。

禁用态：无解析数据时导入按钮 disabled。

结果字段：successCount / failureCount / totalCount。

校验失败必须给出可定位原因（列名 / 行号）。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，失败语义用 error 色。

失败行下载（本页已画目标形态）与重复导入去重（接后端 isDuplicateAddress）为缺口候选；缺手机号格式 / 区域存在性校验。

导入字段不含经纬度（与 F-ADR-022 缺坐标联动）；导入地址 user_id 为 null。

台账须留痕（时间 / 操作人 / 文件 / 成功失败数），失败明细可回查。
