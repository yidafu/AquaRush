页面说明

所属端：管理后台（React + Ant Design 5）

入口：商品列表「新增商品」弹窗；详情页 /products/:id 顶栏「编辑商品」进入编辑态

跳转：顶栏「返回列表」「编辑商品」/「保存」「取消」

权限：PERMISSION_PRODUCT_READ / PERMISSION_PRODUCT_WRITE

布局结构

  1. 列表页新增/编辑弹窗（ProductForm，宽 800）：Collapse/Tabs 分组「基础信息 / 价格信息 / 库存与销售 / 商品详情 / 媒体资源 / 设置」
  2. 详情页左右分栏：左 ProductEditor（查看/编辑切换），右「小程序预览」Card
  3. 弹窗底部「取消 / 创建」（编辑态为「更新」）

关键交互

  1. 新增：填表单 → 校验 → 价格类字段元×100 转分提交 → message「创建成功」→ 刷新列表
  2. 编辑：回填数据（分→元）→ 修改 → 保存转分提交 → message「更新成功」→ 详情页 refetch
  3. 编辑态「取消」且有未保存修改 → 二次确认「确认取消编辑?」
  4. 编辑过程中右侧小程序预览随表单实时更新
  5. 图片上传返回 URL 数组，图集/证书序列化为 JSON 提交

状态与规则

校验文案：「请输入商品名称」「商品名称长度应在2-200个字符之间」「请选择商品规格」「价格应在0.01-99999元之间」「库存数量应在0-99999之间」「请上传封面图片」「标签格式错误，请输入有效的JSON格式」。

加载态：「保存中...」/「加载商品详情...」；错误态：「加载失败」+「返回列表」「重新加载」；禁用态：销量只读、图片上传中禁用提交。

状态下拉三选：在线销售 / 下架 / 缺货（F-PRO-008）；下架后用户端 activeProducts 查询即不再返回。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝、危险操作用语义 error 色。

商品表单不含押金字段（押金按桶规格由「押金管理」独立维护），不再维护商品级配送设置（配送费统一由运营配置 F-OPS-005）。

价格以元录入、×100 转分存储，服务端须校验金额=单价×数量防篡改（R-MON-01）；图集 ≤ 10、证书 ≤ 5。

缺口 G16：dev 环境商品 CRUD 走 mock，开发态看不到真实后端数据。
