页面说明

所属端：管理后台（React + Ant Design 5）

入口：系统设置 → 通知与订阅消息；路由 system-config/notifications；仅超级管理员（NOTIFICATION_WRITE）

权威定义：通知与消息域 13-notification.md §F-NTF-005；本域为系统设置入口与密钥保护（R-SYS-02）

状态：部分实现

布局结构

  1. 订阅消息模板表：模板名（业务场景）/ 模板 ID / 启用 / 保留时长 / 说明 / 操作「编辑」
  2. 用户通知设置预览：用户端订阅设置说明（user_notification_settings）
  3. 站内消息保留期（目标形态）
  4. RN 推送凭证配置（目标形态，掩码展示）
  5. 编辑弹窗：模板 ID + 启用开关 + 参数映射说明

关键交互

  1. 进入页面 → 回显模板配置
  2. 编辑模板 ID / 启用 → 保存 → 列表状态更新
  3. 发送链路接通后（G08）按模板发送订阅消息
  4. RN 凭证不可在线编辑，仅可查看配置状态

状态与规则

空态：无模板空态；加载态：列表 / 保存 loading；错误态：保存失败 toast；禁用态：无权限只读。

状态标签：启用 / 停用 / 未设置。

校验：「模板 ID 不能为空」「模板 ID 格式不正确」；模板 ID 非空且符合微信模板 ID 规则（6-64 位）。

设计要点 / 禁忌

管理端不出现强调橙：密钥 / 凭证类用 warning 提示保护，主操作用品牌蓝。

仅配置非敏感模板参数；小程序 appid/secret 等密钥类不提供在线配置（R-SYS-02），前端展示掩码。

发送链路（G08）未接通前，配置保存成功但实际不发送，需在页面说明。

缺口 G64、G08、G69（RN 推送凭证）。目标形态：保留时长（数据维护）与 RN 推送凭证配置。现状：模板 ID / 启用配置前后端已落地（2026-08）。
