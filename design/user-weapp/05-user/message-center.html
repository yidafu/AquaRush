组件与度量

组件体系：微信官方 WeUI 2.x；筛选用官方 .weui-tabs（选中短下划线），消息列表用官方 .weui-cells + .weui-media-box，未读用 .weui-badge_dot。

本页组件：.mp-nav（含 .mp-nav__right「全部已读」）+ .weui-tabs / .weui-tabs__item.on / .cnt + .weui-media-box / __hd / __title / __desc--2 + .weui-cell__icon--brand + .weui-badge_dot + .weui-loadmore + .weui-empty。

度量：导航栏 44px、胶囊 87×32；Tab 高 43px、选中下划线 20×3；图文项左缩 16px、主文字 17px、摘要 14px、时间 12px；未读圆点 8px。

配色：类型图标统一品牌蓝；未读圆点为语义红 var(--weui-RED)；本页无金额、无强调橙。

页面说明

所属端：用户端小程序

入口：「我的」页「消息中心」入口 + 未读角标

跳转：点击消息 → 标已读 → 跳订单详情 order-detail / 公告详情 notice-detail / 反馈记录 feedback-records

数据：消息类型、标题、摘要、时间、已读状态、关联单号 / 页面

布局结构

  1. 导航栏：返回 + 「消息」+ 右上「全部已读」（.mp-nav__right）
  2. 第一行 Tab（类型）：全部 / 订单 / 系统 / 优惠
  3. 第二行 Tab（已读状态）：全部 / 未读 .cnt / 已读（两维度组合过滤）
  4. 消息列表：类型图标 + 标题 17px + 摘要（.weui-media-box__desc--2 两行省略）+ 时间 12px 灰 + 未读红点
  5. 加载更多（.weui-loadmore）+ 下拉刷新

状态与规则

空态：「暂无消息」+「订单与系统通知会在这里展示」（状态二）；加载态：加载更多 / 下拉刷新；错误态：「加载失败，请重试」；类型：全部 / 订单 / 系统 / 优惠（来源含优惠券即将过期 COUPON_EXPIRING）。

未读 / 已读视觉区分：未读 = 标题加粗（.bold）+ 右侧 .weui-badge_dot 红点；已读 = 标题常规字重 + 无圆点；未读高亮与入口角标实时联动（WebSocket 推送与轮询按幂等键去重）；仅本人可见（R-AUTH-02）。

设计要点 / 禁忌

Web 风旧组件（标签芯片组 / 列表 / 列表项 / 列表图标 / 标签 / 空态等旧类名）一律禁用，全部以 WeUI 等价类实现；本页无主 CTA，不出现强调橙。

双行 Tab 组合筛选需清晰（类型行与已读状态行视觉可区分）；摘要固定 2 行省略（.weui-media-box__desc--2），触达行高 ≥ 44px；未读圆点用语义红，图标统一品牌蓝。

缺口 G66 已解决（2026-08）；左右滑操作与「删除消息」为目标形态（底部 .weui-actionsheet 承载）；F-NTF-007 目标新增「提醒」分类（补水 / 周期 / 余量；无余额提醒——用户储值不做，2026-10-09 决策）。
