组件与度量

组件体系：微信官方 WeUI 2.x；渐变头部（.phone-screen.is-brand + .hero）、资产条用小程序数据格 .mp-statgrid、订单入口用官方 .weui-grids、服务列表用官方 .weui-cells。

本页组件：.mp-status / .mp-nav.is-brand / .mp-capsule + .weui-tag（会员等级）+ .mp-statgrid__item / __num / __lbl + .weui-cells__title + .weui-panel / .weui-grids（5 列，.weui-badge 角标）+ .weui-cell / .weui-cell__icon--brand / .weui-cell__ft_in-access + .weui-empty + .mp-tabbar。

度量：导航栏 44px、胶囊 87×32；TabBar 高 50px、底 --weui-BG-1、图标 27px、文字 10px；单元格最小 56px、17px 主文字；资产格数字 19px、间隔 0.5px 发丝线。

配色：交互主色品牌蓝（图标、TabBar 选中）；金额 .weui-price（微信电商红）；未读 / 角标用 var(--weui-RED)；链接色 var(--weui-LINK)；本页不使用强调橙。

页面说明

所属端：用户端小程序（tabBar 页）

入口：tabBar「我的」

跳转：订单区 → order-list?tab=类型；服务区 → favorites / address-list / 拨打客服 400-800-8888 / feedback / feedback-records / about；消息中心 → message-center（目标形态）；用户区已登录 → 弹头像昵称表单

数据：用户信息（头像 / 昵称 / 手机号）；订单统计 total / pendingPayment / pendingDispatch+pendingDelivery（待配送口径）/ delivering / completed / cancelled / refunded

布局结构

  1. 渐变头部：头像 + 昵称 + 手机号脱敏 + 会员等级标签 + 右箭头
  2. 资产条（.mp-statgrid）：余额（.weui-price--sm）/ 优惠券 / 水票 / 积分，点击下钻
  3. 「我的订单」组标题（.weui-cells__title）+ .weui-panel 内 .weui-grids 五入口：全部 / 待付款 / 待配送 / 配送中 / 已完成（各带图标与 .weui-badge 角标）
  4. 「常用服务」组标题 + 服务单元格（13 项）：我的收藏 / 收货地址 / 水桶账户 / 周期订购 / 优惠券 / 我的水票 / 储值 / 会员中心 / 积分中心 / 消息中心 / 意见反馈 / 反馈记录 / 关于我们
  5. 「退出登录」入口（语义红）
  6. 底部原生 TabBar：首页 / 订单 / 我的（当前选中「我的」）

状态与规则

空态：无头像显示默认头像字母（游客态显示「游」）；无订单角标不显示数字；游客态：昵称「游客」+「点击头像登录」，角标全 0（状态二）；加载态：「加载中...」；错误态：获取用户信息失败回退游客态；禁用态：登录中禁用重复触发。

角标规则：>99 显示 99+；待配送口径 = 待派单 + 待配送。金额一律 .weui-price（分转元两位小数）。useDidShow 加载用户信息与订单统计；未登录回退游客态且不发起需登录请求。

设计要点 / 禁忌

Web 风旧组件（卡片 / 四列宫格 / 快捷入口 / 旧 TabBar / 缩略图等旧类名）一律禁用，全部以 WeUI 等价类实现；本页不出现强调橙，资产条数字与单元格图标一律品牌蓝，角标仅用语义红。

用户区 / 资产条 / 订单区 / 常用服务 / 退出登录自上而下分区清晰；触达行高 ≥ 44px（单元格最小 56px）；「设置」为现状死链，本稿不呈现待清理。

消息中心入口为 目标形态（F-NTF-002），未读数与消息中心联动；订单入口按切片补全为五入口；优惠券 / 水票入口归属见 10-marketing.md（优惠券）与水票域，07-user.md 未定义，需交叉确认归属。
