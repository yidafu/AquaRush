组件与度量

组件体系：微信官方 WeUI 2.x；品牌区为渐变头（.hero + .phone-screen.is-brand，胶囊自动转白），说明区用官方 .weui-cells，协议勾选用 .weui-checkbox。

本页组件：.phone-screen.is-brand / .mp-status / .mp-nav.is-brand / .mp-capsule + .weui-cell__icon--brand + .weui-checkbox + .weui-btn_area / .weui-btn_primary + .weui-mask / .weui-dialog（拦截弹窗）。

度量：导航栏 44px、微信胶囊 87×32；复选 22×22（圆角 4px）；按钮高 48px、圆角 8px；弹窗宽 280px、圆角 12px、按钮行高 56px。

配色：协议链接用 var(--weui-LINK)；主按钮与勾选用品牌蓝；本页无金额、无强调橙。

页面说明

所属端：用户端小程序

入口：冷启动静默登录失败需显式登录时；「我的」页未登录点击用户区（handleWeChatLogin）；下单等需登录操作时引导登录

跳转：登录成功后回跳原页面（回跳目标页）

数据：token、userInfo（头像 avatar / 昵称 nickname / 手机号 phone）、openid

布局结构

  1. 渐变头图品牌区：水滴标识 + 品牌名「AquaRush 桶装水」+ 标语「像点外卖一样方便地买水」（无 TabBar）
  2. 底部白色区：.weui-cells 登录说明（登录价值 + 游客可浏览）
  3. 用户协议 / 隐私政策勾选行（.weui-checkbox + 链接色协议名）
  4. 「微信一键登录」主按钮（.weui-btn_area + .weui-btn_primary，全宽）
  5. 次级入口「暂不登录，先逛逛」
  6. 未勾选协议拦截弹窗（.weui-mask + .weui-dialog）

状态与规则

游客态：昵称显示「游客」+「点击头像登录」，订单角标全 0；加载态：Toast「正在登录...」；错误态：Toast「登录失败」「网络连接失败，请检查网络设置」；禁用态：登录请求单飞（silentLoginPromise），同一时刻仅一个登录请求，防并发重复。

拦截规则：未勾选协议不得发起登录，弹拦截提示并指引先同意（状态二）；同意后继续登录，不阻断主流程。冷启动 silentLogin：有 token 先校验刷新，无效则 Taro.login 取 code → REST /api/auth/wechat/login → 存 token + userInfo。

设计要点 / 禁忌

Web 风旧组件（勾选 / 按钮 / 底部弹层 / 遮罩等旧类名）一律禁用，全部以 WeUI 等价类实现；协议链接用 var(--weui-LINK)，不得用强调橙。

品牌区遵循主色渐变，白字由 .hero / .is-brand 提供，页面内不出现裸 hex；登录页无 TabBar，仅保留 .home-indicator。

规格 07-user.md 明确「免授权弹窗、无独立登录页」（不调用 wx.getUserProfile，属静默登录）；本稿为评审用登录引导视觉，落地时以静默登录为主链路，不新增独立授权弹窗页。
