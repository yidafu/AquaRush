组件与度量

组件体系：微信官方 WeUI 2.x；授权面板用官方 .weui-mask + .weui-dialog（标题 + 模板勾选列表 + 双按钮），降级提示用官方 .weui-notice。

本页组件：.mp-nav（二级页）+ .weui-cells__title / .weui-cells + .weui-tag（场景标签）+ .weui-btn_plain-primary「一键开启 / 去开启」+ .weui-mask / .weui-dialog / __hd / __title / __bd / __ft / __btn_primary + .weui-checkbox.on + .weui-notice + .weui-price + .mp-footbar。

度量：导航栏 44px、胶囊 87×32；单元格最小 56px；弹窗宽 280px、圆角 12px、标题 17px、按钮行高 56px；复选 22×22；通告栏内边距 10px 16px。

配色：弹窗主按钮「允许」用品牌蓝（不得用强调橙诱导）；金额 .weui-price（微信电商红）；本页不使用强调橙。

页面说明

所属端：用户端小程序（UI 为目标形态；送水工端复用同域推送能力）

入口：下单确认页（order-confirm）提交前订阅授权弹窗 / 组件；消息中心「订阅管理」区（F-NTF-002）

跳转：未授权降级站内查看（订单详情 / 消息中心），不阻塞下单主流程

数据：可订阅场景、模板 ID、授权状态、授权剩余次数

布局结构

  1. 授权前置引导（.weui-cells__title + .weui-cells）：说明订阅用途 + 6 个场景标签（下单成功 / 配送员接单 / 开始配送 / 送达确认 / 退款结果 / 催单）+「一键开启」
  2. 订阅授权弹窗（.weui-mask + .weui-dialog）：模板列表（.weui-checkbox.on + 模板名 + 触发场景）+「拒绝」「允许」
  3. 拒绝后降级提示：.weui-notice + 站内可查看节点列表 + 「去开启」补救入口
  4. 确认订单页吸底「提交订单」主按钮（不受授权状态阻塞）

状态与规则

授权状态：已授权 / 未授权 / 已拒绝 / 达次数上限（不再弹）；场景开关 启用 / 停用。

规则：授权弹窗须在提交订单时机触发（与提交动作绑定，不可诱导）；已拒绝或达上限不再打扰；未授权不阻塞下单；发送失败重试并幂等。模板由后台配置（F-NTF-005）驱动，场景与模板 ID 一一对应。

设计要点 / 禁忌

Web 风旧组件（卡片 / 列表 / 列表项 / 勾选 / 金额行 / 底部操作栏 / 遮罩弹层等旧类名）一律禁用，全部以 WeUI 等价类实现。

弹窗内「允许」用品牌蓝，不得用强调橙诱导授权；未授权不得阻断下单主流程；「已拒绝 / 达上限」不再弹授权（不打扰）；场景与模板由后台配置驱动，前端不硬编码模板 ID。

投递链路已接通，UI 为目标形态；缺口 G08（仅脚手架，无发送服务、无 access-token 服务）；权威定义见 13-notification.md，历史编号 F-ADR-011 保留。
