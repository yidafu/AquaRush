组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；单选钮 22px（.weui-radio.on 品牌蓝 + 白点）；按钮高 48px 圆角 8px；金额大号 .weui-price--lg（22px）；单元格内缩 16px 发丝线。

价格：所有金额用 .weui-price（微信电商红 #FA5151），符号 / 小数位缩放；应付金额用 .weui-price--lg。

用色：交互主色品牌蓝（导航 / 主按钮 / 单选 / 成功对勾）；订单状态用 .weui-tag--pay；本屏未使用强调橙（目标形态用 .weui-tag--goal 标注）。

页面说明

所属端：用户端小程序

功能：F-ORD-005 在线支付（微信支付，已实现，V3 + 假支付 mock）。

入口：订单详情「去支付」/ 订单列表「立即支付」。

跳转：调起微信支付 SDK（Taro.requestPayment）；结果回显 → 重新拉取订单详情。

数据：订单号、应付金额、支付方式 WECHAT_PAY、支付时间、交易号、过期时间 expired_at。

布局结构

  1. 支付确认：订单号 + 支付方式 .weui-cells 单选（微信支付 / 余额支付「即将上线」）+ 支付金额 .weui-price--lg + .weui-btn_area「确认支付」
  2. 支付中：loading 遮罩（本稿以确认态表达）
  3. 支付结果态：成功确认页（.weui-empty__icon 换对勾 + 金额 + 订单信息 + 查看订单 / 返回首页）
  4. 支付超时倒计时（目标形态）：剩余时间 + 超时规则 + 取消订单 / 重新支付

关键交互

  1. 点「去支付」→ 调起微信支付（假支付模式自动完成）
  2. 微信回调 → 服务端验签 + 金额校验 → 订单「待支付 → 待派单」（R-ORD-01）
  3. 支付结果实时回显至订单详情（重新拉取 order 查询）
  4. 超时 30 分钟 → 自动取消并恢复库存（R-ORD-04）
  5. 重复回调须幂等，不重复流转、不重复提示支付结果

状态与规则 / 设计要点

支付中：loading 遮罩。

支付失败 / 取消：订单保留「待支付」，可再次支付。

支付超时：订单变「已取消」（.weui-tag--cancel），库存恢复。

支付成功：订单流转至「待派单」（.weui-tag--assign），记录支付时间与交易号。

设计要点：金额必须与后端一致（防篡改）；验签失败 / 金额不符拒绝放行并告警；金额一律 .weui-price 两位小数；成功态对勾使用品牌蓝；不得出现重复的支付结果提示； 支付超时倒计时为目标形态（现状无倒计时组件）。
