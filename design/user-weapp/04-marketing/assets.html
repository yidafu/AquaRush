页面说明

所属端：用户端小程序（Taro）

入口：我的页 →「我的资产」（储值余额 / 我的套餐）

跳转：「充值」→ recharge；水桶账户 / 水票 / 优惠券 / 积分各入口；确认订单页新增「余额抵扣」「套餐卡核销」区

数据：本金余额（分）、赠送余额（分）、套餐卡张数 / 桶数、有效期、状态、抵扣明细

功能状态：规划中（缺口 G79），本页为目标形态。

布局结构

  1. 余额卡（.weui-cells）：余额 .weui-price--lg + 本金 / 赠送说明 +「充值」（.weui-btn_mini）
  2. 我的套餐（.weui-cells）：次卡 / 月卡剩余次数与有效期（可用 .weui-tag--brand / 已过期 .weui-tag--done）
  3. 资产入口（.weui-cells）：水桶账户 / 水票 / 优惠券 / 积分（.weui-cell__ft_in-access）
  4. 明细流水（.weui-cells__title + .weui-cells）：时间 + 备注 + 金额（收入 + / 支出 -）
  5. 空态：.weui-empty「可用套餐不足」「暂无流水」

关键交互

  1. 下单选余额抵扣：优先扣赠送余额、再扣本金（不足走微信组合支付）
  2. 购买套餐 → 按张数 / 桶数生成套餐卡 → 下单核销抵扣（幂等）
  3. 各入口跳转对应资产页；「充值」→ 充值页

状态与规则

套餐卡：可用 / 已核销 / 已过期；空态：「可用套餐不足」「暂无流水」；禁用：余额抵扣「抵扣金额不能超过应付金额」。

流水配色：收入用 var(--weui-price) 前缀 +，支出用 var(--weui-FG-0) 前缀 -。

抵扣顺序：赠送余额优先，再扣本金；本金 / 赠送分开展示。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x；余额、充值按钮、套餐状态用品牌蓝 / 语义色，唯一券元素（优惠券入口图标）用品牌橙红。

关键度量：导航 44px + 胶囊 87×32；.weui-price--lg 22px；.weui-btn_mini 高 28px；.weui-cell 0.5px 内缩 16px 发丝线；页面底 --weui-BG-0。

本页组件：.mp-nav / .mp-capsule、.weui-cells / __title / __tips、.weui-cell / .weui-cell__ft_in-access、.weui-cell_link、.weui-tag（--brand / --done）、.weui-btn_mini / .weui-btn_primary、.weui-empty、.weui-price--lg。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G79。

强调橙禁用：本页属「余额 / 资产」类，禁止把强调橙用于非券元素；余额、充值按钮、明细金额均用品牌蓝 / 语义色。唯一例外是「优惠券」入口图标，作为券品牌元素使用品牌橙红（设计系统 §2.1）。

本金 / 赠送余额分开展示；组合支付明细需清晰；预付卡合规提示。

明细金额正负用色：收入 var(--weui-price) / 支出 var(--weui-FG-0)，金额用 .weui-price；禁止手拼「¥」字符串。
