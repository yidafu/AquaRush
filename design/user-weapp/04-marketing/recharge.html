页面说明

所属端：用户端小程序（Taro）

入口：我的页「我的资产 → 储值余额」→ 充值页

跳转：充值成功 → 我的资产 assets（余额）；「充值记录」→ 充值流水列表

数据：档位金额、赠送金额、本金余额、赠送余额、支付状态、流水号

功能状态：规划中（缺口 G79），本页为目标形态。

布局结构

  1. 当前余额卡（.weui-cells）：本金余额 + 赠送余额（.weui-price--lg 分别展示）
  2. 「储值套餐」（.weui-cells__title）档位卡：.weui-cell + .weui-radio 选中，充 ¥100 得 ¥110 / 充 ¥200 得 ¥230
  3. 自定义金额：.weui-cell + .weui-input
  4. .weui-notice「赠送余额不可退」
  5. 充值须知：有效期 / 退款规则 / 限额 / 单用途预付卡合规（.weui-cells__tips）
  6. 充值记录入口（.weui-cell_link）+ .weui-btn_area 内 .weui-btn_primary「立即充值」
  7. 确认充值半屏（.weui-mask + .weui-half）：档位 / 赠送 / 金额明细 / 微信支付 /「确认支付」

关键交互

  1. 选充值档位 / 输入自定义金额 → 应付金额联动 →「立即充值」→ 确认半屏
  2. 确认 → 微信支付 → 回调入账（幂等，本金 / 赠送分别入账）→ 余额到账
  3. 充值须知常驻可展开；「充值记录」→ 流水查询

状态与规则

档位：选中（.weui-radio.on）/ 未选；支付 loading：按钮转「支付中…」；充值失败：toast 提示并保持原状态；冻结账户：不可充值（按钮置灰 .weui-btn_disabled）。

资金三件套：幂等 + 对账 + 资损监控不可砍。

合规：单用途预付卡，有效期 / 退卡规则 / 限额须明示；赠送余额与本金分账。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x；档位选中态、充值按钮、余额数字均用品牌蓝 / 微信电商红，不使用强调橙。

关键度量：导航 44px + 胶囊 87×32；.weui-radio 22px；.weui-btn_primary 高 48px；.weui-btn_area 内边距 16px；.weui-half 顶部圆角 12px。

本页组件：.mp-nav / .mp-capsule、.weui-cells、.weui-cells__title / __tips、.weui-cell、.weui-radio、.weui-input、.weui-notice、.weui-btn_area + .weui-btn_primary、.weui-cell_link、.weui-mask + .weui-half、.weui-price--lg。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G79。

资金类三件套：幂等 + 对账 + 资损监控不可砍；预付卡合规：有效期 / 退卡规则 / 限额须明示，赠送余额与本金分账。

强调橙禁用：本页属「余额 / 资产」类，禁止把强调橙用于非券元素；档位选中态、充值按钮、金额一律用品牌蓝 / 微信电商红。

赠送金额与本金余额需区分展示，合规提示不可省略；金额禁止手拼「¥」字符串，统一用 .weui-price（分转元、两位小数）。
