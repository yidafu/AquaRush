# JWT Debug Endpoint Documentation

## Overview

The JWT debug endpoint allows developers to generate JWT tokens for debugging and testing purposes. This endpoint is only enabled when `app.debug.enabled=true` is set in the configuration.

## Configuration

To enable the debug endpoints, set the following environment variable or configuration:

```bash
export DEBUG_ENABLED=true
```

Or add to your `application.yml`:

```yaml
app:
  debug:
    enabled: true
```

**IMPORTANT**: This should only be enabled in development environments!

## Endpoints

### 1. Generate JWT Token

**POST** `/api/debug/auth/generate-jwt`

Generates a JWT token for a user based on their ID from the users table.

#### Request Body

```json
{
  "userId": 1
}
```

#### Response

```json
{
  "success": true,
  "message": "JWT token generated successfully",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 1,
    "username": "user_openid_here",
    "userType": "USER",
    "nickname": "Test User",
    "status": "ACTIVE",
    "authorities": ["ROLE_USER"]
  },
  "timestamp": "2025-12-09T10:30:00"
}
```

#### Example Usage

```bash
# First, get a list of users to find a valid user ID
curl -X GET http://localhost:8080/api/debug/auth/users

# Generate JWT for a specific user
curl -X POST http://localhost:8080/api/debug/auth/generate-jwt \
  -H "Content-Type: application/json" \
  -d '{"userId": 1}'
```

## Using the Generated JWT Token

Once you have a JWT token, you can use it to authenticate with the application:

```bash
# Use the token in Authorization header
curl -X GET http://localhost:8080/graphql \
  -H "Authorization: Bearer YOUR_JWT_TOKEN_HERE" \
  -H "Content-Type: application/json" \
  -d '{"query": "{ currentUser { id nickname } }"}'
```

## Testing Workflow

1. **Start the application with debug enabled:**

   ```bash
   DEBUG_ENABLED=true ./gradlew :services:aqua-client:bootRun
   ```

2. **Get a list of users:**

   ```bash
   curl -X GET http://localhost:8080/api/debug/auth/users
   ```

3. **Generate a JWT token for a specific user:**

   ```bash
   curl -X POST http://localhost:8080/api/debug/auth/generate-jwt \
     -H "Content-Type: application/json" \
     -d '{"userId": 1}' | jq -r '.data.token'
   ```

4. **Use the token to test authenticated endpoints:**

   ```bash
   TOKEN=$(curl -X POST http://localhost:8080/api/debug/auth/generate-jwt \
     -H "Content-Type: application/json" \
     -d '{"userId": 1}' | jq -r '.data.token')

   curl -X GET http://localhost:8080/graphql \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"query": "{ currentUser { id nickname email } }"}'
   ```

## Security Notes

- These debug endpoints should **NEVER** be enabled in production
- The endpoints expose sensitive user information
- JWT tokens generated by these endpoints have the same expiration time as normal tokens (24 hours by default)
- Always set `DEBUG_ENABLED=false` in production environments

## Error Responses

### User Not Found

```json
{
  "success": false,
  "message": "User with ID 999 not found",
  "errorCode": null,
  "timestamp": "2025-12-09T10:30:00"
}
```

### Debug Mode Disabled

If debug mode is not enabled, the endpoints will return 404 Not Found.

```json
{
  "timestamp": "2025-12-09T10:30:00",
  "status": 404,
  "error": "Not Found",
  "path": "/api/debug/auth/generate-jwt"
}
```
