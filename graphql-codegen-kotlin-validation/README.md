# GraphQL Code Generator Kotlin Validation Plugin

增强版的 GraphQL Code Generator Kotlin 插件，支持自动生成 Jakarta Validation 注解。

## 功能特性

- ✅ **自动验证注解生成**：从 GraphQL directives 自动生成 Jakarta Validation 注解
- ✅ **完整的指令支持**：支持所有常用的验证指令
- ✅ **中文消息保留**：保持原始的中文验证消息
- ✅ **原生 Kotlin 支持**：使用 `@field:` 注解确保 Kotlin 字段验证正确工作
- ✅ **完全兼容**：保持与原 `@graphql-codegen/kotlin` 插件的所有功能
- ✅ **高度可配置**：支持自定义指令映射、包名和验证选项

## 安装

### 项目内使用（推荐）

此插件直接集成在 AquaRush 项目中：

```bash
# 安装依赖
npm install

# 构建插件
npm run build
```

### 作为独立包使用

```bash
npm install @graphql-codegen/kotlin-validation
```

## 配置

在 `codegen.yml` 中替换原来的 `@graphql-codegen/kotlin` 插件：

```yaml
generates:
  modules/aqua-common/src/main/graphql-gen/schema.kt:
    plugins:
      - '@graphql-codegen/kotlin-validation'  # 替换原来的 '@graphql-codegen/kotlin'
    config:
      package: "dev.yidafu.aqua.common.graphql.generated"
      validationAnnotations: true
      validationPackage: "jakarta.validation.constraints"
      annotationTarget: "field"
      # 其他原有配置保持不变...
      scalars:
        Long: "java.lang.Long"
        BigDecimal: "java.math.BigDecimal"
        LocalDateTime: "java.time.LocalDateTime"
```

## 配置选项

| 选项 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `validationAnnotations` | `boolean` | `false` | 是否生成验证注解 |
| `validationPackage` | `string` | `"jakarta.validation.constraints"` | 验证注解包名 |
| `annotationTarget` | `'field' \| 'property'` | `'field'` | 注解目标位置 |
| `directiveMapping` | `Record<string, ValidationMapping>` | `default` | 自定义指令映射 |
| `validationImports` | `string[]` | `[]` | 额外的验证导入 |
| `suppressUncheckedCast` | `boolean` | `true` | 是否添加 @Suppress("UNCHECKED_CAST") |

## 支持的验证指令

| GraphQL Directive | Jakarta Validation Annotation | 支持参数 |
|------------------|-----------------------------|----------|
| `@notBlank` | `@NotBlank` | `message` |
| `@size` | `@Size` | `min`, `max`, `message` |
| `@email` | `@Email` | `message` |
| `@pattern` | `@Pattern` | `regexp`, `message` |
| `@range` | `@Range` | `min`, `max`, `message` |
| `@positive` | `@Positive` | `message` |
| `@future` | `@Future` | `message` |
| `@past` | `@Past` | `message` |
| `@min` | `@Min` | `value`, `message` |
| `@max` | `@Max` | `value`, `message` |
| `@notNull` | `@NotNull` | `message` |

## 使用示例

### GraphQL Schema 定义

```graphql
input CreateUserInput {
  username: String!
    @notBlank(message = "用户名不能为空")
    @size(min = 3, max = 20, message = "用户名长度应在3-20个字符之间")

  email: String!
    @email(message = "邮箱格式不正确")
    @notBlank(message = "邮箱不能为空")

  age: Int
    @min(value = 18, message = "年龄必须大于等于18岁")
    @max(value = 120, message = "年龄必须小于等于120岁")
}
```

### 生成的 Kotlin 代码

```kotlin
// Generated by GraphQL Code Generator with Jakarta Validation support
package dev.yidafu.aqua.common.graphql.generated

import jakarta.validation.constraints.*

data class CreateUserInput(
    @NotBlank(message = "用户名不能为空")
    @Size(min = 3, max = 20, message = "用户名长度应在3-20个字符之间")
    val username: String,

    @Email(message = "邮箱格式不正确")
    @NotBlank(message = "邮箱不能为空")
    val email: String,

    @Min(value = 18, message = "年龄必须大于等于18岁")
    @Max(value = 120, message = "年龄必须小于等于120岁")
    val age: kotlin.Int? = null
) {
  @Suppress("UNCHECKED_CAST")
  constructor(args: Map<String, Any>) : this(
      args["username"] as String,
      args["email"] as String,
      args["age"] as kotlin.Int? ?: null
  )
}
```
