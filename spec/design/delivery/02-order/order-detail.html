页面说明

所属端：送水工端 App（Expo React Native，亮色）

入口：任务列表点击任务卡。

跳转：「修改地址信息」→ 修改地址信息弹层（F-ORD-024）；「导航」→ 第三方地图（F-ORD-029）；「转单」→ 转单弹层（F-ORD-028）；电话图标 → tel: 拨号。

布局结构

  1. 导航栏：返回 + 标题 + 消息入口（未读红点）
  2. 状态头：订单状态标签 + 配送进度（下单 → 支付 → 派单 → 配送 → 完成）+ 订单号
  3. 收货地址卡：收货人 / 电话（配送阶段完整可见可拨打；非配送阶段脱敏 138****6621 且无拨号入口——号码保护 F-ORD-032 ）/ 省市区 + 详细地址 / 楼层 / 定位；内嵌目的地地图；卡底按钮组「修改地址信息(定位/楼层等)」+「导航」
  4. 商品卡：图 / 名 / 规格 × 数量
  5. 收款方式（配送中）：现金 / 水票 / 扫码 三选一
  6. 配送照片上传（≥ 1 张）+ 配送备注
  7. 配送信息卡（完成态）：配送备注 / 完成时间 / 收款方式
  8. 底部操作区：「开始配送」/「完成配送」+「转单」

关键交互

  1. 「开始配送」→ 待配送 → 配送中（startDelivery）。
  2. 拍照 → 上传返回 fileUrl（≥ 1 张，支持删除）。
  3. 选收款方式 → 必选（非自提且无水票核销时拦截；电子票核销订单自动记「水票」；自提订单默认已收款豁免）。
  4. 「完成配送」→ 前置校验（本人订单、状态 = 配送中、照片非空、收款方式必选）→ 配送中 → 已完成，记 completedAt（送达即完成，R-ORD-11）。
  5. 「修改地址信息」→ 打开弹层（地址修正仅改订单快照，不回写地址簿）；「导航」→ 唤起第三方地图；「转单」→ 打开转单弹层。

状态与规则

状态：待配送 / 配送中 / 已完成；已完成 = 终态（不可取消、不可修正地址、不展示转单）。

禁用态：未拍照禁用「完成配送」并提示「请先拍摄配送照片」；终态订单隐藏修改地址 / 转单入口。

错误态：提交失败提示后端错误（如「订单已结束」）；自提标识：自提订单显示自提标识、免运费。

收款方式三选一互斥；导航无坐标时降级为「复制地址」；离线提示「网络不可用，可复制地址」。

号码保护（R-ORD-17，F-ORD-032 规划中）：收货人电话按配送阶段控制可见性——「待配送 / 配送中」完整号码 + tel: 拨号；其余阶段脱敏「前 3 + **** + 后 4」且无拨号入口；管理员后台订单详情不受限（完整可见）。

弹层说明（转单）

转单弹层：标题「转单」+ 目标送水工列表（在线，按片区 / 就近排序，忙碌不可选）+ 转单原因（选填）+ 取消 / 确认。

仅「待配送 / 配送中」可转；目标须在线可接单（R-ORD-08 口径）；已完成 / 已取消不可转；并发转单幂等仅一次生效；留痕含原 / 目标 / 时间 / 原因。空态「暂无其他在线送水工」；不可接单提示「该送水工当前不可接单」。

设计要点 / 禁忌

完成配送为硬校验（照片 ≥ 1 张 + 收款方式必选），未满足不得提交；送达即完成，不得出现「待确认收货」中间态。

送水工端完全不出现强调橙：主操作「开始配送 / 完成配送」走品牌蓝（品牌蓝 --brand），禁用态置灰，异常用 error 色。

规划中缺口：转单 F-ORD-028（G84，规划中，chip-plan）；一键导航 F-ORD-029（G85，地图已具备 / 唤起导航未集成，chip-partial）；号码保护 F-ORD-032（G95，规划中，2026-10-11 新增）。目标形态以 .tag-goal 标注。
