页面说明

所属端：送水工端 App（Expo React Native，亮色）

入口：工作台快捷入口「历史订单」/「我的」页「历史订单」。

跳转：点击订单卡片 → 订单详情。

布局结构

  1. 导航栏：返回 + 标题「历史订单」+ 消息入口（未读红点）
  2. 日期筛选（分段控件：今日 / 近 7 天 / 本月）
  3. 历史订单卡片列表：订单号 + 状态标签 + 收货地址 + 商品摘要 + 完成时间 / 收款方式 + 金额
  4. 加载更多区：「没有更多了」

关键交互

  1. 按时间 / 状态筛选；下拉刷新 / 触底加载。
  2. 点击卡片查看订单详情。

状态与规则

空态：「暂无历史订单」；加载态：加载中；禁用态：无更多数据时显示「没有更多了」。

营收口径：按完成配送时间（completed_at）计入，送水工业绩 / 收款日报 / 对账三者口径一致（R-ORD-11）。

设计要点 / 禁忌

订单号可截断但需完整可查；金额精确到分、统一「¥xx.xx」。

送水工端完全不出现强调橙：状态标签用 .tag-done 灰系，选中项走品牌蓝。

列表倒序（按完成时间）不可打乱；卡片圆角 ≥ 16px。
