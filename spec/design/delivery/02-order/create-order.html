页面说明

所属端：送水工端 App（Expo React Native，亮色）

入口：工作台快捷入口「代客下单」/ 任务列表悬浮按钮。

跳转：提交成功后 1.5s 返回；订单落入「待派单」。

布局结构

  1. 导航栏：返回 + 标题「代客下单」+ 消息入口（未读红点）
  2. 收货地址卡（AddressDisplay）
  3. 商品选择卡（ProductSelector）：未选时「点击选择商品」，选中后回显封面 / 名称 / 价格 / 库存
  4. 数量步进器（Stepper）
  5. 自提开关（自提免运费、记为已收款）
  6. 收款方式（默认现金）
  7. 备注输入
  8. 底部提交栏：合计 +「创建送水订单」

关键交互

  1. 点击商品卡 → 打开底部弹层「选择商品」，首开加载在售商品（每页 20）。
  2. 搜索框输入（防抖 300ms）→ searchProducts 实时刷新列表；空结果区分「暂无可用商品」/「没有匹配的商品」。
  3. 点击选中商品 → 弹层关闭，卡片回显商品并带勾选标记。
  4. 填数量 / 选自提 / 填备注 → 校验地址、商品、数量（≥ 1）→ 提交 createOrder。

状态与规则

空态：弹层无商品「暂无可用商品」/「没有匹配的商品」；加载态：弹层搜索「加载中...」、提交中按钮「创建中...」。

错误态：提交失败 toast 后端错误；禁用态：未选地址 / 商品或数量 < 1 时提交按钮 disabled。

仅可选在售且有库存商品（R-PRO-01 / R-PRO-03）；items-only，同一商品不可重复；自提订单免运费且 paymentTime = 下单时间（已收款）；代客下单默认 CASH（R-PAY-03）。

设计要点 / 禁忌

送水工端完全不出现强调橙：提交按钮走品牌蓝（品牌蓝 --brand）。

商品图一律 .thumb 占位并标注「实拍图」；不得使用卡通插画风；金额「¥xx.xx」两位小数。

手动改价为订单层兜底（目标形态，单价链「手动实收价」未接入统一取价服务）；同一时刻仅一次提交（防重）。
