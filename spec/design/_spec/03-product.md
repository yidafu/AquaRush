# 03 商品域 页面规格

## 页面 1：用户端小程序 · 首页（建议文件名 home.html）
- 功能编号：F-PRO-001 [已实现]
- 所属端：用户端小程序
- 页面入口与跳转：入口=小程序启动默认页（下拉刷新/触底加载为页内交互）。出口=点击商品卡 navigateTo `/pages/product-detail/index?id=xx`；点击「+」悬浮按钮跳地址列表选择模式（select=true）；轮播第一张 CTA「快速下单」跳下单流程（现状直接进地址选择/确认页）。
- 布局结构：按从上到下逐行——
  1. 顶部自定义导航栏（CustomNavBar）
  2. 顶部轮播位：Swiper 自动轮播 3 张运营图，每张含标题、副标题、CTA 按钮（第一张「快速下单」，其余静态展示）
  3. 「推荐产品」分隔线（AtDivider）
  4. 商品网格：商品封面（1:1 实拍图）+ 商品名称 + 两行描述（副标题/规格）+ 价格区 + 库存文案「库存N」
  5. 加载更多区 AtLoadMore（加载中 / 点击加载更多 / 末尾「没有更多产品了」）
  6. 底部安全区 + 「+」圆形悬浮按钮（AtFab，跳地址选择）
  7. 目标形态：顶部搜索栏 + 分类快捷入口（现状为 TODO 占位）
- 组件清单：CustomNavBar（标题栏 + 右侧图标位）；Swiper/SwiperItem（自动轮播，含标题/副标题/CTA 按钮）；AtDivider（推荐产品分隔线）；商品网格卡片（封面 1:1 + 名称 + 两行描述 + 价格 displayCents 分转元 + 「库存N」）；AtLoadMore（加载中/点击加载更多/无更多）；AtFab（「+」圆形悬浮）；AtButton（轮播 CTA）；ProductService（数据层）。
- 关键交互：
  1. 首屏 useDidShow/useEffect 加载第 0 页（每页 20 条，按 createdAt 倒序）
  2. 下拉刷新重置到第 0 页并停止下拉动画
  3. 触底 useReachBottom：hasMore 且非加载中时请求下一页并追加到列表
  4. 点击商品卡 → 携带商品 id 进入详情页
  5. 点击「+」悬浮按钮 → 跳转地址列表选择模式，为下单准备地址
  6. 加载失败 → 展示错误文案 + 「重试」按钮
  7. 点击轮播位「快速下单」→ 跳转下单流程
- 状态与标签：空态「暂无产品」；加载态首屏「加载中...」、加载更多时 AtLoadMore 显示加载中；错误态首屏错误文案 + 「重试」按钮、分页失败 toast「加载失败」；禁用态 hasMore=false 不触发加载更多、显示「没有更多产品了」；价格标签：有营销优惠时展示优惠价并划线目录价（如「¥15.00 划线 ¥21.00」），无优惠仅展示目录价。
- 关键数据字段：商品封面图、商品名称、描述（副标题/规格）、displayCents（价格，分→元）、库存 stock（「库存N」）、营销优惠价、划线目录价、createdAt（排序）。
- 页面文案：分隔线「推荐产品」；轮播标题「新鲜好水」「品质保证」「优惠活动」；轮播 CTA「快速下单」；无更多「没有更多产品了」；空列表「暂无产品」；首屏加载「加载中...」；失败 toast「加载失败」「刷新失败」。
- 设计要点/禁忌：价格必须以元显示（displayCents 分→元，R-MON-01）；有优惠时优惠价 + 划线目录价并存，无优惠不出现划线价；列表仅展示在售且库存>0 商品（R-PRO-03），由服务端过滤、前端不自行拼接；下架/售罄商品即时可见性以刷新后查询结果为准。色彩/字体规范 PRD 未给，按全局品牌规范。
- 备注：目标形态标注——搜索与分类筛选可用、轮播图可由后台运营配置（F-OPS-001）；缺口 G18（首页搜索入口为 stub）。文档内部不一致：需求描述称轮播为 3 张硬编码，业务规则扩充称 2026-08 起已由后台运营配置驱动（G61 已解决），设计以「可配置」为准。

## 页面 2：用户端小程序 · 商品详情（建议文件名 product-detail.html）
- 功能编号：F-PRO-002 [已实现]
- 所属端：用户端小程序
- 页面入口与跳转：入口=首页商品卡、我的收藏页、订单相关页携带商品 id 进入。出口=立即购买 → BuyModal → 写 pendingOrder → navigateTo order-confirm；客服 → 拨打门店电话；分享 → showShareMenu；无 id/无效 id → toast 后返回。
- 布局结构：按从上到下逐行——
  1. 图片画廊 ProductImageGallery：Swiper 多图，点击 Taro.previewImage 全屏预览，逐图加载/失败占位
  2. 商品信息卡：名称 + 副标题 + 价格区（优惠价 现价/熟客价/特价，红 + 划线价 目录价/原价）+ 「已售/剩余」区 + 规格 + 配送说明（现状固定「当日达」）
  3. 详情图文区：detailContent 以 RichText 渲染，无详情则隐藏区块
  4. 底部操作栏 ActionButtons：收藏（♥/♡）+ 客服（📞）+「立即购买」（仅在售且库存>0 可用，否则显示「暂时缺货」并禁用）
  5. BuyModal 购买弹窗：数量步进（1~库存）+ 确认/取消
- 组件清单：ProductImageGallery（Swiper 多图 + 全屏预览 + 逐图加载态）；ProductInfo（名称/副标题/价格区/已售剩余/规格/配送说明）；ActionButtons（收藏 ♥/♡、客服 📞、立即购买主按钮）；BuyModal（数量步进 1~库存、确认/取消）；LoadingSkeleton（骨架屏）；ProductContext/ProductProvider；AtToast；AtButton。
- 关键交互：
  1. 读取路由 id，无 id → toast「产品ID缺失」并返回
  2. 加载详情，网络错误最多重试 3 次（间隔 1s）；加载中展示 LoadingSkeleton
  3. 收藏：未登录点击 → toast「请先登录」；已登录调用 FavoriteService 切换 → toast「已添加收藏」/「已取消收藏」，图标即时切换
  4. 立即购买 → 打开 BuyModal → 数量超库存拦截「库存不足」→ 确认后写 pendingOrder 本地缓存 → navigateTo order-confirm
  5. 客服：makePhoneCall 直接拨打门店电话；分享：showShareMenu
  6. 下拉刷新重载详情并停止动画
  7. 目标形态：详情页「加入购物车」按钮（F-PRO-004，缺货禁用）
- 状态与标签：空态商品不存在显示「产品不存在」+「返回」按钮；加载态 LoadingSkeleton 骨架屏、画廊逐图加载中占位；错误态 toast「产品不存在」「加载失败，请检查网络后重试」；禁用态库存≤0 或非在售时「立即购买」禁用且显示「暂时缺货」、非在售不渲染主按钮；价格标签：优惠价（熟客价/特价，红）+ 划线目录价/原价，无优惠仅目录价。
- 关键数据字段：图集 images、名称、副标题、现价/熟客价/特价、划线原价/目录价、已售 salesVolume、剩余 stock、规格 specification、水源地、矿物质含量、配送说明、detailContent 富文本、资质证书图。
- 页面文案：「产品ID缺失」「暂时缺货」「已添加收藏」「已取消收藏」「请先登录」「库存不足」「产品不存在」「加载失败，请检查网络后重试」「操作失败，请重试」「返回」；配送说明「当日达」（现状固定文案）。
- 设计要点/禁忌：价格单位元（R-MON-01）；现价/熟客价/特价用红色，与划线原价并存；库存≤0 或非在售必须禁用购买并显示「暂时缺货」（R-PRO-01/R-PRO-03）；按规格展示可退水桶押金（2026-10 恢复押金桶，R-MON-03）；购买按钮禁用由前端控制、最终库存校验以后端原子扣减为准。视觉风格 PRD 未给。
- 备注：目标形态标注——熟客分组价/限时特价/优惠价+划线目录价展示、加入购物车按钮；缺口 G03（仅单商品下单，详情只能单选数量）；G19（销量/库存硬编码）、G52（用户端分组价未展示）、G06（水桶押金）均已解决。

## 页面 3：用户端小程序 · 我的收藏（建议文件名 favorites.html）
- 功能编号：F-PRO-003 [已实现]
- 所属端：用户端小程序
- 页面入口与跳转：入口=我的页「我的收藏」（收藏/取消在商品详情页 F-PRO-002 执行）。出口=点击商品卡 → product-detail?id=xx；空态「去逛逛」按钮 → 回首页。
- 布局结构：按从上到下逐行——
  1. 页头统计：「共 N 件收藏」
  2. 收藏列表：商品封面缩略图 + 名称 + 价格（¥，displayCents）+ 已售 + 缺货标「暂时缺货」，点击整卡进详情
  3. 加载更多区 AtLoadMore（加载中 / 「没有更多了」）
  （整页由 BasePageLayout 承载，含登录引导空态 / 无收藏引导空态）
- 组件清单：BasePageLayout（页头统计 + 空态容器）；收藏列表项（封面缩略图 + 名称 + 价格 ¥ + 已售 + 缺货标）；AtGrid（样式）；AtLoadMore；FavoriteService；authService。
- 关键交互：
  1. useDidShow 检查登录态，已登录则刷新第 0 页；未登录展示登录引导空态
  2. 下拉刷新重置第 0 页；触底加载下一页（每页 20）
  3. 点击商品卡 → navigateTo product-detail?id=xx；在详情页取消收藏后返回，useDidShow 自动刷新列表
- 状态与标签：空态「暂无收藏」「快去收藏喜欢的商品吧」+「去逛逛」按钮；加载态首屏 loading、加载更多 AtLoadMore 加载中；错误态 toast「加载失败」；禁用态未登录时显示登录引导、不加载列表；缺货商品标「暂时缺货」且仍可点击进详情。
- 关键数据字段：收藏总数 N、封面缩略图、名称、价格 displayCents、已售、缺货状态。
- 页面文案：「共 N 件收藏」「暂无收藏」「快去收藏喜欢的商品吧」「去逛逛」「暂时缺货」「加载失败」「没有更多了」。
- 设计要点/禁忌：缺货商品标「暂时缺货」但仍可点击；未登录不加载列表、只展示登录引导。视觉细节 PRD 未给。
- 备注：收藏为用户维度数据，跨页面一致性依赖 useDidShow 每次刷新；目标形态为服务端收藏列表随详情页操作即时一致（现状已通过刷新达成）。

## 页面 4：用户端小程序 · 购物车（建议文件名 cart.html）
- 功能编号：F-PRO-004 [规划中]（1.1 状态校准说明：由原「部分实现」按 facts.md §1 校准为「规划中」）

- 页面入口与跳转：入口=商品详情页「加入购物车」按钮、首页悬浮购物车按钮、我的页「购物车」。出口=「去结算」携带勾选商品写入 pendingOrder → 确认订单页（复用 F-ORD-004 多商品下单）；空态「去逛逛」→ 首页。
- 布局结构：按从上到下逐行——（目标形态）
  1. 购物车列表：商品封面 + 名称 + 规格 + 单价 × 数量（步进器）+ 勾选框 + 删除
  2. 底部结算栏：合计金额 + 「去结算」按钮
  3. 空态：无商品时引导去首页逛一逛
- 组件清单（目标形态）：pages/cart（购物车列表项 / 数量步进器 / 勾选框 / 删除按钮 / 结算栏 / 空态）+ utils/cart（本地存储读写/合并/勾选）。
- 关键交互：
  1. 详情页「加入购物车」→ 写本地 `cart` 累积多商品 → toast「已加入购物车」
  2. 购物车页调整数量/勾选/删除 → 合计金额实时汇总（分→元）
  3. 「去结算」→ 携带勾选多商品进入确认订单页（与 F-ORD-004 共用）
  4. 数量调整超库存 → 拦截并提示「库存不足」（R-PRO-01）
- 状态与标签：空态无商品显示空态引导「去逛逛」、结算不可用；加载态本地读取瞬时完成（无网络请求）；错误态本地数据损坏时提示并清空；禁用态无勾选商品时结算按钮禁用。
- 关键数据字段：商品封面、名称、规格、单价、数量、勾选状态、合计金额（分→元）。
- 页面文案：「已加入购物车」「库存不足」「去逛逛」「去结算」。
- 设计要点/禁忌：金额汇总精度（R-MON-01）；数量 ≤ 库存（R-PRO-01）；库存校验以各商品分别校验，部分缺货整体拦截并提示缺货项。视觉 PRD 未给。
- 备注：目标形态标注——购物车页 pages/cart、详情页「加入购物车」按钮激活（缺货禁用）、同商品按 productId 合并数量、入口=详情页按钮 + 首页悬浮购物车按钮 + 「我的」常用服务；缺口 G03 已解决。文档状态矛盾：表格标 [规划中]，需求描述写「现状(2026-08 已实现)」，以 1.1 校准说明 [规划中] 为准。

## 页面 5：送水工端 App · 代客下单（建议文件名 create-order.html）
- 功能编号：F-PRO-005 [已实现]
- 所属端：送水工端 App
- 页面入口与跳转：入口=任务列表页（order-list）顶部悬浮按钮跳转；提交成功 1.5s 后返回，订单进入「待派单」。
- 布局结构：按从上到下逐行——
  1. 选择地址区：AddressDisplay 卡片
  2. 选择商品区：ProductSelector 卡片（未选时「点击选择商品」，选中后展示封面/名称/价格/库存）
  3. 订单详情区：OrderSummaryCard（数量步进 + 是否自提开关 + 备注输入）
  4. 底部提交按钮：「创建送水订单」
  （商品选择为 AtFloatLayout 弹层：「选择商品」标题 + 搜索框 + 商品列表 + 选中勾）
- 组件清单：PageContainer；AddressDisplay；ProductSelector（弹层含搜索框 AtIcon search、商品列表、选中勾）；OrderSummaryCard（数量步进、自提开关、备注）；AtFloatLayout；AtButton。
- 关键交互：
  1. 点击商品卡 → 打开 AtFloatLayout 弹层「选择商品」，首开加载在售商品（每页 20）
  2. 搜索框输入（防抖 300ms）→ searchProducts(keyword) 实时刷新列表；空结果区分「暂无可用商品」/「没有匹配的商品」
  3. 点击选中商品 → 弹层关闭，卡片回显商品（封面/名称/价格/库存）并带勾选标记
  4. 填数量/选是否自提/填备注 → 校验地址、商品、数量（≥1）→ 提交 createOrder
- 状态与标签：空态弹层无商品「暂无可用商品」/「没有匹配的商品」；加载态弹层搜索加载中「加载中...」、提交中按钮「创建中...」+ loading；错误态提交失败 toast 后端错误信息；禁用态未选地址/商品或数量<1 时提交按钮 disabled。
- 关键数据字段：地址、商品封面/名称/价格/库存、数量、是否自提、备注。
- 页面文案：「点击选择商品」「选择商品」「创建送水订单」「创建中...」「暂无可用商品」「没有匹配的商品」「加载中...」「请选择地址」「请选择商品」「数量不能少于1」「创建成功」。
- 设计要点/禁忌：仅可选在售且有库存商品（R-PRO-01/R-PRO-03）；提交时数量不超库存、超限由后端原子扣减兜底；搜索防抖 300ms。视觉 PRD 未给。
- 备注：—（本页无未解决缺口）。

## 页面 6：管理后台 · 商品列表（建议文件名 products-list.html）
- 功能编号：F-PRO-006 [已实现]
- 所属端：管理后台
- 页面入口与跳转：入口=左侧菜单「产品管理」。出口=行「详情」/「编辑」→ /products/:id；「新增商品」→ 打开 ProductForm 弹窗；删除 → Popconfirm 确认后 deleteProduct。
- 布局结构：按从上到下逐行——
  1. 顶部操作栏：「新增商品」按钮（打开创建弹窗）
  2. 筛选条件卡：关键词 + 商品状态 + 价格范围（元）+ 销量范围 + 标签 + 排序方式 + 库存范围；「快速操作」区含「导出数据」「批量导入」按钮（现状 disabled 占位）
  3. 商品表格：列=名称/副标题/规格/价格/原价/库存/销量/排序权重/状态/创建时间，各列可排序
  4. 分页：每页条数切换 + 页码跳转，显示「共 N 条记录」
  5. 操作列：「详情」「编辑」「删除」（删除带 Popconfirm 二次确认）
- 组件清单：ProductFilters（筛选卡）；ProductTable（商品表格 + 价格/库存/状态标签 + 操作列）；ProductForm（新增弹窗）；ProductEditor；EnhancedWeChatPreview；antd(Table/Select/InputNumber/Tag/Popconfirm)。
- 关键交互：
  1. 筛选条件变更（关键词 300ms 防抖、其余即时）→ GET_PRODUCTS_QUERY(productsPaginated) 重新查询
  2. 排序/分页变更 → 更新筛选变量重查
