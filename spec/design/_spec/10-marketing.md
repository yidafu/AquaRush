> 来源：`spec/prd/10-marketing.md`（只读提取，不修改原文）。金额一律以「分」计算与校验、展示层转元（R-MON-01）；功能状态标注沿用 PRD（[已实现]/[部分实现]/[规划中]/[暂缓]）。
> 视觉口径：优惠券相关视觉（券卡金额、类型标签、领券按钮、券选择器、券图标）按 `spec/design/ui-design-system.md` 使用品牌橙红 **#FF5436**，不受「强调橙仅限 CTA」限制；其余页面强调色遵循设计系统 CTA 规则。

## 页面 1：管理后台 · 客户分组管理（建议文件名 customer-groups.html）
- 功能编号：F-MKT-001 [已实现 2026-08]
- 所属端：管理后台
- 页面入口与跳转：用户管理 → 客户分组；分组详情可跳「分组商品价格」(group-prices)；用户管理客户列表(F-USR-022)提供「设置分组」行操作
- 布局结构：
  1. 顶部：面包屑「用户管理 / 客户分组」+ 右侧「新建分组」主按钮
  2. 分组列表表格：分组名 / 描述 / 成员数 / 创建时间 / 操作（新建/编辑/删除）
  3. 分组详情抽屉或页：分组信息 + 成员列表 + 「商品价格策略」入口
  4. 客户列表(F-USR-022)目标形态新增「所属分组」列 + 行操作「设置分组」下拉
  5. 新建/编辑分组弹窗：名称、描述、初始成员（按昵称/手机号搜索多选）
- 组件清单：Table、Modal、Form、Select、Popconfirm；成员多选搜索（昵称/手机号）；分组下拉含「未分组」选项
- 关键交互：
  1. 新建分组：填名称/描述 → 可选初始成员 → 保存；名称重复拦截
  2. 设置分组：客户列表选中用户 → 选择分组 → 保存，即时生效
  3. 编辑分组成员：勾选/取消成员 → 保存，成员覆盖式同步（移除成员回「未分组」）
  4. 删除分组：二次确认 → 成员回退「未分组」
- 状态与标签：无分组/无成员空态；列表/保存 loading；保存失败 toast；删除中禁用操作；未归属显示「未分组」
- 关键数据字段：分组名、描述、memberCount、创建时间、成员（昵称/手机号）、用户「所属分组」
- 页面文案：「新建分组」「分组名称不能为空」「分组名称已存在」「确定删除分组 X 吗？成员将回到未分组」「未分组」
- 设计要点/禁忌：分组是营销受众与计价维度，删除/移除成员影响面大，二次确认需醒目标红；成员多选需支持搜索与已选回显
- 备注：目标形态；客户列表「所属分组」列为目标形态新增；缺口 G50

## 页面 2：管理后台 · 分组价格管理（建议文件名 group-prices.html）
- 功能编号：F-MKT-002 [已实现 2026-08]
- 所属端：管理后台
- 页面入口与跳转：商品管理 → 分组价格；或客户分组详情 → 商品价格(F-MKT-001)
- 布局结构：
  1. 顶部：面包屑 + 分组选择器（切换客户分组）
  2. 操作条：保存 / 批量设置 / 清空分组价
  3. 商品价格表：商品名 / 规格 / 目录价（元）/ 分组价（可编辑，元，空=不设置，回退目录价）/ 较目录价差额（「较目录价省 ¥x」）
- 组件清单：Table、InputNumber（元，precision=2）、Select（分组切换）、Button；差额为只读计算列
- 关键交互：
  1. 选分组 → 加载商品列表（目录价 + 已配置分组价）
  2. 编辑分组价（元）或清空 → 保存（元 ×100 转分提交）
  3. 保存后订单计价即时生效，已生成订单成交价不变（下单快照）
  4. 批量设置：对勾选商品统一填分组价
- 状态与标签：无商品/未配置价格空态；保存中 loading；保存失败 toast；非管理员不可操作（禁用）
- 关键数据字段：分组 ID、商品 ID、规格、目录价（分）、分组价（分，可空）、差额
- 页面文案：「请输入有效的分组价格」「较目录价省 ¥x」「清空」「批量设置」
- 设计要点/禁忌：分组价为选填，空值需明确表达「回退目录价」；差额为让利语义，默认允许低于目录价（是否允许上浮为开放问题）
- 备注：目标形态；缺口 G50

## 页面 3：管理后台 · 优惠券管理（建议文件名 coupons.html）
- 功能编号：F-MKT-003 [已实现 2026-08]
- 所属端：管理后台
- 页面入口与跳转：营销管理 → 优惠券；行「详情」进入营销活动详情页（共用，见页面 8）；相关用户详情「优惠券」Tab(F-USR-022)
- 布局结构：
  1. 顶部：面包屑 + 「新建优惠券」按钮
  2. 券列表表格：券名称 / 类型 / 面额或折扣率 / 门槛 / 适用范围 / 有效期 / 发放方式 / 已领未用数 / 操作（详情/新建/编辑/停用/作废）
  3. 新建/编辑弹窗表单（字段见下）
  4. 定向发放弹窗：选择用户或客户分组 → 发放
- 组件清单：Table、Modal、Form、InputNumber、Select、DatePicker、Radio、Switch（目标形态）
- 表单字段（后台配置，逐个列出）：
  - 券名称（Input，必填，占位「满 50 减 10」）
  - 券类型（Radio：现金券 / 折扣券，必填）
  - 面额（InputNumber，单位元，precision=2，仅现金券，>0，占位「10.00」）或 折扣率（InputNumber，单位折，0.01–9.99，仅折扣券，占位「9.5」）
  - 门槛「满 X」（InputNumber，单位元，≥0，占位「50.00」）
  - 适用范围（Select：全场 / 指定商品；选指定商品时联动商品多选）
  - 有效期类型（Radio：固定区间 / 领取后 N 天）；固定区间用 DatePicker.RangePicker（开始<结束）；领取后 N 天用 InputNumber（天数 >0）
  - 发放方式（Radio：自动领取 / 定向发放）
  - 限领数（InputNumber，整数，>0，占位「每人限领 1 张」）
- 关键交互：
  1. 建券 → 保存上架（可领取/发放）
  2. 定向发放 → 目标用户券包出现
  3. 用户端确认订单 → 满足门槛的可用券列表 → 勾选一张 → 优惠金额计入应付（R-MKT-07）
  4. 订单取消/退款 → 未过期券退回券包（核销幂等）
- 状态与标签：券状态机 未领取 → 已领取 / 已核销 / 已过期 / 已退回；停用/作废后不可领取使用
- 关键数据字段：券模板 ID、类型、面额/折扣率（分/%）、门槛（分）、适用范围、有效期、发放方式、限领数、已领未用数
- 页面文案：「券面额无效」「折扣率超出范围」「门槛金额无效」「有效期不合法」「上架」「停用」「作废」
- 设计要点/禁忌：券卡视觉使用品牌橙红 #FF5436 的金额/类型标签（不受「强调橙仅限 CTA」限制）；后台表单需区分现金券/折扣券两套字段显隐；一单一券不可叠加
- 备注：已实现闭环；缺口 G54 已解决

## 页面 4：用户端 · 领券中心（建议文件名 coupon-center.html）
- 功能编号：F-MKT-003 [已实现 2026-08]
- 所属端：用户端小程序

- 布局结构：
  1. 顶部导航：「领券中心」
  2. 领取状态分区（可领取 / 已领取，目标形态）
  3. 券卡列表：券种卡（左金额区 + 右侧类型/门槛/适用范围/有效期 + 「立即领取」按钮）

- 组件清单：券卡列表、券卡（左橙红金额块）、领取按钮、空态
- 关键交互：点击「立即领取」→ 领取成功 toast → 按钮变「已领取」/进入券包；限领数扣减
- 状态与标签：可领取（按钮可点）/ 已领取（置灰）/ 已领完（置灰）；空态「暂无可领取优惠券」
- 关键数据字段：券名称、面额或折扣率、门槛、适用范围、有效期、领取状态
- 页面文案：「立即领取」「已领取」「已领完」「满 50 减 10」「满 50 打 9 折」
- 设计要点/禁忌：券卡金额、类型标签、领券按钮统一品牌橙红 #FF5436（不受「强调橙仅限 CTA」限制）；券卡形态一眼可辨金额与门槛
- 备注：已实现；券状态机同页面 3

## 页面 6：管理后台 · 满减/折扣活动（建议文件名 promotion-full-reduce.html）
- 功能编号：F-MKT-004 [已实现 2026-08]
- 所属端：管理后台
- 页面入口与跳转：营销管理 → 满减/折扣；行「详情」→ 营销活动详情页（共用，见页面 8）
- 布局结构：
  1. 顶部：「新建活动」按钮
  2. 活动列表表格：活动名称 / 类型 / 档位 / 适用范围 / 时间窗 / 状态（未开始/进行中/已结束/已停用）/ 操作（详情/新建/编辑/停用）
  3. 新建/编辑弹窗：类型、多档位、适用范围、时间窗
- 组件清单：Table、Modal、Form、InputNumber、Select、DatePicker、Switch
- 表单字段：
  - 活动名称（Input，必填，占位「全场满 100 减 10」）
  - 类型（Radio：满减 / 满折，必填）
  - 档位（可增删多行：满 X [InputNumber 元 ≥0] 减 Y [InputNumber 元 >0] / 打 N 折 [InputNumber 折 1-9.99]，档位金额需递增）
  - 适用范围（Select：全场 / 指定商品 / 指定分组；联动选择器）
  - 时间窗（DatePicker.RangePicker，开始<结束，必填）
  - 启用（Switch）
- 关键交互：
  1. 配置活动 → 保存上架 → 下单自动减免（无需领券）
  2. 修改档位/时间窗 → 新订单生效，已生成订单不受影响
  3. 停用 → 立即失效
  4. 用户端确认订单展示「活动已减 ¥x」行（order-confirm）
- 状态与标签：未开始 / 进行中 / 已结束 / 已停用；同一订单命中多活动取优惠最大者，不叠加
- 关键数据字段：活动 ID、名称、类型、档位数组（门槛分/减免分或折扣率）、适用范围、开始/结束时间、状态
- 页面文案：「档位金额需递增」「时间窗不合法」「满 100 减 10」「活动已减 ¥x」
- 设计要点/禁忌：多档阶梯需可增删且实时校验递增互斥；时间窗过期自动失效需在列表状态体现
- 备注：已实现；缺口 G55 已解决

## 页面 7：管理后台 · 限时特价活动（建议文件名 flash-sale.html）
- 功能编号：F-MKT-005 [已实现 2026-08]
- 所属端：管理后台
- 页面入口与跳转：营销管理 → 限时特价；用户端商品列表/详情特价展示(product-detail，归属商品域 F-PRO-002)；行「详情」→ 营销活动详情页（共用，见页面 8）
- 布局结构：
  1. 顶部：「新建特价」按钮
  2. 活动列表表格：商品 / 目录价 / 特价 / 时间窗 / 状态（未开始/进行中/已结束）/ 操作
  3. 新建/编辑弹窗：选商品、特价（元）、时间窗
  4. 用户端展示说明：特价「特价 ¥15.00」+ 划线目录价 ¥21.00（可选倒计时）
- 组件清单：Table、Modal、Form、InputNumber、DatePicker、Select
- 表单字段：
  - 商品（Select/商品搜索，必填，占位「选择商品」）
  - 特价（InputNumber，单位元，precision=2，0.01–99999，占位「15.00」）
  - 时间窗（DatePicker.RangePicker，开始<结束，必填）

  1. 配置特价 → 上架 → 活动期自动按特价计价（R-MKT-02③）
  2. 到期 → 自动失效，回退分组价/目录价
  3. 修改特价/时间窗 → 新订单生效，已生成订单不变
  4. 用户端展示特价与划线目录价
- 状态与标签：未开始 / 进行中 / 已结束；停用后商品回退目录价
- 关键数据字段：商品 ID、目录价（分）、特价（分）、开始/结束时间、状态
- 页面文案：「特价无效」「时间窗不合法」「特价 ¥15.00」「¥21.00（划线）」
- 设计要点/禁忌：特价默认须低于目录价（上浮为开放问题）；同商品时间窗重叠需拦截；划线价与特价视觉区分
- 备注：已实现；缺口 G56 已解决
