页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「地址与配送」→ 配送轨迹

跳转：选择送水工切换查看；轨迹时间轴点选定位到地图

权限：PERMISSION_DELIVERY_WORKER_READ（仅此权限可查）

布局结构

  1. 顶部操作栏：时间范围（默认当天）+「刷新」
  2. 主区左：送水工选择列表（姓名 + 在线状态 + 配送中订单数）+ 订单查询
  3. 主区中：地图轨迹回放（折线 + 起点 / 终点 / 当前位置标记）+ 播放控制条（播放暂停 / 倍速 / 时间刻度）
  4. 主区右：轨迹详情（起止时间 / 总里程 / 平均时速 / 停留点列表）+ 权限说明

关键交互

  1. 选择送水工 → 地图展示当前位置与历史轨迹
  2. 「轨迹回放」→ 按时间顺序播放所选时间范围轨迹，可调速（1× / 2× / 4×）
  3. 轨迹时间轴点选 → 地图定位到该轨迹点并与回放同步高亮
  4. 「刷新」重取当前位置与最新轨迹
  5. 数据仅 PERMISSION_DELIVERY_WORKER_READ 可查

状态与规则

空态：该送水工无轨迹或当前无配送任务「暂无轨迹数据」；加载态：轨迹加载中；错误态：「轨迹加载失败」/ 定位权限拒绝提示。

禁用态：非配送中无实时位置，仅展示历史轨迹。

地图需区分「当前位置标记」与「历史轨迹折线」；上报频率 / 保留时长为后台可配置（开放问题）。

设计要点 / 禁忌

管理端不出现强调橙：轨迹折线与标记统一品牌蓝；当前位置用目标色区分，不用强调橙大色块。

轨迹涉及用户收货地址隐私，仅管理员可查（R-AUTH-02）；用户端配送跟踪复用同一数据源为后续迭代（缺口 G65）。

坐标统一 WGS-84，勿与小程序端 GCJ-02 混用；数据来自 delivery_trajectories 表（G22 已解决）。
