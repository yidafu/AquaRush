页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「地址与配送」→ 地址热力图

跳转：点击标记点 / 列表项联动地图 setCenter；区域维度视图依赖片区数据

权限：PERMISSION_ADDRESS_READ

布局结构

  1. 顶部：时间范围 + 汇总卡（地址总数 / 有坐标地址数 / 统计范围内订单总数）
  2. 主区左：筛选与图例（时间范围 / 订单量 vs 营收 / 按片区聚合 / 热力强度图例）
  3. 主区中：热力图（半透明热力块叠层 + 标记点 + TOP 区域 map-label）
  4. 主区右：TOP 区域排行（.hbar：区域名 / 订单量 / 占比）+ 缺坐标提示 + 导出

关键交互

  1. 进入默认拉取最近 30 天统计 → 渲染热力图 + 标记点 + 排行
  2. 调整时间范围 / 切换订单量与营收 → 重新查询并刷新地图与列表
  3. 点击标记点 / 排行项 → 展示地址详情与订单数，并触发地图定位
  4. 无坐标地址不计入地图点，仅在汇总中体现并提示
  5. 切换「区域维度」按配送片区聚合（片区未建时不可用）

状态与规则

空态：无有坐标地址时提示「暂无带坐标的地址，请通过地图选点或编辑地址补充经纬度」；无订单时热力图不显示热区但标记点仍展示。

加载态：列表 loading + 地图就绪前 Spin；错误态：message「获取地址热度统计失败」。

规则：时间范围开始不得晚于结束、上限 1 年；坐标统一 WGS-84（与天地图底图一致）。

设计要点 / 禁忌

管理端不出现强调橙：热力块与条形统一用品牌蓝系 tint，高热度用加深而非换色。

整页为目标形态：后端暂无按地址聚合订单数接口；区域维度依赖 F-ADR-013 片区数据（缺口 G89）；缺坐标地址无法上图为缺口候选。

缺坐标地址必须显式说明而非静默丢失；热力图与标记点可叠加。
