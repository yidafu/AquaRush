页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「地址与配送」→ 地址管理

跳转：「新增地址」/「编辑」→ 地址表单弹窗；「导入 Excel」→ 地址批量导入弹窗（F-ADR-021）

权限：PERMISSION_ADDRESS_READ / PERMISSION_ADDRESS_WRITE

布局结构

  1. 页面标题区：标题 + 说明 +「导入 Excel」「＋ 新增地址」操作按钮
  2. 筛选卡：收货人 / 手机号 / 省市区 / 标签 / 是否有定位 + 重置 / 查询
  3. 地址表格（全宽）：收货人 / 电话（脱敏）/ 省市区 + 详细地址 / 楼层 / 标签 / 定位坐标 / 关联用户 / 更新时间 / 操作
  4. 分页脚：记录总数 + 已选数 + 页码 + 每页条数
  5. 第二状态：删除二次确认弹窗（居中）

关键交互

  1. 进入页面拉取地址列表；筛选变更（关键词 300ms 防抖）→ 重新查询
  2. 「编辑」打开表单弹窗回填；保存成功后刷新列表
  3. 「删除」弹出二次确认「确定要删除这个地址吗？删除后无法恢复。」→ 确认后删除并刷新
  4. 「导入 Excel」打开批量导入弹窗（见 address-import.html）
  5. 分页 / 排序变更 → 更新筛选变量重新查询

状态与规则

空态：表格空；加载态：表格 loading；错误态：message「获取地址列表失败」「删除失败: …」「操作失败: …」。

手机号：列表内部分脱敏（138****6621），仅授权角色可查看完整号码。

定位坐标：缺坐标行以警示色标注「缺少坐标」，不静默丢失（与 F-ADR-022 联动）。

关联用户：后台新增 / 导入地址 user_id 为 null，显示「—（平台导入）」。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，删除用语义 error 色。

用户端与后台地址同源，数据须一致；编辑应复用 update（现状编辑走 create 会新增一条，属缺陷）。

筛选（收货人 / 手机号 / 省市区 / 标签 / 是否有定位）与分页：后端已支持，前端接入为目标形态；现状为全量拉取。

删除建议补二次确认；导入地址不关联用户。
