页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「地址与配送」→ 配送片区管理

跳转：派单弹窗（F-ORD-022）按片区置顶推荐绑定送水工；编辑 / 启停用 / 删除行内操作

权限：建议复用 OPS_CONFIG_READ / OPS_CONFIG_WRITE（待定，开放问题）

布局结构

  1. 操作栏：「导出」「＋ 新增片区」
  2. 筛选卡：片区名称关键词 / 状态
  3. 片区表格（全宽）：片区名称 / 覆盖范围 / 关联送水工 / 关联地址数 / 状态 / 更新时间 / 操作
  4. 就近派单规则说明卡
  5. 新建 / 编辑弹窗：名称 + 地图圈选 + 默认送水工 + 生效时段 + 启用状态
  6. 第三状态：空态

关键交互

  1. 新增片区 → 选覆盖范围（省市区 / 地图围栏）→ 可选绑定送水工 → 保存
  2. 地图围栏：拖动顶点圈选多边形范围
  3. 启停用 → 即时生效；停用片区内地址下单即不可达（R-ADR-04）
  4. 派单 / 批量派单 → 按收货地址所属片区优先推荐绑定送水工，仍可人工改派
  5. 删除二次确认「确定删除该片区吗?删除后该范围地址将不可下单」

状态与规则

空态：「暂无配送片区,请新增」；加载态：列表 / 保存 loading；错误态：保存失败 message。

禁用态：停用片区不参与校验与推荐。

校验：片区名必填且唯一（「片区名称已存在」）；覆盖范围不能为空（「请选择覆盖范围」）。

片区为「范围校验 + 就近派单」共用数据源；范围变更即时生效，已生成订单按下单时快照。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，删除用语义 error 色。

本页整页为目标形态（缺口 G78：片区维护；G07：现状范围校验恒为真、校验关闭）。现状无片区模型。

与 F-ADR-003 配送区域维护为同一数据底座，实施时可能合并；是否支持地图围栏为开放问题，首批可仅省市区匹配。

地图圈选范围需与底图坐标系一致（WGS-84）。
