页面说明

所属端：管理后台（Ant Design 5）

入口：订单列表点击订单

跳转：派单弹窗；退款管理（支付管理 - 退款管理，R-PAY-02）

权限：取消 / 派单按流转表校验（R-ORD-01）

布局结构

  1. 状态头 + 进度条（下单 → 支付 → 派单 → 配送 → 完成）
  2. 左栏：收货地址卡（含地图）→ 商品明细 → 金额明细卡 → 交付照片核验卡 → 配送轨迹入口
  3. 右栏：支付与退款信息卡 + 订单信息卡（含操作留痕时间线）
  4. 底部操作区：派单 / 取消订单 / 退款 / 修改地址

关键交互

  1. 待派单订单 → 点「派单」→ 打开派单弹窗
  2. 点「取消订单」→ Popconfirm 确认 → cancelOrder → 刷新
  3. 查看配送照片 → 核验闭环：通过 / 驳回（驳回必填原因）
  4. 「修改地址信息」→ 回显当前地址（终态隐藏入口）

状态与规则

金额明细逐行：商品金额 → 满减 → 首单立减 → 优惠券 → 水票抵扣（带桶数标签）→ 赠品行（¥0.00）→ 配送费（免费楼层内显示「免配送费」）→ 水桶押金 → 实付合计；减项红色、实付合计突出。

7 态展示；待派单才显示「派单」；已取消 / 已退款 / 已完成不显示取消；终态不可修正地址。

后台取消按流转表校验（仅允许 待支付 / 待派单 → 已取消、已取消 → 已退款，非法流转拒绝）。

设计要点 / 禁忌

管理端不出现强调橙：取消 / 退款等危险操作用语义 error 色，核验与派单用品牌蓝。

取消按钮为危险样式 + Popconfirm 二次确认；金额一律 ¥0.00；状态一律 .tag-*。

配送照片核验为闭环能力（G23）； 手动改价（F-ORD-023 部分实现）在代客下单页以订单层兜底形态呈现。
