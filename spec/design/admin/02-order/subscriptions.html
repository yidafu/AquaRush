页面说明

所属端：管理后台（已实现，2026-10-11 恢复开发并变更方向）

入口：菜单「订单管理 → 周期订购计划」（路由 /subscriptions，权限码 SUBSCRIPTION_READ / SUBSCRIPTION_WRITE）

跳转：计划详情（用户 / 商品 / 周期 / 下次配送）

对应用户端：用户端入口本期不开发（继续暂缓；F-ORD-026 后台侧已实现）

布局结构

  1. 筛选 / 分页
  2. 计划表格：用户 + 商品摘要 + 周期规则 + 下次配送时间 + 状态 + 操作
  3. 状态标签：生效中 / 已暂停 / 已终止；生成失败计划展示 lastError（不静默）

关键交互

  1. 新建计划：绑定用户 + 收货地址 + 可选绑定送水工（商品/周期/时段/生效与终止条件）
  2. 筛选 / 分页查看周期订购计划
  3. 查看用户计划（商品 / 周期 / 下次配送 / 状态 / lastError）
  4. 暂停 / 恢复 / 终止（终止后不可恢复，需新建）

状态与规则

空态：「暂无周期订购计划」；加载态：loading；禁用态：已终止计划不提供恢复入口。

到期每日 05:30 调度自动生成「待派单」订单（支付 CASH，幂等键 = 计划 id + 期次）；生成成功提醒送水工（绑定定向 / 未绑定广播）；暂停期间不生成；生成失败记录 last_error、次日重试不推进，单条失败不阻断批次。

地址以生成时快照（后续地址簿变更不影响已生成订单，R-MON-02 快照原则）；生成订单与支付超时 / 取消解耦。

设计要点 / 禁忌

本页 已实现（2026-10-11 恢复开发并变更方向：入口仅管理后台、到期自动生成订单、提醒送水工而非用户）；缺口 G77 残余为用户端入口未开发。

管理端不出现强调橙：主操作用品牌蓝；生效中用成功绿、已暂停用 warning、已终止用中性灰。

列表可筛选分页；后台可新建/查看/暂停/恢复/终止周期订购计划，但不得静默失败（lastError 必须可见）。

开放问题：「自动下单 vs 仅提醒」默认值（2026-10-11 新方向取消：恒为自动下单，不做「仅提醒」模式）。
