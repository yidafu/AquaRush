页面说明

所属端：管理后台（Ant Design 5）

入口：左侧菜单「订单管理」

跳转：点订单 → 订单详情；「批量派单」→ 派单弹窗；「导出」→ 导出弹窗（F-ORD-030 规划）

权限：导出受独立权限码 ORDER_EXPORT（规划）约束，无权限时隐藏 / 禁用

布局结构

  1. 顶部筛选栏：订单号 / 用户 / 状态 / 下单时间范围 / 配送人 / 是否自提 / 支付方式
  2. 顶部操作区：多选批量操作条「批量派单 / 导出」+ 取消选择
  3. 订单表格：多选列 + 订单号 + 用户 + 商品摘要 + 金额 + 配送费 + 状态 + 配送人 + 下单时间 + 操作
  4. 分页器

关键交互

  1. 设置筛选条件 → 查询
  2. 多选订单 → 「批量派单」→ batchAssignOrders（前置状态 = 待派单）
  3. 点「导出」→ 按当前筛选生成导出任务
  4. 单行「派单」→ 打开派单弹窗；「取消」→ Popconfirm 确认

状态与规则

状态列展示 7 态：待付款 / 待派单 / 待配送 / 配送中 / 已完成 / 已取消 / 已退款（映射见页底图例）。

空态：无匹配数据；加载态：加载中；禁用态：无导出权限时隐藏导出按钮。

批量派单仅对「待派单」订单有效；已完成 / 已取消 / 已退款订单不提供取消与派单入口。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝、取消等危险操作用语义 error 色。

订单状态一律用「10% tint 底 + 状态色文字」的 .tag-*，不得自造颜色；金额一律 ¥0.00。

导出入口为 F-ORD-030 规划（缺口 G86），落地形态见 order-export.html。
