页面说明

所属端：管理后台（目标形态）

入口：订单列表顶部操作区「导出」按钮

效果：生成导出任务 → 下载链接 / 自动下载

权限：受独立权限码 ORDER_EXPORT（规划）约束，无权限时按钮隐藏 / 禁用

布局结构

  1. 订单列表顶部「导出」按钮
  2. 导出弹窗：选择导出范围（当前筛选 / 全部）+ 选择字段模板
  3. 异步生成任务 + 进度提示 + 下载

关键交互

  1. 设置筛选 → 点「导出」→ 按筛选条件生成导出任务
  2. 异步生成完成后下载链接 / 自动下载
  3. 导出操作记业务日志（操作人 / 条件 / 条数）

状态与规则

空态：无匹配数据提示「无可导出数据」；加载态：「导出中，请稍候」进度；错误态：「导出失败」message；禁用态：无导出权限时按钮隐藏 / 禁用。

导出内容与筛选结果一致；导出条数上限（如 5 万条，超限分批或拒绝，开放问题）；金额以元两位小数（R-MON-01）。

设计要点 / 禁忌

本页为 ，缺口 G86（商品导出见 G20）。

管理端不出现强调橙：主操作用品牌蓝、失败 / 无数据用语义 warning / error 色。

敏感字段（顾客手机号）导出前必须脱敏，先脱敏再输出并留痕；导出为只读快照，不改变数据。

开放问题：导出字段模板与条数上限、敏感字段脱敏范围、独立导出权限码落地。
