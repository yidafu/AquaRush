页面说明

所属端：管理后台

入口：订单列表「批量派单」/ 单行「派单」、订单详情「派单」

效果：assignDeliveryWorker（单）/ batchAssignOrders（批量）

权限：派单前置状态 = 待派单

布局结构

  1. 弹窗标题「派单 / 批量派单」
  2. 送水工在线列表：姓名 / 在线状态 / 当前任务数 / 今日完成数
  3. 选择送水工（按单指派 = 单选；批量指派同一人 = 多单共享）
  4. 确认 / 取消

关键交互

  1. 单派单：选择一名送水工 → 确认 → assignDeliveryWorker
  2. 批量派单：订单列表多选 → 批量派单弹窗 → batchAssignOrders
  3. 仅可派给在线且可接单的送水工；离线 / 忙碌不可选

状态与规则

派单后订单置「待配送」；送水工显式「开始配送」才进入「配送中」。

同一订单仅能派单一次，二次派单被状态拦截；派单与抢单并发先到先得（幂等）。

批量派单仅对「待派单」订单有效；非待派单行不可勾选。

设计要点 / 禁忌

管理端不出现强调橙：主操作「确认派单」用品牌蓝；在线 / 忙碌 / 离线用语义状态色。

派单弹窗为 Modal（AssignDeliveryModal），单 / 批量两种形态共用一套在线列表。

重复派单拦截为后端状态机保证，前端以禁用行与提示文案呼应，不得仅靠前端拦截。
