页面说明

所属端：管理后台（代客下单，与送水工端同链路）

入口：订单管理 → 代客下单

去向：提交后订单落入「待派单」

权限：下单后由后台派单或送水工抢单

布局结构

  1. 客户信息 / 收货地址卡（姓名 / 手机号 / 详细地址 / 楼层）
  2. 商品多选清单：多选添加 + 行内数量步进器（小计实时计算）
  3. 自提开关（开启免运费、记录已收款）+ 收款方式单选（默认现金）
  4. 手动改价（目标形态）+ 右栏订单摘要与提交后流转

关键交互

  1. 多选添加商品 + 调整数量（items 多商品，同一商品不可重复）
  2. 选自提 → 免运费、记录为已收款
  3. 填手动改价 → 仅作用于订单层实收金额并留痕
  4. 提交 → 订单进入「待派单」

状态与规则

禁用态：未选商品时提交禁用；无地址 / 无商品时提交禁用。

约束：items-only（orders 删除 product_id / quantity 列）；同一商品不可重复；自提订单免运费；数量 ≤ 库存。

代客下单默认收款方式 CASH（R-PAY-03）；自提订单 paymentTime = 下单时间。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝、金额一律 ¥0.00。

手动改价为订单层兜底（F-ORD-023 部分实现）——单价链「手动实收价」未接入统一取价服务，属开放问题；改价须留痕且不改目录价。

代客下单不进入微信支付，收款方式默认现金（或水票 / 扫码）。
