页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 营收统计」；路由 statistics

跳转：无（只读）

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 日期粒度 + 支付方式 + 配送方式 + 导出
  2. 汇总卡第一行（三卡）：营收总额 / 商品营收 / 配送费
  3. 汇总卡第二行（三卡）：押金 / 退款金额 / 客单价
  4. 营收 / 净营收 / 退款趋势折线（内联 SVG）
  5. 构成区两列：营收构成占比 · 按支付方式 / 配送方式构成 · 退款与净营收口径
  6. 明细表格（按粒度行）+ 分页

图表规格

图表类型：折线图（营收 / 净营收 / 退款，内联 SVG）· 横向条形占比（营收构成 / 支付方式 / 配送方式）

X-Y 轴：X = 日/周 MM-DD、月 YYYY-MM；Y = 金额（¥ 元，分→元两位小数）

指标口径：营收 = 已完成订单金额合计（completed_at）；净营收 = 营收 − 退款；退款 = payment_refunds COMPLETED 且 ORDER_REFUND（按 processed_at）；押金退还 DEPOSIT_REFUND 不计入；多商品订单金额按订单只计一次

时间范围：今日 / 本周 / 本月 / 自定义；粒度切换自动重置（日=近 30 天、周=近 12 周、月=近 1 年），禁用未来日期

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 挂载即按当前粒度查询（默认按日 + 近 30 天），汇总与趋势联动
  2. 切换日/周/月粒度 → 重置默认时间范围并 refetch
  3. 选择时间范围 → 格式化 startDate/endDate 传入并 refetch
  4. 失败整页 Alert「数据加载失败」+ error.message + 重试按钮
  5. 空态：无日期行 → 汇总卡 0、图表 Empty「所选范围暂无数据」

设计要点 / 禁忌

管理端不出现强调橙：图表主色品牌蓝 var(--brand)，净营收用浅蓝虚线，退款用语义红 var(--st-cancel-fg)。

营收总额仅计已完成订单，已取消/已退款/未完成不计入；金额一律「元」两位小数（R-MON-01）。

退款率在营收为 0 时显示「—」，不报错；净营收可如实为负，禁止钳 0。

统计导出：按当前筛选与粒度生成文件。
