页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 商品统计」；路由 statistics/products

跳转：「阈值配置」→ 系统设置-库存预警阈值 /system-config/stock（F-SYS-003）

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 维度 + 商品 + 规格 + 导出
  2. KPI 第一行（三卡）：在售商品数 / 总销量 / 总销售额
  3. KPI 第二行（三卡）：缺货商品数 / 库存周转 / 商品总数
  4. 图表区两列：商品销量排行 TOP10 柱状图 · 规格维度占比（.hbar）
  5. 库存预警明细表格（商品 / 规格 / 销量 / 销售额 / 库存 / 状态）

图表规格

图表类型：柱状图（销量 TOP10）· 横向条形占比（规格维度）· 表格（销量排行 / 库存预警明细）

X-Y 轴：柱状 X = 商品名（超 10 字截断加「...」）、Y = 销量（桶）

指标口径：销量 = 窗口内商品销量；销售额 = 营收（分→元两位小数）；低库存预警 = 0 < 库存 ≤ 阈值（默认 10）；缺货 = 库存 0；总收藏数按收藏数聚合

时间范围：今日 / 本周 / 本月 / 自定义（默认近 30 天）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 挂载并发查询统计、日销量趋势与商品下拉数据源
  2. 选择商品或时间范围 → refetch → 刷新趋势图（选中商品按 productId 过滤）
  3. 销量排行 / 规格占比取排行榜数据渲染
  4. 库存预警明细：缺货置顶、按库存升序；「阈值配置」跳转系统设置
  5. 低库存预警计数 > 0 带上升 trend 标识；失败「加载失败: {statsError.message}」

设计要点 / 禁忌

管理端不出现强调橙：柱状图与条形一律品牌蓝 var(--brand)。

低库存预警计数与预警明细表同源同口径（阈值默认 10）；库存 = 0 归「缺货」并置顶，0 < 库存 ≤ 阈值 归「预警」。

库存着色仅作用于在售/库存维度，不影响下架商品；商品名超 10 字截断加「...」。

统计导出：按当前筛选生成文件。
