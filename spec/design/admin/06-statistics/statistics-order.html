页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 订单统计」；路由 statistics/orders

跳转：无（只读）

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 日期粒度 + 订单状态 + 配送区域 + 导出
  2. KPI 第一行（三卡）：订单总数 / 完成率 / 取消率
  3. KPI 第二行（三卡）：退款率 / 平均履约时长 / 已完成订单
  4. 订单与营收趋势：柱状（订单数）+ 折线（营收）叠加
  5. 分析区两列：订单状态分布（.hbar）· 客单价分布（.hbar）
  6. 高峰时段分析（.bars，0-23 时）· 商品/区域维度拆分表格

图表规格

图表类型：柱状 + 折线叠加（订单与营收趋势）· 横向条形（状态/客单价分布）· 柱状（高峰时段 0-23 时）

X-Y 轴：趋势 X = 日/周 MM-DD、月 YYYY-MM，左 Y = 订单数（单）、右 Y = 营收（¥）；时段 X = 小时 0-23、Y = 订单创建量

指标口径：订单数按 created_at；营收按已完成订单金额（completed_at）；状态 = 所选范围全部订单按态聚合（OrderModelStatus.entries 补零）；客单价按 amountCents 分桶只计一次；时段按 created_at 小时聚合（Asia/Shanghai）

时间范围：今日 / 本周 / 本月 / 自定义；粒度联动（日=近 30 天、周=近 12 周、月=近 1 年）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 默认「按日」+ 近 30 天；切换粒度重置时间范围并 refetch
  2. 三分析卡随汇总查询一并下发，随粒度 / 时间范围联动刷新
  3. 高峰柱显示最大小时并标注「高峰时段: X 时 (n 单)」
  4. 空态：卡片 0、折线无数据点；三分析卡仍渲染真实 0 值图表，不用空态占位
  5. 失败「加载失败: {error.message}」

设计要点 / 禁忌

管理端不出现强调橙：柱状品牌蓝 var(--brand)，折线用深湖蓝 var(--brand-dark) 以区分双系列。

「已完成订单」卡必须取 completedOrders，不得复用 totalOrders；营收总额仅计已完成订单。

三分析卡无数据时仍渲染真实 0 值图表；金额统一「元」两位小数。

统计导出：按当前筛选与粒度生成文件。
