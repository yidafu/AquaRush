页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 送水工统计」；路由 statistics/delivery-workers

跳转：无（只读）

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 在线状态 + 配送站 + 导出
  2. KPI 第一行（三卡）：在岗送水工 / 完成总单数 / 平均单量
  3. KPI 第二行（三卡）：好评率 / 平均配送时长 / 送水工总数
  4. 图表区两列：送水工工作量排行柱状图 · 好评率分布（1~5 星 .hbar）
  5. 送水工排行榜表格（姓名 / 完成单数 / 桶数 / 收款额 / 好评率 / 平均时长 / 在线状态）

图表规格

图表类型：柱状图（工作量排行 Top10）· 横向条形占比（好评率 1~5 星）· 表格（排行榜）

X-Y 轴：柱状 X = 送水工姓名（Top10）、Y = 今日完成订单数（单）

指标口径：完成 = 当日已完成订单（completed_at，送达即完成）；平均单量 = 完成总数 ÷ 在岗人数；平均履约时长 = Σ(完成时间 − 派单时间) ÷ 完成订单数；好评率 = rating × 100%

时间范围：今日 / 本周 / 本月 / 自定义（排行柱状固定当日口径）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 挂载并发查询概览与排行（Top10），前 10 生成柱状图与表格
  2. 切换时间范围 / 在线状态 / 配送站 → refetch → 卡片与图表联动
  3. 效率指标无数据时显示「—」而非 0（人均单量与平均履约时长）
  4. 查询失败显示「加载失败: {error.message}」
  5. 空态：柱状图空、表格空，效率卡显示「—」

设计要点 / 禁忌

管理端不出现强调橙：柱状图与条形一律品牌蓝 var(--brand)。

好评率无评价数据时显示 0.00% 或空，须有数据源缺失说明；人均单量/平均履约时长无数据时显示「—」。

当前排序固定按「今日完成订单」降序，列头切换排序标目标形态。

排行榜列头切换排序、统计导出。
