页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 用户统计」；路由 statistics/users

跳转：无（只读）；如需下钻用户详情标目标形态

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 用户维度 + 下单次数 + 导出
  2. KPI 第一行（三卡）：总用户数 / 新增用户 / 活跃用户
  3. KPI 第二行（三卡）：复购率 / 平均下单次数 / 本月新增
  4. 新增与活跃趋势折线（内联 SVG，双线）
  5. 下单次数分布（.hbar）+ 下单用户指标列
  6. 用户 TOP 榜表格（昵称 / 订单数 / 消费额 / 最近下单）+ 分页

图表规格

图表类型：折线图（新增与活跃，内联 SVG）· 横向条形占比（下单次数分布）· 表格（TOP 榜）

X-Y 轴：折线 X = 日期 MM-DD（近 30 天固定）、Y = 用户数（人）

指标口径：新增 = 当日新增用户；活跃 = 近 30 天下单用户去重；复购率 = 下单 ≥ 2 次 ÷ 下单用户；占比 = 下单用户 ÷ 总用户；平均下单次数 = 订单总数 ÷ 下单用户数

时间范围：今日 / 本周 / 本月 / 自定义（趋势图固定近 30 天）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 挂载发起单查询，返回后回填六张数字卡
  2. 切换时间范围 / 维度 → refetch → 卡片与图表联动刷新
  3. 下单用户分布按近 30 天下单用户按 userId 去重分层
  4. 今日新增 > 0 时带上升 trend 标识；查询失败整页「加载失败: {error.message}」
  5. 空态：卡片值 0、图表无数据点、分布图空

设计要点 / 禁忌

管理端不出现强调橙：新增用品牌蓝 var(--brand)，活跃用浅蓝 var(--brand-light) 虚线。

占比 / 复购率两位小数；总用户或下单用户为 0 时比率显示 0，不报错。

累计登录非历史全量，与登录趋势同为近 30 天窗口，文案须避免歧义。

统计导出：按当前筛选生成文件。
