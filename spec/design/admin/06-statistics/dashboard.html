页面说明

所属端：管理后台（React + Ant Design 5）

入口：登录后台默认首页；左侧菜单「数据统计 → 仪表盘」；路由 dashboard

跳转：待处理事项各卡 → 订单管理 / 派单中心 / 照片核验 / 日报确认 / 差异申诉；本页无子页

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围切换（今日 / 本周 / 本月 / 自定义）+ 维度筛选 + 导出
  2. KPI 卡区（一行四卡）：今日订单数 / 今日营收 / 待派单数 / 配送中数
  3. 待处理事项卡：待派单 N / 待核验照片 N / 待确认日报 N / 差异申诉 N，各带跳转
  4. 图表区两列：近 7 日订单量柱状图 · 近 7 日营收趋势折线
  5. 分析区两列：订单状态分布（.hbar）· 热销商品 TOP5（.hbar）

图表规格

图表类型：柱状图（近 7 日订单量）· 折线图（营收趋势，内联 SVG）· 横向条形占比（订单状态分布 / 热销 TOP5）

X-Y 轴：柱状 X = 日期 MM-DD、Y = 订单数（单）；折线 X = 日期 MM-DD、Y = 营收（¥ 元，分→元两位小数）

指标口径：营收 = 已完成订单金额合计（按 completed_at 归属，送达即完成）；订单数 = 全部订单按下单时间 created_at 归属；待处理 = 存量快照，不设环比

时间范围：今日 / 本周 / 本月 / 自定义（禁用未来日期）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT 预留码）

关键交互

  1. 挂载即查询，默认近 30 天；窗口向前扩展以覆盖昨日与上月同期环比基准
  2. 切换预设或自定义范围 → 重查 → 两张趋势图与数字卡联动刷新
  3. 数据返回后取切片末条日数据回填「今日订单 / 今日营收」
  4. 待处理事项由存量快照查询，挂载仅取一次，与日期窗口无关
  5. 环比：上升红色向上箭头，下降绿色向下箭头；上期为 0 且本期 > 0 显示「—」

设计要点 / 禁忌

管理端不出现强调橙：图表主色用品牌蓝 var(--brand)，对比系列用浅蓝 var(--brand-light)。

营收一律带「元」后缀两位小数；订单数为整数，不混用单位。增长用 .up（红）、下降用 .down（绿）。

待处理订单为存量指标，不设环比，避免误导。

统计导出（PERMISSION_STATISTICS_EXPORT）：按当前筛选生成文件。
