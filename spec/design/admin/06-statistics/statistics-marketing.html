页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「数据统计 → 营销统计」；路由 statistics/marketing

跳转：明细行「详情」→ 对应营销活动详情页 /marketing/{coupons|promotions|newcomer|buy-gift|water-tickets}/:id

权限：PERMISSION_STATISTICS_READ；导出 PERMISSION_STATISTICS_EXPORT（目标形态）

布局结构

  1. 筛选区：时间范围（今日 / 本周 / 本月 / 自定义）+ 营销玩法 + 刷新方式（手动 / 定时）+ 导出
  2. KPI 第一行（三卡）：优惠券领取量 / 核销率 / 优惠金额合计
  3. KPI 第二行（三卡）：水票销售张数 / 活动带动订单数 / 赠品数量
  4. 优惠券核销趋势折线（内联 SVG，领取 / 核销双线）
  5. 构成两列：营销方式构成（.hbar）· 营销订单与用券趋势（柱 + 线叠加）
  6. 营销方式使用明细：Segmented 切换（优惠券 / 满减折扣 / 首单立减 / 买赠满赠 / 桶水票）+ 效果对比表格

图表规格

图表类型：折线图（核销趋势 / 水票销售与核销）· 柱 + 线（营销订单与用券）· 横向条形占比（营销方式构成）

X-Y 轴：X = 日期 MM-DD（日粒度）；Y = 张数 / 金额（¥ 元，两位小数）/ 订单数（单）

指标口径：优惠金额 = 券 + 满减 + 首单立减 三快照优惠列（精确）；营销订单按订单去重（任一快照列 > 0）；用券 = user_coupons USED 按 used_at；水票销售 = ticket_purchases PAID 按 paidAt、核销 = user_tickets USED 按 usedAt；赠品优惠 = 件数 × 当前目录价（估算）

时间范围：今日 / 本周 / 本月 / 自定义（默认近 30 天、日粒度、禁用未来日期）

导出：无（目标形态，PERMISSION_STATISTICS_EXPORT）

关键交互

  1. 挂载发起单查询（默认近 30 天）
  2. 切换时间范围 → refetch → 汇总卡 / 图表 / 明细表联动刷新
  3. 明细表切换 Segmented → 前端按 kind 过滤展示该玩法区间使用记录
  4. 行「详情」→ 跳转对应活动详情页
  5. 失败整页 Alert「数据加载失败」+ error.message + 重试；空态汇总卡 0、图表 Empty

设计要点 / 禁忌

管理端不出现强调橙：折线品牌蓝 var(--brand)，核销对比用浅蓝虚线，柱线叠加折线用深湖蓝。

让利总额 = 券 + 满减 + 首单立减 三快照列合计（精确），不含赠品估算与桶水票抵扣，页面须明示。

营销订单数由每日事实独立聚合，不能由明细求和得出；明细优惠金额须区分口径（快照精确 / 赠品估算带说明）。

统计导出：按当前筛选生成文件。
