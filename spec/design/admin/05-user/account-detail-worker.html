页面说明

所属端：管理后台（React + Ant Design 5）

入口：账号列表行「详情」（送水工角色）／顶部「← 返回账号列表」

路由：/users/accounts/:id，与管理账号同路由按角色渲染

权限：送水工视图无「账号安全」「操作」Tab（与管理员视图 8 Tab 的差异点）

布局结构

  1. 返回栏：← 返回账号列表
  2. 基本信息卡：头像 / 账号 / 姓名 / 工号 / 在线状态 / 当前任务数 / 状态
  3. Tabs（6 个，默认「基本信息」）：基本信息 · 统计 · 配送记录 · 配送轨迹 · 每日收款 · 评价记录
  4. 「统计」Tab：完成单数 / 收款金额 / 平均评分 / 总评价数 + 1~5 星分布（.hbar）
  5. 配送记录为单表格 + Tab 内「订单状态」下拉筛选

关键交互

  1. 进入 → 加载基本信息 / 统计 / 配送记录 / 配送轨迹 / 每日收款 / 评价记录，默认「基本信息」，Tab 切换按需加载
  2. 配送记录按「订单状态」（全部 / 送货中 / 待派送 / 已完成）筛选，切换即重新请求
  3. 删除 / 重置在列表行操作完成（详情页送水工视图无「操作」Tab）

状态与规则

空态：无轨迹空态；无日报 / 无评价空态；详情加载失败「加载失败」+「返回账号列表」。

加载态：Spin loading；错误态：「无法获取送水工信息」；禁用态：提交 loading。

标签：在线状态 / 账号状态标签；评分分布 1~5 星；「当前任务数」为待配送订单数。

开放问题：「收入」口径待确认；在线状态为静态字段，目标接入实时状态同步。

设计要点 / 禁忌

使用 Tab 布局（2026-09 由纵向区块改为 Tab）；送水工视图无「账号安全」「操作」Tab。

配送记录为单表格 + Tab 内「订单状态」下拉筛选（非多 Tab）。

管理端不出现强调橙；金额分转元（¥0.00 口径）；好评率用语义绿。
