页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「用户管理 → 账号」

跳转：行「详情」→ /users/accounts/:id（按角色渲染管理员 / 送水工两套 Tab）

权限：超管可见全部账号；普通管理员仅见配送能力账号（R-AUTH-04）

布局结构

  1. 页头：标题「账号列表」+「用户类型」下拉 +「新增管理员」/「新增送水工」按钮
  2. 筛选卡：关键词 · 用户类型 · 角色 / 在线状态 · 状态
  3. 管理员视角列：账号 / 姓名 / 角色 / 状态 / 兼送水标记 / 创建时间 / 操作
  4. 送水工视角列：账号 / 姓名 / 工号 / 在线状态 / 今日完成单数 / 今日收款 / 状态 / 操作
  5. 操作列：管理员「详情·编辑·重置密码·删除」；送水工「详情·编辑·停用·重置密码·删除」

关键交互

  1. 「用户类型」下拉切换即过滤（全部 / 超级管理员 / 管理员 / 送水工；兼送水管理员视图含「兼送水管理员」）——不使用 Tab
  2. 新增 / 编辑 → 表单弹窗 → message「管理员创建成功」「管理员更新成功」→ refetch
  3. 删除 → Modal.confirm「确定要删除管理员 X 吗？此操作不可恢复。」（送水工同款文案）→ 软删除
  4. 重置密码 → ResetPasswordModal（新密码可留空 = 默认 123456）→「密码重置成功」
  5. 停用 / 启用 → 二次确认 → 账号无法登录且旧 token 立即失效

状态与规则

空态：列表为空；加载态：Table loading；错误态：「操作失败」/「删除失败」；禁用态：提交 loading 期间禁用。

标签：角色 超级管理员（品牌蓝）/ 普通管理员（中性灰）/ 送水工；状态 正常绿 / 已停用红；在线状态 在线绿 / 离线灰。

删除保护：不能删自己、不能删最后一个超管；停用送水工不可派单 / 接单。

设计要点 / 禁忌

列表页不使用 Tab：管理员与送水工共用同一页，仅「用户类型」过滤视图不同（合并为同一列表）。

送水工档案已并入 admins 单表（2026-08 迁移 v1.2.1），不再有 delivery_workers 表；无自助注册入口。

管理端不出现强调橙；权限隔离须服务端强制，前端隐藏不作为隔离手段。

金额分转元（¥0.00 口径）；仅超管可进入本页 / 增删改管理员。
