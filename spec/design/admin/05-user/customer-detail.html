页面说明

所属端：管理后台（React + Ant Design 5）

入口：用户列表行「详情」／「← 返回用户列表」回到列表

路由：/users/:id；顶部为返回栏 + 基本信息卡 + 统计卡

权限：用户只读 + 营销（优惠券 / 水票）只读

布局结构

  1. 返回栏：← 返回用户列表
  2. 基本信息卡：头像 / 用户ID / 昵称 / 手机号 / 微信OpenID / 用户角色 / 账户状态 / 所属客户分组 / 邮箱 / 总消费金额 / 最近下单时间 / 注册时间 / 最后更新（无账户余额项——用户储值不做，2026-10-09 决策）
  3. 统计卡（全量口径）：总订单数 / 总消费金额 / 已完成订单 / 平均客单价
  4. Tabs（7 个，默认「收货地址」）：收货地址 · 订单记录 · 优惠券 · 水票 · 意见反馈 · 评价记录 · 收藏商品
  5. 各 Tab 独立查询、独立空态、互不影响

关键交互

  1. 进入 → 加载基本信息卡 + 统计卡 + 默认「收货地址」；切换 Tab 按需加载
  2. 订单记录：订单状态筛选 + 分页，可下钻订单详情
  3. 优惠券 / 水票：状态筛选 + 分页；意见反馈 / 评价记录 / 收藏商品各自分页
  4. 金额分 → 元展示

状态与规则

空态（逐 Tab 独立）：暂无收货地址 / 该用户暂无订单记录 / 该用户暂无优惠券 / 该用户暂无桶水票 / 该用户暂无意见反馈 / 该用户暂无评价记录 / 该用户暂无收藏商品。

加载态：Table / Spin loading；错误态：详情整体失败「加载失败」+「返回用户列表」，单个 Tab 失败仅区块内提示，不整页失败；禁用态：提交 loading。

统计卡口径（2026-09 修正）：总订单数 / 已完成订单 / 总消费金额均为全量口径，不随分页变化；平均客单价 = 总消费 ÷ 总订单（除零为 0）。

设计要点 / 禁忌

使用 Tab 布局（2026-09 决策，PRD v0.15「详情页纵向区块」表述作废，禁止纵向堆叠）。

所属客户分组为空显示「未分组」；微信OpenID 截断展示；手机号脱敏。

管理端不出现强调橙；评价星级用语义 warn 色；订单状态沿用标色映射（待付款橙 / 配送中绿 / 已完成灰 / 已取消红）。

优惠券 / 水票归属 10-marketing 与桶水票域，本页仅只读查询展示。
