页面说明

所属端：管理后台（React + Ant Design 5）

入口：账号列表行「详情」（管理账号角色）／顶部「← 返回账号列表」

路由：/users/accounts/:id，与送水工视图同路由按角色渲染

权限：超管可见「操作」Tab；普通管理员仅见配送能力账号范围（R-AUTH-04）

布局结构

  1. 返回栏：← 返回账号列表
  2. 基本信息卡：头像 / 账号 / 姓名 / 角色 / 权限信息（权限码标签墙）/ 兼送水标记 / 状态
  3. Tabs（8 个，默认「基本信息」）：基本信息 · 账号安全 · 配送能力 · 配送记录 · 配送轨迹 · 每日收款 · 评价记录 · 操作
  4. 配送能力 / 配送记录仅兼送水管理员展示；操作 Tab 仅超管视角
  5. 配送记录为单表格 + Tab 内「订单状态」下拉筛选

关键交互

  1. Tab 切换按需加载对应区块，默认「基本信息」
  2. 配送记录按「订单状态」（全部 / 送货中 / 待派送 / 已完成）筛选，切换即重新请求
  3. 重置密码 → ResetPasswordModal（可留空 = 默认 123456）
  4. 停用 / 启用 → 二次确认；停用后无法登录、旧 token 失效
  5. 删除 → Modal.confirm → 软删除（超管保护）

状态与规则

标签：账号状态 正常绿 / 已停用红；最后登录时间未登录时展示「从未登录」；在线状态 / 接单权限标签；评分分布 1~5 星。

空态：无轨迹空态；无日报 / 无评价空态。

加载态：Spin loading；错误态：操作失败 message；禁用态：提交 loading 期间禁用。

权限信息：由角色推导——超管全权限；普通管理员 = 配送能力账号范围；兼送水含 DELIVERY_TASK；删除 / 重置密码仅超管。

设计要点 / 禁忌

详情页使用 Tab（2026-09 由纵向区块改为 Tab 布局，禁止纵向堆叠）。

「配送能力 / 配送记录」仅兼送水管理员展示；「操作」Tab 仅超管视角。原弹窗 AdminDetailModal 已移除，统一为独立详情页。

管理端不出现强调橙；金额分转元（¥0.00 口径）；删除用语义 error 色。
