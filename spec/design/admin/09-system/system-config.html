页面说明

所属端：管理后台（React + Ant Design 5）

入口：系统设置 → 系统参数；路由 system-config/parameters；仅超级管理员可见（管理员菜单不可见、接口返回 FORBIDDEN — R-SYS-03）

权限：SYSTEM_CONFIG_READ / SYSTEM_CONFIG_WRITE

状态：规划中 目标形态为「参数中心 + 业务消费 + 审计闭环」。

布局结构

  1. 参数分组导航（Tabs）：「安全」「通知」「数据维护」「修改记录」；订单与履约、库存两组在独立页面配置（F-SYS-002 / F-SYS-003），本页不重复展示
  2. 分组卡片（基础参数 / 业务参数 / 展示参数）逐字段：参数名 + 键 + 类型 + 当前值控件 + 说明 + 修改人 / 修改时间
  3. 参数列表（Table）：参数名 / 键 / 类型 / 当前值 / 说明 / 修改人 / 修改时间 + 操作「编辑」「恢复默认」
  4. 编辑弹窗（Modal）：按声明类型渲染控件
  5. 「修改记录」页签：时间 / 操作人 / 旧值 / 新值

关键交互

  1. 进入页面 → 按组加载参数列表
  2. 编辑 → 按声明类型校验 → 保存 → 按声明热生效
  3. 恢复默认 → 二次确认「确定恢复默认值吗?」→ 回默认值
  4. 「修改记录」页签可查审计日志

状态与规则

空态：组内无参数空态；加载态：列表 / 保存 loading；错误态：保存失败 toast；禁用态：无 SYSTEM_CONFIG_WRITE 权限时只读（仅超管可写）。

类型 Tag：数值 / 布尔 / 文本 / 枚举。

校验：「参数值格式不正确」「参数值超出范围」；值按声明类型校验（数值区间 / 布尔 / 枚举 / 长度），整数型限区间。变更不追溯已生成业务数据（R-SYS-01）。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，恢复默认等敏感动作二次确认，密钥类参数用 warning 提示保护。

值与控件须按声明类型渲染（数值 / 开关 / 文本 / 枚举），不得一律用文本框。

密钥类参数（微信 / 支付 / DB 口令等）不得出现在本页（R-SYS-02），后端不回显明文、前端展示掩码。

缺口 G64：批量修改、参数导入导出；孤儿种子键 bucket_deposit_amount 清理（G06）。「参数导入 / 导出」按钮现状为禁用占位。
