页面说明

所属端：管理后台（React + Ant Design 5）

入口：系统设置 → 账号与安全；路由 system-config/security；仅超级管理员可见

下游：「日志管理 → 用户操作日志」承接登录日志检索

状态：规划中（目标形态）

布局结构

  1. 密码策略分组：最小长度 / 字母数字混合 / 有效期 / 历史密码不可重用次数
  2. 登录安全分组：失败锁定次数 / 锁定时长
  3. Token 有效期分组（重启生效提示）：Token 有效期
  4. 敏感操作二次确认范围（目标形态）
  5. 登录日志查询入口 + 保存按钮 + 修改记录

关键交互

  1. 回显当前策略 → 修改 → 确认保存 → 新策略生效（登录校验类即时、Token 类重启生效）
  2. 点「查询登录日志」→ 跳转日志管理并带账号 / 时间条件
  3. 敏感操作范围开关变更后，对应操作弹出二次确认

状态与规则

加载态：回显 / 保存 loading；错误态：保存失败 toast；禁用态：无权限只读；重启生效提示：Token 有效期字段旁提示「重启生效」。

校验：「参数无效」（最小长度 6-32、锁定次数 1-99、锁定时长 > 0）。

生效提示：「登录校验即时生效」「Token 有效期重启生效」。

设计要点 / 禁忌

管理端不出现强调橙：敏感配置用 warning 色提示保护（重启生效 Tag、敏感操作范围卡），主操作用品牌蓝。

区分即时生效（登录校验类）与重启生效（Token 类），字段旁须明示生效时机。

密钥 / 证书类不在此页在线修改（R-SYS-02）。

缺口 G64、G49（权限强制配套）。现状登录校验简化（无强度 / 锁定策略），Token 有效期配置于 application.yml。开放问题：是否引入双因子 / 验证码登录（现状按不引入设计）。
