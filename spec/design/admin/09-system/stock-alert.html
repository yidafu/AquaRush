页面说明

所属端：管理后台（React + Ant Design 5）

入口：系统设置 → 库存预警阈值；路由 system-config/stock；仅超级管理员可见

反向入口：商品统计（F-STA-006）库存预警明细「阈值配置」跳转本页

状态：规划中（目标形态）

布局结构

  1. 全局默认阈值卡：低库存阈值（默认 10）+ 缺货阈值（0）
  2. 预警色阶档位卡：红 <X（默认 10）/ 橙 <Y（默认 50）/ 绿 ≥Y（派生）
  3. 预警通知方式卡：站内消息（默认启用）/ 订阅消息（默认停用）
  4. 按商品覆盖阈值表：商品 / 规格 / 当前库存 / 应用阈值 / 状态 / 操作
  5. 关联说明区（消费方说明）+ 预警记录表

关键交互

  1. 进入页面 → 回显默认阈值（10）
  2. 修改 → 确认保存 → 商品列表库存着色与低库存预警明细按新阈值刷新
  3. 按商品设置覆盖阈值 / 清除覆盖 → 单独商品按覆盖阈值计算
  4. 命中预警按通知方式写站内消息 / 推订阅消息（联动 F-SYS-005）

状态与规则

空态：未配置时按默认阈值展示；加载态：回显 / 保存 loading；错误态：保存失败 toast；禁用态：无权限只读。

规则：阈值 0-99999 整数；色阶档位必须递增（红 < 橙 < 绿）；库存 = 0 视为「缺货」（不属预警档），与 F-STA-006 明细口径一致。

范围：预警仅作用于在售 / 库存维度，不影响下架商品；阈值配置后即时生效（热生效）。

设计要点 / 禁忌

管理端不出现强调橙：色阶用语义 error / warning / success 色文字，主操作用品牌蓝。

校验：「阈值无效」「档位需递增」；绿色档位为派生展示，不可直接编辑。

缺口 G64（阈值后台可配、商品域 / 统计域消费）、G39（阈值配置入口缺失）。现状阈值与色阶硬编码于后台商品列表展示逻辑（无后台入口）。开放问题：色阶是否允许自定义；预警是否联动通知配置（F-SYS-005）。
