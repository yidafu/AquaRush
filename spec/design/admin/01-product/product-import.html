页面说明

所属端：管理后台（目标形态）

入口：商品列表页顶部「快速操作」区「导出数据」「批量导入」按钮（现状为禁用占位）

无独立页面：状态均寄居于 products-list.html 的快速操作区

权限：无导入权限时按钮禁用 / 隐藏（独立权限码为开放问题）

布局结构

  1. 「导出数据」按钮：按当前筛选导出（Excel / CSV）
  2. 「批量导入」按钮 → 导入弹窗：下载模板 → 上传文件 → 字段 / 行校验预览 → 确认导入
  3. 导入结果反馈：成功 N 条、失败 M 条，失败明细可下载

关键交互

  1. 筛选 → 导出 → 按筛选条件生成文件下载
  2. 点「批量导入」→ 下载模板 → 上传 → 校验（必填 / 格式 / 价格精度 / 重复）→ 预览通过 / 失败行 → 确认导入 → 落库并返回结果
  3. 导入留痕（操作人 / 条件 / 条数）

状态与规则

空态：无匹配数据导出提示「无可导出数据」；加载态：导入校验 / 生成 loading；错误态：导入失败给出每行原因（如「第 N 行:价格格式不正确」）；禁用态：无导入权限时按钮禁用 / 隐藏。

校验规则：模板列名 / 必填 / 数值格式（价格元两位、库存非负整数）；同名同规格重复商品的判重策略待定（跳过 / 更新）。

设计要点 / 禁忌

本页为 ，缺口 G20（落地形态），行级校验参照地址批量导入口径 G27。

管理端不出现强调橙：主操作用品牌蓝、失败用语义 error 色。

导入数据须服务端二次校验、不以文件为准；导出为只读快照，不改变数据。

开放问题：判重策略、导入字段范围（是否含图片 / 详情富文本）、导出字段模板、独立导出 / 导入权限码。
