页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「商品管理」

跳转：操作列「详情」/「编辑」→ /products/:id；「新增商品」→ 表单弹窗（宽 800）

权限：PERMISSION_PRODUCT_READ / PERMISSION_PRODUCT_WRITE

表格列与规则

列：商品名称 / 规格 / 价格 / 原价 / 库存 / 销量 / 排序权重 / 状态 / 创建时间 / 操作，各列可排序。

库存着色（R-PRO-02）：< 10 红 · < 50 橙 · ≥ 50 绿。

状态标签：在售绿 / 下架红 / 缺货橙 / 活跃蓝；枚举 ONLINE / OFFLINE / OUT_OF_STOCK。

价格：分 → 元展示；原价用删除线。

关键交互

  1. 筛选变更（关键词 300ms 防抖，其余即时）→ 重新查询
  2. 排序 / 分页变更 → 更新筛选变量重查
  3. 删除 → 二次确认「确定要删除这个商品吗?」→「删除后无法恢复，请谨慎操作。」
  4. 编辑态取消且有未保存修改 → 二次确认「确认取消编辑?」
  5. 价格类字段以元录入、×100 转分提交，回显 ÷100

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝、删除用语义 error 色。

商品表单不含押金字段（押金按桶规格由「押金管理」独立维护），也不再维护商品级配送设置（配送费统一由运营配置 F-OPS-005）。

「导出数据」「批量导入」按钮现状为禁用占位（F-PRO-011 / 缺口 G20）：导出按当前筛选生成文件；导入走「下载模板 → 上传 → 行级校验预览 → 确认导入 → 失败明细可下载」四步。

图集 ≤ 10、证书 ≤ 5；价格以元录入但金额一律分存储（R-MON-01）。

状态与异常

空态：表格空；加载态：表格 loading、保存中「保存中...」；错误态：表单校验 message、提交失败「创建失败」/「更新失败」；禁用态：销量只读、图片上传中禁用提交。
