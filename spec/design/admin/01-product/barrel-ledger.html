页面说明

所属端：管理后台（目标形态）

入口：后台「商品管理 → 押金管理 → 桶账台账」（新增）

跳转 / 下钻：「查看明细」→ 该客户押金记录 / 回收记录

备注：后台「押金管理」已具备押金价目 / 押金记录 / 空桶回收与退押确认，但无按客户的桶账台账视图与导出。

布局结构

  1. 汇总卡：在租总桶数 / 总押金 / 欠桶客户数（统计卡 3 列）
  2. 筛选区：客户（姓名 / 手机号）+ 规格 + 是否有欠桶 / 在租
  3. 台账 Table：客户 / 规格 / 在租桶数 / 欠桶数 / 押金合计 / 押金余额 / 最近变动时间；操作「查看明细」
  4. 顶部「导出台账」按钮

关键交互

  1. 进入页面加载台账（实时聚合）
  2. 筛选 / 排序
  3. 点「导出台账」→ 按筛选条件导出（个人信息列脱敏）→ 下载
  4. 下钻查看某客户押金 / 回收明细

状态与规则

空态：「暂无桶账数据」；加载态：列表 / 导出 loading；错误态：加载 / 导出失败 message；禁用态：—。

数据口径：押金余额 = 押金合计 − 已退押金；欠桶数 = 应回收未回收；台账为实时聚合非独立存储。

退押不计入营收 / 退款统计，走独立押金账本 DEPOSIT_REFUND。

设计要点 / 禁忌

本页为 ，缺口 G87。

管理端不出现强调橙：主操作用品牌蓝、欠桶等异常用语义 error 色。

导出含客户姓名 / 手机号等个人信息，须先脱敏再输出并留痕；导出为只读快照、不改变数据；金额以分计、导出为元两位小数（R-MON-01）。

开放问题：导出独立权限码、导出条数上限。
