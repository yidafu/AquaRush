页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「商品管理」→ 规格 / 水源地配置；商品表单「规格 / 水源地」标签旁「管理」链接直达本页

跳转：新增 / 编辑 / 删除为页内弹窗与二次确认

权限：复用 PRODUCT_READ / PRODUCT_WRITE，不新增权限码

布局结构

  1. Tabs 切换「规格 / 水源地」；顶部说明文案 + 右上「新增」按钮
  2. 选项表格：选项值（Tag）+ 排序号 + 状态（启用 / 禁用 Tag）+ 创建时间；操作编辑 / 删除
  3. 新增 / 编辑弹窗：选项值（1–100 字符必填，同类型内唯一）+ 排序号（缺省排末尾）+ 启用开关
  4. 商品表单联动区：规格必选 Select showSearch / 水源地可选 allowClear

关键交互

  1. 配置页加载：单页单请求，一次取回两类全量选项（含禁用项）
  2. 新增 / 编辑 / 删除 → 保存 / 二次确认 → 列表刷新，商品表单下拉即时更新
  3. 禁用选项：不在商品表单下拉展示；已使用该值的商品回显不受影响（当前值兜底补入）
  4. 删除选项：仅移除候选，商品上已保存的值不受影响（快照值保留）

状态与规则

空态：「暂无配置选项,点击右上角『新增』添加」；加载态：列表 / 保存 loading；错误态：保存失败 message「选项值在同类型内已存在」；禁用态：已禁用选项在商品表单不出现。

二次确认文案：「确定删除该选项吗?」「删除后商品表单下拉不再展示;已引用该值的商品不受影响」。

启用项排序按 sortOrder 升序；桶水票「适用规格」沿用商品 specification 值，不因字典变更改变口径。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝、删除用语义 error 色。

禁用 / 删除仅影响候选列表，不影响商品已保存属性值（商品维度 value 独立存储）—— 这是本页最易误解之处，需在列表与确认文案中反复强调。

原「规格 / 水源地候选前端硬编码」问题已解决；本页为唯一候选维护入口。
