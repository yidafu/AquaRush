页面说明

所属端：管理后台（React + Ant Design 5）

入口：运营配置 → 店铺信息；路由 operations/store

下游：用户端关于页（about，F-USR-006）、意见反馈页（feedback）客服热线

状态：规划中（目标形态）

布局结构

  1. 基础信息卡：门店名称 / 门店简介 / 关于我们（含 LOGO 上传）
  2. 联系方式与服务时间卡：客服电话 / 服务时间
  3. 门店地址卡：地址输入 + 地图选点
  4. 门店照片与资质证照卡：门店照片（≤ 6）/ 资质证照（多图）
  5. 营业状态卡 + 修改记录表

关键交互

  1. 进入页面回显当前配置 → 修改 → 保存 → 用户端关于页 / 反馈页更新
  2. 地图拖拽选点 → 回填经纬度
  3. 修改留审计日志（操作人 / 时间 / 前后值）

状态与规则

状态：未配置时用户端按默认值兜底；回显 / 保存 loading；保存失败 toast。

关键数据字段：门店名称、LOGO、客服电话、服务时间、门店地址、门店照片、资质证照、营业状态、简介、关于我们、审计记录。

校验：「客服电话格式不正确」；门店名称 ≤ 20 字，门店简介 ≤ 100 字，关于我们 ≤ 2000 字。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，敏感配置（资质变更）不额外着色，统一以留痕呈现。

客服电话为骨架校验项；修改留痕（操作人 / 时间 / 前后值）需可见。

门店照片与资质使用真实场景实拍占位，严禁卡通插画；资质证照须真实可核验。

缺口 G62：用户端消费点（关于页 / 反馈页底部）为目标形态。
