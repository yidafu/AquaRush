页面说明

所属端：管理后台（React + Ant Design 5）

入口：运营配置 → 公告；路由 operations/announcements

下游：用户端首页公告栏（home）、公告详情页（notice-detail，目标形态）

状态：部分实现（用户端展示已具备、后台维护链路未闭环）

布局结构

  1. 顶部：「新建公告」按钮
  2. 公告列表：标题 / 类型（Tag）/ 置顶标识 / 展示位置 / 生效时间 / 状态 / 发布时间 / 操作（编辑 / 发布 / 置顶 / 停用 / 删除）
  3. 新建 / 编辑弹窗：标题、内容富文本、类型、展示位置、生效时间范围、置顶开关

关键交互

  1. 新建公告（草稿）→ 编辑 → 发布（时间窗内生效）
  2. 置顶公告在公告栏最前展示
  3. 停用 / 到期 → 用户端不再展示

状态与规则

状态：草稿 / 已发布 / 已停用；置顶标识；时间窗内 / 已过期。

关键数据字段：标题、内容、类型、置顶、展示位置、开始 / 结束时间、发布时间、状态。

校验：「公告标题不能为空」「公告内容不能为空」「时间窗不合法」。

设计要点 / 禁忌

管理端不出现强调橙：类型「停水通知」用语义 error 色标识，「活动预告」用品牌蓝，主操作用品牌蓝。

已停用公告不可再编辑（开放问题）；公告为站内内容，与订阅消息不同通道。

缺口 G62：用户端展示已具备、后台维护链路为目标形态（新建 / 编辑 / 发布 / 置顶 / 停用）；公告详情页与展示位置为开放问题。
