页面说明

所属端：管理后台（React + Ant Design 5）

入口：运营配置 → 意见反馈；路由 operations/feedbacks

关联：用户详情「意见反馈」Tab（F-USR-022）；用户端反馈页（F-USR-005）与反馈记录（feedback-records）

状态：已实现（缺口 G63 / G04 已解决）

布局结构

  1. 筛选区：反馈类型 Select、状态 Select（待处理 / 处理中 / 已处理）、用户 / userId、时间范围 RangePicker、「搜索」/「重置」
  2. 反馈列表：提交时间 / 用户 / 类型（Tag）/ 内容摘要（省略）/ 图片数 / 状态（Tag 着色）/ 操作「处理」「查看」
  3. 处理抽屉：反馈详情（类型 / 内容全文 / 图片可预览 / 联系方式）/ 处理区（处理结果 + 状态流转）/ 处理人留痕

关键交互

  1. 进入页面 → 反馈列表加载（默认第 1 页，分页）
  2. 组合筛选 / 搜索 / 重置
  3. 打开详情 → 查看内容与图片 → 填写处理结果 → 流转状态
  4. 「处理结果回传用户端」：提交后回传至用户端反馈记录（feedback-records）可见

状态与规则

状态：待处理 / 处理中 / 已处理（Tag 着色）；空态「暂无反馈」。

关键数据字段：类型、内容、图片、联系方式、提交时间、状态、处理结果、处理人 / 时间。

表单字段：处理结果（TextArea，≤ 500 字，选填）；状态流转（待处理 → 处理中 → 已处理）。

设计要点 / 禁忌

管理端不出现强调橙：状态 Tag 用品牌蓝 / warning / success，主操作用品牌蓝。

联系方式默认脱敏（开放问题）；已处理反馈不可再修改（开放问题）。

图片预览使用真实场景实拍占位，严禁卡通插画；抽屉内处理留痕须可见（操作人 / 时间）。
