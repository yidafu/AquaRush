页面说明

所属端：管理后台（React + Ant Design 5）

入口：运营配置 → 首页轮播；路由 operations/banners

下游：用户端首页轮播位（home，消费于 F-PRO-001）

状态：已实现（缺口 G61 已解决）

布局结构

  1. 顶部：「新建轮播」按钮
  2. 轮播列表：缩略图 / 标题 / 副标题 / CTA 文案 / 跳转类型与目标 / 排序号 / 生效时间 / 状态 / 操作（编辑 / 上移 / 下移 / 删除）
  3. 新建 / 编辑弹窗：图片上传、标题 / 副标题 / CTA 文案、跳转类型与目标、排序号、生效时间范围、启用开关
  4. 拖拽排序说明 + 小程序首页预览

关键交互

  1. 上传图片 → 填写标题 / 跳转 / 排序 / 时间窗 → 保存启用
  2. 上移 / 下移或编辑排序号调整顺序（亦可拖拽 ⠿）
  3. 停用 / 到期 → 用户端该轮播位不再展示
  4. 用户端首页 Swiper 按配置渲染

状态与规则

状态：启用 / 停用；时间窗内 / 已过期。无轮播配置时用户端轮播位隐藏（是否回退默认运营图为开放问题）。

关键数据字段：图片 URL、标题、副标题、CTA 文案、跳转目标、排序号、开始 / 结束时间、启用状态。

校验：「时间窗不合法」；图片必传，建议 750×360、≤ 5MB、jpg / png / webp。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，删除用语义 error 色。

需提示图片规格（750×360）；排序号唯一；停用 / 已过期条目编辑置灰；轮播图用真实场景实拍占位，严禁卡通插画。

跳转目标「指定分类筛选」因商品无分类概念暂不实现，外部链接为开放问题。
