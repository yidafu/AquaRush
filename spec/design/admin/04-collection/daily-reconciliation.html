页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧菜单「收银对账」→ 每日收款记录 Tab

跳转：「查看明细」打开当日已送达订单流水；「对账记录」Tab 见 F-COL-011

权限：PERMISSION_COLLECTION_READ / PERMISSION_COLLECTION_CONFIRM

布局结构

  1. 日期选择：前一日 / 日期 / 后一日
  2. 4 张汇总卡：现金收款 / 扫码收款 / 水票数量 / 订单金额
  3. Tabs：每日收款记录 ｜ 对账记录
  4. 日报表格：送水工 / 现金 / 水票 / 扫码 / 合计 / 订单笔数 / 系统预计算 / 差异 / 状态 / 操作
  5. 差异高亮规则说明卡
  6. 第二状态：确认日报二次确认弹窗

关键交互

  1. 切换日期重新加载当日日报
  2. 点「确认」→ 二次确认「确认配送员 … 的收款记录吗?」→ 确认成功状态置「已确认」
  3. 差异申诉中的行可确认或驳回（驳回必填原因，回退可重提）
  4. 「查看明细」下钻当日已送达订单流水（含差异说明）
  5. 切换「对账记录」Tab 进入每日对账与审核

状态与规则

状态标签：待确认 / 已确认 / 差异申诉中 / 已审核。

差异着色：|差异| ≤ 1 元绿、否则红；差异申诉中的行整行浅红底突出。

空态：表格空；加载态：表格 loading；错误态：确认失败 message；禁用态：非「待确认 / 差异申诉中」行不显示确认按钮。

水票按张数单独精确比对，不计入金额差异基数（R-COL-02）。

设计要点 / 禁忌

管理端不出现强调橙：「待确认」用 warn 语义色，主操作用品牌蓝，驳回用 error 色。

系统预计算值必须与配送员填报值并列展示，差异列高亮；「差异申诉中」行需突出并可查看差异说明。

金额以「分」存储与计算（R-MON-01），展示两位小数；容差固定 ±100 分（可配置化为缺口 G73）。
