页面说明

所属端：管理后台（React + Ant Design 5）｜ 资金类

入口：左侧菜单「收银对账」→ 工资结算

跳转：结算单详情可下钻关联日报 / 对账；「导出」下载结算台账

权限：PERMISSION_PAYROLL_READ / PERMISSION_PAYROLL_WRITE

布局结构

  1. 筛选区：结算周期（按周 / 按月）+ 周期区间 + 送水工 + 状态
  2. 操作按钮：「生成结算单」「导出台账」
  3. 结算参数卡：基础单价 / 楼层加价 / 桶数提成 / 好评奖励 / 周期 / 跨周期归属
  4. 汇总卡：应发合计 / 已发合计 / 待发合计 / 对账一致率
  5. 结算单表格：送水工 / 完成单数 / 桶数 / 结算金额 / 已发金额 / 状态 / 操作
  6. 结算明细下钻弹窗（工资项明细 + 订单级明细 + 对账一致性标记）
  7. 空态「暂无结算单」

关键交互

  1. 选择周期 →「生成结算单」→ 系统按规则汇总（幂等：同周期同人唯一）
  2. 复核明细（可下钻查看订单 / 日报 / 对账）→「确认」
  3. 确认发放二次弹窗「确认发放送水工 {name} 本期工资 ¥{amount} 吗?」→ 记录发放方式 / 凭证 → 状态「已结算」
  4. 「导出台账」下载当前筛选结算台账

状态与规则

状态机：待生成 → 已生成 → 已确认 → 已发放；状态标签：待结算 / 已结算 / 有差异。

空态：「暂无结算单,请先选择周期生成」；加载态：生成 / 列表 loading；错误态：生成失败 / 对账不一致提示。

禁用态：已发放结算单不可再确认 / 发放（幂等防重复发放）。

计算：应发合计 = 底薪 + 计件提成 + 补贴 − 扣款（负值告警，开放问题）。

设计要点 / 禁忌

管理端不出现强调橙：主操作用品牌蓝，差异 / 负值告警用语义 error 色。

整页为目标形态（缺口 G88：送水工端「收入提现」为后续）。现状无工资规则配置、无结算单、无发放记录，报酬依赖线下人工核算。

资金底线（不可砍）：同周期同人唯一 + 发放幂等（防重复发放）；计件数据与日报 / 对账不一致时挂起告警、不静默发放；对账一致率目标 100%；发放记录留痕（方式 / 时间 / 操作人）。

金额以「分」存储与计算，禁止浮点（R-MON-01），展示两位小数。
