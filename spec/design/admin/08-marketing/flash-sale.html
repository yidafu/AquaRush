页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 限时特价

跳转：用户端商品列表 / 详情特价展示（F-PRO-002）；行「详情」→ 营销活动详情页（共用）

组件：Table、Modal、Form、InputNumber、DatePicker、Select

布局结构

  1. 顶部：「新建特价」按钮
  2. 活动列表：商品 / 目录价 / 特价 / 时间窗 / 状态 / 操作
  3. 新建 / 编辑弹窗：选商品、特价（元）、每人限购、时段、库存投放量
  4. 活动商品明细表：商品 / 原价 / 活动价 / 投放量 / 已售 / 已抢进度条
  5. 用户端展示说明：特价 ¥15.00 + 划线目录价 ¥21.00（可选倒计时）

关键交互

  1. 配置特价 → 上架 → 活动期自动按特价计价（R-MKT-02③）
  2. 到期 → 自动失效，回退分组价 / 目录价
  3. 修改特价 / 时间窗 → 新订单生效，已生成订单不变
  4. 用户端展示特价与划线目录价

状态与规则

活动态：未开始 .tag-assign / 进行中 .tag-deliver / 已结束 .tag-done；停用后商品回退目录价。

校验：「特价无效」「时间窗不合法」；同商品时间窗重叠需拦截。

展示：「特价 ¥15.00」「¥21.00（划线）」；已抢进度条满 100% 用 error 色标识售罄。

设计要点 / 禁忌

特价默认须低于目录价（上浮为开放问题）；划线价与特价视觉需明确区分（删除线 + 品牌蓝特价）。

管理端不出现强调橙：主操作与进度条均用品牌蓝 / 语义色。

缺口 G56 已解决：限时特价已闭环，明细表与详情页共用同一活动口径。
