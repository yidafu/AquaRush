页面说明

所属端：管理后台（admin-client）

入口：营销管理 → 套餐票种（原「储值与套餐」，2026-10-09 收敛）

跳转：票种详情 / 编辑（弹窗）；核销 / 退款记录查询；用户端下游为 我的资产 · 我的套餐 / 套餐商城

数据：票种（类型 / 张数 / 桶数 / 售价 / 赠送次数 / 有效期 / 适用规格 / 启用）、核销 / 退款记录

合规：不做用户储值（2026-10-09 决策）——本页无储值档位 / 余额账本 / 充值流水；套餐卡为预购货物凭证，与水票同口径。

功能状态：规划中（缺口 G79），本页为目标形态。

布局结构

  1. 页面标题 +「导出」「＋ 新建票种」
  2. 合规常驻提示（.notice brand）：凭证类预购 · 有效期 / 退款规则明示
  3. 票种列表（.ant-table）：套餐名（类型副行）/ 张数 / 售价 / 赠送次数 / 有效期 / 适用规格 / 启用开关 / 操作
  4. 记录查询（Tabs 或子页）：类型（购买 / 核销 / 退款）+ 筛选（用户 / 票种 / 日期）+ 分页
  5. 凭证类预购合规与资金口径卡（.card + .desc-grid）

关键交互

  1. 新建 / 编辑票种 → 保存并启用 → 用户端套餐商城可见
  2. 停用 → 新购不可见，已持有卡继续有效至到期 / 用完
  3. 记录查询按条件分页（禁全表）；核销记录与订单核销明细一一对应（幂等防重）

状态与规则

票种：启用 / 停用；记录类型：购买 / 核销 / 退款；退款：未核销且未过期可退（原路），已核销 / 已过期不可退（R-MKT-11，对齐 R-MKT-08）。

校验：张数 / 桶数整数 > 0；售价 precision=2；有效期 ≤ 365 天；赠送次数整数 ≥ 0。

R-MON-01：金额以分存储，展示转元（两位小数）。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G79。

禁止出现储值元素：储值档位 / 赠送金额（货币）/ 余额流水 / 充值对账视图一律不得出现（用户储值不做，2026-10-09 合规决策）。

赠送仅允许「次数 / 张数」形态（如 10+1），不允许货币赠送；配置形态复用桶水票票种管理（water-tickets）。
