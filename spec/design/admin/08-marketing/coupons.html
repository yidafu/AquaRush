页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 优惠券

跳转：行「详情」→ 券详情（本页状态三）；用户详情「优惠券」Tab（F-USR-022）

组件：Table、Modal、Form、InputNumber、Select、DatePicker、Radio、Switch

布局结构

  1. 顶部：面包屑 + 「新建优惠券」按钮
  2. 券列表：券名 / 类型 / 面额或折扣率 / 门槛 / 适用范围 / 有效期 / 发放方式 / 已领未用数 / 操作
  3. 新建 / 编辑弹窗表单（逐字段，见状态二）
  4. 券详情：领取与核销记录（Tabs + 表格）
  5. 定向发放弹窗：选择用户或客户分组 → 发放

关键交互

  1. 建券 → 保存上架（可领取 / 发放）
  2. 定向发放 → 目标用户券包出现
  3. 用户端确认订单 → 满足门槛的可用券列表 → 勾选一张 → 优惠金额计入应付（R-MKT-07）
  4. 订单取消 / 退款 → 未过期券退回券包（核销幂等）

状态与规则

券状态机：未领取 → 已领取 / 已核销 / 已过期 / 已退回；停用 / 作废后不可领取使用。

活动态标签：未开始 .tag-assign / 进行中 .tag-deliver / 已结束 .tag-done；已停用 .tag-neutral / 已退回 .tag-cancel。

校验文案：「券面额无效」「折扣率超出范围」「门槛金额无效」「有效期不合法」；操作按钮「上架 / 停用 / 作废」。一单一券不可叠加；现金券 / 折扣券两套字段显隐。

设计要点 / 禁忌

券的视觉标识（金额 / 类型标签）在管理后台用品牌蓝或中性色；品牌强调橙（--action）是消费者端券卡 / 领券按钮 / 券选择器的专属，后台不出现强调橙。

金额一律分存储（R-MON-01），展示两位小数；核销幂等，退款退回未过期券。

缺口 G54 已解决：本页已形成「建券 → 发放 → 下单用券 → 退款退回」闭环。
