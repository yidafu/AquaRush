页面说明

所属端：管理后台（React + Ant Design 5）

入口：用户管理 → 客户分组（面包屑「用户管理 / 客户分组」）

跳转：行「商品价格策略」→ 分组价格管理（F-MKT-002）；客户列表（F-USR-022）提供「设置分组」行操作

组件：Table、Modal、Form、Select、Popconfirm、Drawer

布局结构

  1. 顶部：面包屑 + 右侧「新建分组」主按钮
  2. 分组列表表格：分组名 / 描述 / 成员数 / 创建时间 / 操作
  3. 分组详情抽屉：分组信息 + 成员列表 + 「商品价格策略」入口
  4. 客户列表新增「所属分组」列 + 行操作「设置分组」下拉（含「未分组」选项）
  5. 新建 / 编辑分组弹窗：名称、描述、初始成员（昵称 / 手机号多选搜索）

关键交互

  1. 新建分组：填名称 / 描述 → 可选初始成员 → 保存；名称重复即时拦截
  2. 设置分组：客户列表选中用户 → 选择分组 → 保存，即时生效
  3. 编辑分组成员：勾选 / 取消成员 → 保存，覆盖式同步（移除成员回「未分组」）
  4. 删除分组：二次确认 → 成员回退「未分组」

状态与规则

空态：无分组 / 无成员；加载态：列表与保存 loading；失败态：保存失败 toast；禁用态：删除中禁用操作；兜底：未归属客户显示「未分组」。

校验：「分组名称不能为空」；「分组名称已存在」；删除文案「确定删除分组 X 吗？成员将回到未分组」。

设计要点 / 禁忌

分组是营销受众与计价维度，删除 / 移除成员影响面大，二次确认需醒目标红。

成员多选需支持昵称 / 手机号搜索与已选回显；分组下拉固定含「未分组」。

管理端不出现强调橙：主操作用品牌蓝，删除用语义 error 色。

本页客户列表「所属分组」列为目标形态新增（缺口 G50），已实现部分为分组列表与成员管理。
