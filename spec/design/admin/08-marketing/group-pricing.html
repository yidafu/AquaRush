页面说明

所属端：管理后台（React + Ant Design 5）

入口：商品管理 → 分组价格；或客户分组详情 →「商品价格策略」

跳转：分组切换加载商品；保存后订单计价即时生效

权限：非管理员不可操作（禁用）

布局结构

  1. 顶部：面包屑 + 分组选择器（切换客户分组）
  2. 操作条：保存 / 批量设置 / 清空分组价
  3. 商品价格表：商品 / 规格 / 目录价（元）/ 分组价（可编辑，元，空=不设置，回退目录价）/ 折扣率 / 生效时间 / 操作
  4. 行内差额只读列：「较目录价省 ¥x」
  5. 未配置分组价商品提示条 + 批量设置弹窗

关键交互

  1. 选分组 → 加载商品列表（目录价 + 已配置分组价）
  2. 编辑分组价（元）或清空 → 保存（元 ×100 转分提交）
  3. 保存后订单计价即时生效，已生成订单成交价不变（下单快照）
  4. 批量设置：对勾选商品统一填分组价

状态与规则

空态：无商品 / 未配置价格；加载态：保存中 loading；失败态：保存失败 toast；禁用态：非管理员控件灰置。

校验：「请输入有效的分组价格」；分组价为选填，空值明确表达「回退目录价」；差额为让利语义，默认允许低于目录价（是否允许上浮为开放问题）。

设计要点 / 禁忌

分组价是计价链中的让利维度，须与目录价并列可读，差额用品牌色强调「省 ¥x」。

管理端不出现强调橙：主操作「保存」用品牌蓝。

金额一律分存储（R-MON-01），展示层两位小数；折扣率为只读计算列。

目标形态（缺口 G50）：客户列表「所属分组」列与分组价格策略联动为本域后续收敛点。
