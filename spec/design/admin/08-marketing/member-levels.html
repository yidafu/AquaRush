页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 会员等级（或客户分组详情）

跳转：用户端会员中心；下单按等级权益应用会员折扣 / 免配送费

组件：Table、Form、InputNumber、Switch

布局结构

  1. 等级列表：等级名 / 成长值门槛 / 折扣率 / 免配送费 / 生日券 / 专属客服 / 会员数 / 操作
  2. 配置弹窗：等级名、升级门槛、折扣率、权益勾选、启用
  3. 等级权益矩阵表：等级 × 权益
  4. 升级规则（成长值来源：每消费 ¥1.00 = 1 成长值）
  5. 降级规则

关键交互

  1. 配置等级与门槛 → 保存生效
  2. 用户完成订单 → 累计消费更新 → 达门槛自动升级 → 可选站内 / 订阅消息通知
  3. 下单 → 按等级权益应用会员折扣（R-MKT-06，商品维度互斥）、免配送费等

状态与规则

空态：无等级配置时引导先建；停用：停用等级不参与判定。

校验：「等级门槛需递增」「折扣率超出范围」（1%–99%）；文案「会员折扣 -¥5.00」。

口径：累计消费 = 已完成订单实付金额（不含押金、退款）；免配送费权益与楼层分档关系为开放问题。

设计要点 / 禁忌

本页为规划中（缺口 G80，含 G57 收敛）：门槛递增且不重复，等级与权益矩阵同屏可评审。

管理端不出现强调橙：折扣率用品牌蓝强调，权益标签用品牌蓝。

金额分存储（R-MON-01）、百分比两位小数；等级卡在用户端可适度品牌化，后台保持克制。
