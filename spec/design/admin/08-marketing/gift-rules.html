页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 买赠 / 满赠

跳转：行「详情」→ 营销活动详情页（共用）；用户端确认订单赠品区（order-confirm）

组件：Table、Modal、Form、InputNumber、Select、DatePicker、Switch

布局结构

  1. 顶部：「新建活动」按钮
  2. 活动列表：活动名 / 类型 / 达标门槛 / 赠品（商品 + 数量）/ 适用范围 / 时间窗 / 状态 / 操作
  3. 新建 / 编辑弹窗：类型、门槛、赠品、库存上限、每人限享次数、适用范围、时间窗、启用
  4. 用户端说明：确认订单页「赠品」区（赠品名 × N，单价 ¥0.00）

关键交互

  1. 配置 → 保存上架 → 订单达标自动赠
  2. 达标判定：满赠按现金部分商品小计、买赠按指定商品数量 → 追加赠品行（0 价）→ 随单配送
  3. 停用 → 新订单失效，已生成订单不变

状态与规则

活动态：未开始 .tag-assign / 进行中 .tag-deliver / 已结束 .tag-done / 已停用 .tag-neutral；赠品 ¥0.00。

校验：「门槛无效」「请选择赠品」「时间窗不合法」；文案「满 100 元赠 4L 小桶 1 桶」。

规则：赠品为附加 0 价行，不参与现金叠加与券门槛；同一订单命中多档取赠品最大者（开放问题）。

设计要点 / 禁忌

赠品为核心决策信息，赠品行在列表与弹窗中需明确「商品 + 数量」；“买 N 送 M”语义突出。

管理端不出现强调橙：主操作与类型标签用品牌蓝 / 中性色。

缺口 G59 已解决；赠品库存上限与每人限享次数需与列表面向一致。
