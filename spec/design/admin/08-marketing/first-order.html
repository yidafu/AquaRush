页面说明

所属端：管理后台（React + Ant Design 5）

入口：营销管理 → 首单立减 / 新人价

跳转：用户端商品详情新人价、确认订单立减行；行「详情」→ 营销活动详情页（共用）

组件：Table、Modal、Form、InputNumber、Select、DatePicker、Switch

布局结构

  1. 顶部：「新建活动」按钮 + 首单立减总开关
  2. 活动列表：名称 / 类型 / 优惠内容 / 适用范围 / 有效期 / 状态 / 操作
  3. 新建 / 编辑弹窗：类型、优惠内容、适用范围、有效期、时间窗、启用
  4. 新人专享商品价配置表：商品 / 规格 / 目录价 / 新人价 / 折扣率 / 生效时间 / 操作
  5. 预算与已用金额卡 + 互斥取最大规则说明

关键交互

  1. 配置 → 上架 → 首单自动应用
  2. 判定新用户（无已完成订单）→ 首单立减（R-MKT-07①）或新人价（R-MKT-02④）
  3. 首单完成 → 资格失效；停用 → 新订单失效
  4. 新人专享价以元录入、×100 转分提交，回显 ÷100

状态与规则

活动态：未开始 .tag-assign / 进行中 .tag-deliver / 已结束 .tag-done / 已停用 .tag-neutral；新人价划线展示。

校验：「新人优惠无效」「时间窗不合法」；文案「新人价 ¥15.00」「首单立减 -¥10.00」。

规则：首单立减与满减互斥取最大；新人价进单价链④（优先于目录价）；预算按已用金额监控。

设计要点 / 禁忌

首单立减与新人价两套语义需在类型处清晰区分；新人价配置表与分组价格表结构同源（商品 / 目录价 / 让利价 / 折扣率）。

管理端不出现强调橙：主操作用品牌蓝，划线价用中性删除线。

缺口 G60 已解决；金额分存储（R-MON-01）、百分比两位小数。
