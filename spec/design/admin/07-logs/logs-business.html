页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧导航「日志管理 → 业务日志」；路由 /logs/business

跳转：行内「详情」弹出弹窗（消息全文 + 堆栈跟踪）

权限：GraphQL businessLogs（admin 角色，PERMISSION_LOG_READ）

布局结构

  1. 筛选卡：时间范围 / 业务域 / 操作类型 / 日志级别 / 用户 + 搜索 / 重置
  2. 视图切换：Segmented「表格 / 时间线」
  3. 视图区：表格（时间 / 用户 / 业务域 / 操作 / 对象 / 结果）或按用户分组的时间线
  4. 分页（表格 20/页，时间线 10/页）
  5. 详情弹窗：消息全文 + 堆栈跟踪

表格与字段

本页无图表（表格 / 时间线 + 弹窗）；时间线视图即「用户业务操作轨迹」可视化。

级别配色：TRACE default · DEBUG 绿 · INFO 蓝 · WARN 橙 · ERROR 红。

业务域枚举：订单 / 支付 / 配送 / 用户 / 认证（映射自 loggerName）；操作类型与业务域联动（登录 / 提交订单 / 查看产品等，未选域展示全部）。

时间范围格式：YYYY-MM-DDTHH:mm:ss（本地时间，弃用 UTC 偏移）。导出：无（如需为目标形态）。

关键交互

  1. 进入页面按默认第 1 页 / 20 条经 GraphQL 请求并渲染列表与总数
  2. 选择业务域 → 操作类型下拉联动为该域类型；其余条件可组合 → 搜索 → 回第 1 页
  3. 切换「时间线」视图 → 以时间线展示当前筛选结果（恒 createdAt 倒序）
  4. 两视图共用同一筛选状态，切换保留筛选、分页回第 1 页并按视图调整每页条数
  5. 点击某行「详情」→ 弹窗展示消息全文与堆栈跟踪；失败仅 console.error（缺口 G74）

设计要点 / 禁忌

管理端不出现强调橙；级别 Tag 配色稳定映射，TRACE / 自定义类型走 default 色。

操作类型中文文案：老数据（operation 列为 NULL）前端回退解析 message 前缀 Operation: X，不可显示为空。

消息以 { / [ 开头且可解析时用 JsonViewer 格式化，否则保留原文；堆栈跟踪可滚动、可复制。

关联ID（correlationId）用于与订单操作时间线 / 请求链对齐，须完整展示；本页时间不做时区换算。 错误态前端提示、查询期间按钮禁用、导出。
