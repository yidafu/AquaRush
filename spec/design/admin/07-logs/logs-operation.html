页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧导航「日志管理 → 用户操作」；路由 /logs/user-actions

跳转：行内「详情」弹出抽屉；本页不提供用户时间线视图（时间线仅在业务日志页）

权限：PERMISSION_LOG_READ

布局结构

  1. 筛选卡：时间范围 / 操作人 / 角色 / 操作类型 / 业务域 / 结果 + 搜索 / 重置
  2. 操作表格：时间 / 操作人 / 角色 / 业务域 / 操作类型 / 目标对象 / 结果 / IP / 操作
  3. 分页（默认 20/页）
  4. 操作详情抽屉：元素级信息 + 变更前后对比 + 附加属性

表格与字段

本页无图表（纯表格 + 抽屉）。

操作类型配色：页面浏览 蓝 · 点击 绿 · 表单提交 橙 · 搜索 紫 · 分享 青 · 滚动 品红 · 文件操作 红；未命中枚举显示原值 + default 色。

详情字段：操作类型 / 用户ID / 用户名 / IP / 页面URL / 目标 / 元素ID / 元素类型 / 元素文本 / UserAgent / 附加属性 / 时间。

导出：无（如需导出为目标形态）。

关键交互

  1. 进入页面按默认第 1 页 / 20 条请求并渲染列表与总数
  2. 选择操作类型 / 输入用户 / 选择时间范围（可组合）→ 搜索 → 回第 1 页重新请求
  3. 重置 → 清空全部筛选并回第 1 页
  4. 点击某行「详情」→ 抽屉展示元素级信息与变更前后对比
  5. 翻页 / 切换每页条数 → 按新分页重新请求

设计要点 / 禁忌

管理端不出现强调橙；操作类型 Tag 配色须稳定映射，新增后端自定义类型走 default 色并显示原值。

页面 URL / 目标 / UserAgent 超长须省略或滚动 + 复制；追溯三要素「操作人 + 时间 + 对象」须完整可读。

附加属性格式化 JSON 展示，敏感键被后端剔除后落库；时间不做时区换算。

请求失败现状仅 console.error（缺口 G74）； 业务操作维度筛选（枚举映射，与当前前端行为枚举口径存在差异）、错误态前端提示、查询期间按钮禁用、导出。
