页面说明

所属端：管理后台（React + Ant Design 5）

入口：左侧导航「日志管理 → API 日志」；路由 /logs/api

跳转：行内「详情」弹出抽屉（不跳页）

权限：PERMISSION_LOG_READ

布局结构

  1. 筛选卡：时间范围 / 路径 / 方法 / 状态码 / 耗时阈值 / 用户 / traceId + 搜索 / 重置（均 allowClear）
  2. 日志表格（横向滚动 x=1200）：时间 / 方法 / 路径 / 状态码 / 耗时 / 用户 / IP / traceId / 操作
  3. 分页（默认 20/页）
  4. 请求详情抽屉：请求参数 / 响应体 / 耗时分解

表格与字段

本页无图表（纯表格 + 抽屉）。

状态着色：2xx 绿 / 4xx 橙 / 5xx 红 / 其余 default，避免与类型标签混淆。

详情字段：请求类型 / 方法 / URI / Query / 状态码 / 耗时 / 用户ID / 用户名 / IP / UserAgent / 关联ID / 操作类型 / 操作名称 / 请求体 / 错误信息 / 时间。

导出：无（如需导出为目标形态）。

关键交互

  1. 进入页面按默认第 1 页 / 20 条请求并渲染列表与总数
  2. 设置任一筛选条件（可组合）→ 搜索 → 回第 1 页重新请求
  3. 重置 → 清空全部筛选并回第 1 页重新加载
  4. 点击某行「详情」→ 打开抽屉展示完整请求信息
  5. 翻页 / 切换每页条数 → 按新分页参数重新请求

设计要点 / 禁忌

管理端不出现强调橙：操作链接用品牌蓝，删除等语义色用 error。

URI / 请求体超长须省略或滚动 + 复制，禁止撑破布局；错误信息红色、可滚动且可复制。

时间以服务端时间为准，前端仅做本地化，不换算时区；敏感字段脱敏（R-SYS-02）。

请求失败现状仅 console.error，无前端提示（缺口 G74）； 状态筛选（4xx/5xx 快速定位）、错误态前端提示、查询期间按钮禁用、导出。
