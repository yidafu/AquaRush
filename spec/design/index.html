阅读方式：每张稿为「stage 画布 + 设备外框 + 右侧标注面板」。左侧是设计效果（多状态并排：正常态 / 空态 / 弹窗态 / 视口态），右侧标注面板给出 页面说明 / 布局结构 / 关键交互 / 状态与规则 / 设计要点·禁忌；三端稿件的标注面板另含一张「组件与度量」说明卡。
小程序端（user-weapp）组件体系：严格按微信官方 WeUI 2.x —— 44px 导航栏 + 87×32 微信胶囊、原生 TabBar（50px / 图标 27px / 文字 10px / 底 #F7F7F7）、页面底 #EDEDED、单元格 17px 主文字与 0.5px 内缩 16px 发丝线、官方 Grids / Loadmore / Actionsheet / HalfScreen / Dialog。主题色经 --weui-BRAND 注入奔泉品牌蓝；金额用微信电商惯例红 #FA5151。
配色红线：强调橙仅用于消费者端优惠券品牌元素与最高优先级 CTA（每屏 ≤ 3 处）；管理后台与送水工端完全不出现强调橙。增长指标用红、下降用绿（中国口径）。金额一律分存储、展示为元两位小数。
入口收口：用户端不设独立登录页——微信授权以半屏授权引导弹层承载（见「个人中心（我的）」状态三），登录成功后就地返回原动作；水桶账户 / 水票 / 套餐 / 积分 / 优惠券在「我的」聚合为单一「我的资产」入口，在资产页内下钻。不做用户储值（2026-10-09 合规决策：无预付卡资质，余额充值 / 余额支付 / 余额抵扣均不设，充值页与余额入口已移除，预收资金由水票与套餐卡承接）。
价格与圆角分端：小程序端金额用微信电商红 #FA5151、按钮圆角 8px（WeUI 官方）；管理端 / 配送端金额用品牌蓝加粗、按钮全圆角 24px。
状态标记：与 PRD 功能条目一一对应；「规划中」页面在稿内以「目标形态」标签标出并注明缺口编号（G 编号）。
