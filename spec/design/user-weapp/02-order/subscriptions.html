组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；半屏弹层圆角 12px、最高 78% 屏高、标题内缩 20px；分段控件与选项芯片高 22px（.weui-tag--md）；步进器 28px；按钮高 48px。

价格：本屏为计划信息展示，无金额明细；如需展示单价统一用 .weui-price（微信电商红 #FA5151）。

用色：交互主色品牌蓝（导航 / 主按钮 / 单选 / 选中芯片）；计划状态用 .weui-tag--brand / --done / --cancel；目标形态用 .weui-tag--goal；本屏未使用强调橙。

页面说明

所属端：用户端小程序（后台对应页 F-ORD-026 后台侧）

功能：F-ORD-026 周期订购（，缺口 G77）。

入口：「我的」页服务区「周期订购」；复购确认页「设为周期订购」。

跳转：确认订单页（周期来源复用）；计划详情 → 最近生成订单列表。

数据：商品明细、周期类型、配送时段、收货地址、生效时间、终止条件、下单方式、下次配送时间、幂等键（计划 id + 期次）。

布局结构

  1. 计划列表（.weui-cells）：商品摘要 + 周期规则 + 下次配送时间 + 状态标签（.weui-tag--brand / --done / --cancel）+ 操作（.weui-btn_xs 暂停 / 恢复 / 终止）
  2. 新建计划半屏表单（.weui-half）：商品 / 数量（.weui-stepper）/ 周期（.weui-segmented + 星期多选芯片）/ 配送时段 / 地址 / 生效时间 / 终止条件 / 下单方式（.weui-radio 自动下单 / 仅提醒）
  3. 计划详情：最近生成订单列表
  4. 空态：「暂无周期订购计划」+ 新建入口

关键交互

  1. 新建计划 → 校验（商品在售、地址在配送范围内 R-ADR-04）→ 保存生效
  2. 到期 → 按计划生成「待支付」订单（幂等键 = 计划 id + 期次）→ 未开启自动支付则推送「周期订单待支付」提醒（F-NTF-007）
  3. 失败（缺货 / 地址不可达）→ 不生成订单，推送提醒用户手动下单 / 调整计划
  4. 暂停 → 暂停期间不生成；终止 → 计划结束，已生成订单不受影响

状态与规则 / 设计要点

计划状态标签：生效中 .weui-tag--brand / 已暂停 .weui-tag--done / 已终止 .weui-tag--cancel（计划状态，非订单状态，故不使用订单状态标签--pay/--assign/--deliver）。

空态：「暂无周期订购计划」；加载态：列表 / 保存 loading；错误态：保存 / 生成失败 toast 与提醒。

禁用态：终止后不可恢复（需新建）。

设计要点：地址以生成时快照；生成订单与支付超时 / 取消解耦（生成即「待支付」）；暂停期间不生成；自动下单失败不静默；「自动下单 / 仅提醒」须给出区别说明，避免误选（开放问题：默认值待定）；暂缓（2026-10-10 产品决策，保留编号与设计、不进当期排期，勿重复立项）缺口编号 G77（14-misc.md [暂缓]）；若重启建议先做「提醒型」。
