组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；通告栏内缩 16px、图标 16px；加载更多提示 14px；弹窗宽 280px（≤84%）、圆角 12px、按钮行高 56px。

价格：所有金额用 .weui-price（微信电商红 #FA5151），划线目录价 .weui-price--origin，实付 .weui-price--lg。

用色：交互主色品牌蓝（导航 / 主按钮）；剔除提示用橙色 tint 通告栏 .weui-notice；目标形态用 .weui-tag--goal 标注；本屏未使用强调橙。

页面说明

所属端：用户端小程序

功能：F-ORD-025 一键复购 / 再来一单（，缺口 G76）。

入口：订单列表「再来一单」按钮（已完成 / 已取消 / 已退款订单卡片操作区）；订单详情底部操作区「再来一单」。

跳转：校验通过 → 确认订单页（复用 F-ORD-001）；剔除后无商品 → 停留原页并提示。

数据：历史订单 items + 地址快照、当前在售状态（vendor ONLINE）、当前库存、按 R-MKT-02 重算单价。

布局结构

  1. 入口：订单卡片操作区「再来一单」（进行中订单默认不展示）
  2. 校验中：.weui-loadmore_loading 转圈 + 文案「正在校验商品在售状态与库存」
  3. 剔除后：橙色通告栏 .weui-notice「部分商品已下架或售罄，已自动移除：N 件」+ 订单摘要 .weui-cells + 商品清单 + 金额明细 + .weui-btn_area「再来一单」
  4. 全部失效：.weui-dialog「商品均已下架，无法复购」+ 返回 / 去逛逛

关键交互

  1. 点「再来一单」→ 读取该订单 items + 地址快照 → 校验商品在售与库存 → 组装 pendingOrder → 跳确认订单页
  2. 有效商品全部保留、无效商品剔除并提示「部分商品已下架或售罄，已自动移除：N 件」
  3. 剔除后无商品 → 提示「商品均已下架，无法复购」并停留原页
  4. 确认页展示当前单价与合计，用户可调数量 / 换券 / 改地址后提交（走 R-ORD-06 幂等与 R-ORD-02 库存校验）

状态与规则 / 设计要点

空态：订单无商品明细时「再来一单」不可点。

加载态：组装中按钮 loading（本稿以 .weui-loadmore_loading 表达）。

错误态：toast「加载失败，请重试」。

禁用态：进行中订单默认不展示（开放问题：是否允许对进行中订单复购）。

设计要点：不沿用历史成交价（按当前营销链路重算）；水票 / 优惠券 / 押金不沿用，由用户当期重新选择；地址沿用订单快照（无效则默认地址，无默认则显示「请选择收货地址」）；重复触发仅生成一份待下单数据（本地幂等），不得重复创建订单； 目标形态缺口编号 G76（14-misc.md）。
