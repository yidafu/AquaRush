组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；星标 30px（只读 20px）；标签芯片 .weui-tag--md 高 22px；开关 51×31；文本域最小高 96px、字数计数右对齐 14px。

价格：本屏无金额。星级用品牌蓝（选中态），不使用价格红，避免与金额语义混淆。

用色：交互主色品牌蓝（导航 / 星级 / 选中标签 / 主按钮）；未选中标签用 .weui-tag--outline；本屏未使用强调橙。

页面说明

所属端：用户端小程序

功能：F-ORD-007 订单评价（已实现，一单一评、不可修改）。

入口：已完成订单详情「评价」。

跳转：提交成功 → 返回订单详情并展示已评内容。

数据：订单号、送水工信息、评分（1-5）、评论（≤500 字）、匿名标记、是否可评（orderReviewCheck）。

布局结构

  1. 送水工信息 + 商品行（.weui-cells）：头像 / 姓名 / 门店 · 送水工；缩略图 + 名称 + 规格
  2. 星级评分（1-5 星，点选，5 星为「非常满意」，内联 SVG 星选中态品牌蓝）
  3. 评价标签多选（.weui-tag 芯片，选中 .weui-tag--brand）
  4. 文字评论 .weui-textarea（≤500 字）+ .weui-textarea__counter 计数
  5. 匿名开关 .weui-cell_switch + .weui-switch（开启后对送水工隐藏身份）
  6. .weui-btn_area 内「提交评价」主按钮
  7. 已评价态：订单详情内只读展示已评星级、标签与文字

关键交互

  1. 已完成订单 → 点「评价」→ 进入评价页
  2. 选星 / 填文字 / 开匿名 → 提交（createReview）
  3. 提交成功 → 计入送水工评分 → 返回订单详情展示评价内容
  4. 已评价订单再次进入 → 只读展示已评内容，不可修改（R-EVL-01）

状态与规则 / 设计要点

加载态：提交中按钮 loading；错误态：提交失败 toast。

禁用态：非已完成 / 已评价订单评价入口隐藏。

校验：未选评分提示「请选择评分」；已评价提示「该订单已评价」。

设计要点：评论 ≤500 字且实时计数；匿名评价对送水工隐藏用户身份；评分实时计入送水工统计；星级使用品牌蓝而非价格红；一单一评、不可修改，提交后必须能即时反馈。
