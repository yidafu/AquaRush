组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；通告栏内缩 16px、图标 16px；单选钮 22px；步进器 28px；按钮高 48px、禁用态文字 18% 黑；底部操作栏内缩 16px。

价格：所有金额（信用额度 / 已用额度 / 子订单合计）用 .weui-price（微信电商红 #FA5151），合计用 .weui-price--lg。

用色：交互主色品牌蓝（导航 / 主按钮 / 单选）；企业身份用 .weui-notice--brand；超额度用 .weui-notice--red；本屏未使用强调橙。

页面说明

所属端：用户端小程序（后台对应页 F-ORD-027 后台侧）

功能：F-ORD-027 企业下单（，缺口 G83）。

入口：侧边 / 服务区「企业下单」（新增路由）。

跳转：拆单结果（多张子订单）/ 订单列表。

数据：企业客户档案（企业名称 / 税号 / 开票抬头 / 账期 / 信用额度）、多收货地址、商品明细、支付方式（月结(账期)）、拆单结果（子订单）。

布局结构

  1. 企业身份与账期条（.weui-notice--brand）：企业名称 + 企业客户 + 账期 + 联系人；下接信用额度 / 已用额度
  2. 多地址分组批量录入：.weui-cells__title 地址分组 + 每地址下商品清单（含 .weui-stepper 调数量 / 追加商品）
  3. 支付方式（.weui-cells__title「支付方式」+ .weui-cells 内 .weui-radio）：微信支付（即时收款）/ 月结(账期)（企业专享，选中时不进入微信支付）
  4. 超额度拦截：.weui-notice--red「已超出信用额度，请先结清或联系管理员」
  5. 底部操作栏 .mp-footbar「提交拆单」，按收货地址拆分为多张子订单

关键交互

  1. 录入多地址 / 多商品（可复用购物车组件）
  2. 提交 → 按收货地址拆分为多张子订单（每张独立走库存校验与状态机）
  3. 月结订单不即时收款，计入应收账款
  4. 超出信用额度时下单拦截，提示「已超出信用额度，请先结清或联系管理员」

状态与规则 / 设计要点

空态：无可用地址 / 商品时引导添加。

禁用态：超出信用额度时提交按钮禁用（.weui-btn_disabled）。

错误态：提交失败 message。

设计要点：仅企业客户出现「月结」选项，个人客户不出现；各子订单独立走库存校验与状态机；企业客户身份由后台在客户档案标记（非自助注册）；月结为资金类业务（征信 / 账期 / 对账），须评估资质与风控；禁用按钮须给出明确出路（结清 / 联系管理员 / 改用即时收款）； 暂缓（2026-10-10 产品决策，保留编号与设计、不进当期排期，勿重复立项）缺口编号 G83（14-misc.md [暂缓]）。
