组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；步骤条圆点 18px、已完成段连线转品牌蓝；单元格 17px 主文字、内缩 16px 发丝线；状态标签大号 .weui-tag--md（高 22px）。

价格：所有金额用 .weui-price（微信电商红 #FA5151），实付合计用 .weui-price--lg；订单编号用等宽数字（tabular-nums）。

用色：交互主色品牌蓝（导航 / 进度 / 主按钮）；地图当前定位点 .pin.cur 为强调橙（来自 ui.css）；本屏未额外使用强调橙。

页面说明

所属端：用户端小程序

功能：F-ORD-003 订单详情（已实现）；「立即支付」F-ORD-005 /「取消订单」F-ORD-006 /「评价」F-ORD-007 / 催单 F-ORD-008（部分实现）/「再来一单」F-ORD-025（规划中）。

入口：订单列表点击订单；下单成功 redirectTo。

跳转：「立即支付」→ 支付发起；「评价」→ 订单评价；「再来一单」→ 确认订单页；「查看配送」→ 配送跟踪；拨号 → 送水工电话 / 客服。

布局结构

  1. 状态头：大号状态标签（.weui-tag--md）+ 说明 + 进度步骤条（.weui-steps：下单 → 支付 → 派单 → 配送 → 完成，.done 标记）
  2. 配送地图卡（配送中）：.map 双标记（送水工 .pin.cur / 收货地址 .pin）+ 送水工信息 + 查看跟踪
  3. 收货地址（.weui-cells）：联系人 / 电话 / 完整地址（含楼层）
  4. 商品清单（.weui-cells）：图 / 名 / 规格 / 优惠价 + 划线价 × 数量
  5. 金额明细（.weui-cells）：商品金额 / 营销优惠 / 水票抵扣 / 配送费 / 水桶押金 / 实付合计
  6. 订单信息（.weui-cells）：订单编号（等宽 / 可复制）/ 下单时间 / 支付方式 / 备注
  7. 交付照片核验（.weui-cells）：待核验 / 核验通过
  8. 底部操作区 .mp-footbar（按状态变化）

关键交互

  1. componentDidMount 读 orderId → 加载详情；orderId 缺失 toast「订单ID缺失」并返回
  2. 点「复制订单号」→ 写剪贴板并 toast「复制成功」
  3. 「立即支付」→ createOrderPayment；「催单」→ 配送中专属，防抖，toast「催单已受理」
  4. 「查看配送」→ 配送跟踪 delivery-tracking?orderId=xx
  5. 「再来一单」→ 写 pendingOrder 跳确认订单页

状态与规则 / 设计要点

操作集合：待付款 = 取消订单 + 立即支付；待配送 = 再次购买；配送中 = 查看配送 + 催单；已完成 = 评价 / 查看评价 + 再来一单；已取消 / 已退款 = 再来一单。

时间线口径：下单 → 支付 → 派单 → 配送 → 已送达 → 订单完成；送达即完成，无中间态（R-ORD-11）；不得出现「确认收货」节点。

禁用态：非配送中不展示催单；已完成 / 已取消 / 已退款为终态，不可取消、不可改地址。

设计要点：步骤条节点与状态节点必须一致；金额减项用微信电商红、实付合计突出并精确到分；「再来一单」目标形态见 F-ORD-025（缺口 G76）；「查看配送」依赖用户端配送跟踪接入真实轨迹数据源（缺口 G65）。
