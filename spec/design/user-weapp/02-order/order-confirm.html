组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；单元格 17px 主文字、行高 1.4117、内缩 16px 发丝线；页面底 #EDEDED、单元格底 #FFFFFF；按钮高 48px 圆角 8px；开关 51×31；单选 22px；商品缩略图 72px（--sm 48px）。

价格：所有金额用 .weui-price（微信电商红 #FA5151），符号 / 小数位缩放；划线原价 .weui-price--origin；免运费 .weui-price--free（绿）。

用色：交互主色品牌蓝（导航 / 主按钮 / 单选 / 开关）；订单状态用 .weui-tag--*；强调橙 --action 仅限优惠券品牌元素，本屏 1 处。

页面说明

所属端：用户端小程序

功能：F-ORD-001 确认订单与提交下单（已实现）；多商品下单复用本页（F-ORD-004）；单价按登录用户分组价解析（F-ORD-023，部分实现）。

入口：商品详情「立即购买」/ 购物车结算 / 订单列表·详情「再来一单」/ 周期订购计划确认（F-ORD-026 暂缓，暂不接入）。

跳转：地址卡 → 地址列表选择模式 address-list?select=true；提交成功 → order-detail?orderId=xx；无商品异常 → 返回首页。

数据：读本地 pendingOrder 与 selectedAddress 缓存；商品或地址变化触发 orderPreview 预检计价（防抖 + 序号防竞态）。

布局结构

  1. 导航栏「确认订单」（返回 + 小程序胶囊）
  2. 收货地址行（.weui-cell_link 带箭头）：紧凑两行、有默认地址加「默认」标签
  3. 商品清单（.weui-cells）：缩略图 + 名称 + 规格 + 优惠价（并存划线目录价）+ 数量步进，组标题右侧「共 N 件」
  4. 配送时间：.weui-segmented（立即配送 / 上午 / 下午 / 晚上），选项由后台配置驱动
  5. 自提开关 .weui-cell_switch + .weui-switch；支付方式 .weui-cells 单选行
  6. 订单备注 .weui-textarea（≤200 字）
  7. 金额明细 .weui-cells：商品金额 → 满减 / 首单立减 / 优惠券 → 水票抵扣 → 赠品 ¥0.00 → 配送费 → 水桶押金 → 实付合计
  8. 服务条款复选 + 底部操作栏 .mp-footbar（已优惠 + 实付 +「提交订单」）

关键交互

  1. useReady 读 pendingOrder；无商品则 toast「订单数据异常，请重新选择商品」后回首页
  2. 点地址行 → 地址列表选择模式；useDidShow 回填 selectedAddress 缓存，否则取默认地址
  3. 切换配送时间 / 支付方式 / 填备注为本地 state；商品或地址变化触发 orderPreview 重算
  4. 提交依次校验 地址 → 商品 → 条款 → 置 loading → createOrder（回传 preferredCouponId / ticketRedeemCount，携带 clientRequestId 幂等键）→ 成功 toast「订单创建成功」跳详情；失败 toast 后端错误并停留本页
  5. 配送时段来自 deliverySlots 查询，失败回退兜底文案（立即配送 30 分钟内 / 上午 / 下午 / 晚上）
  6. 优惠券半屏：自动推荐最优券，用户可改选或「不使用优惠券」

状态与规则 / 设计要点

状态：空态（地址为空时地址行显示「请选择收货地址」+「选择地址」）；加载态（预检 loading；提交中按钮文案固定「提交中...」且禁用）；禁用态（提交期间防重复提交）；本页创建的订单落入「待支付」（30 分钟超时自动取消并恢复库存）。支付方式区仅微信支付（无余额支付选项——用户储值不做，2026-10-09 合规决策）。

金额口径：商品金额按成交单价计；减项 -¥x（微信电商红）；赠品 ¥0.00；配送费免费楼层（默认 4 层）内显示「免配送费」，超出按档加价；水桶押金首次为该规格购桶时收取、可退；实付 = 商品金额 − 优惠 − 水票抵扣 + 配送费 + 水桶押金。

设计要点：地址行须为「紧凑两行」；配送时段选中态为分段控件白底高亮；金额一律两位小数且全部用 .weui-price；条款未勾选不得提交；商品图严禁卡通插画，统一「实拍图占位」；强调橙每屏 ≤ 3 处。

起送门槛（R-OPS-03，缺口 G96 规划中）：商品金额低于后台配置门槛（示例 ¥30.00）时提交拦截——客户端展示红色提示「商品金额未达起送金额 ¥30.00，还差 ¥5.00」，服务端同步校验拦截；起送门槛 0 = 不启用；画布内红色提示条为目标形态。距离阶梯运费（与楼层分档叠加）配置见后台 F-OPS-005。
