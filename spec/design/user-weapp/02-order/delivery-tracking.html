组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；步骤条圆点 18px、已完成段连线转品牌蓝；单元格内缩 16px 发丝线；小按钮 .weui-btn_mini 高 28px；地图圆角 8px。

价格：本屏无金额。用色：交互主色品牌蓝（导航 / 路线 / 步骤条 / 主按钮）；送水工当前定位点 .pin.cur 为强调橙（来自 ui.css），本屏未额外使用强调橙；订单状态 .weui-tag--deliver / --done。

页面说明

所属端：用户端小程序

功能：F-ADR-010 配送跟踪（部分实现；真实轨迹接入为本期目标 2026-10）。

入口：订单详情「查看配送进度」；参数 delivery-tracking?orderId=xx；无 orderId 时 toast 并返回。

跳转：电话按钮 → 拨号；路线按钮 → openLocation 打开配送地址地图。

数据：orderId、送水工姓名 / 电话 / 当前位置、收货地址（经纬度 + 文案）、预计送达时间、订单状态。

布局结构

  1. 全屏地图 .map：双标记（送水工 .pin.cur + 收货地址 .pin）+ 路线虚线 + 右下角刷新 / 路线圆形控件
  2. 实时跟踪提示条（.weui-notice--brand）：「实时跟踪中，每 10 秒更新位置」
  3. 配送员信息卡（.weui-cells）：头像 + 姓名 + 电话 + 右侧电话图标 +「配送中」标签 + 当前位置 + 预计送达
  4. 配送进度（.weui-steps：已派单 → 配送中 → 已送达）
  5. .weui-btn_area 内 .weui-btn_mini「联系送水工」+ 底部 .mp-footbar「查看路线」

关键交互

  1. 进入：读取 orderId，无则 toast「订单ID缺失」1.5s 返回
  2. 加载跟踪信息（现状为 mock，目标为真实轨迹数据源）
  3. useDidShow 开启 10s 定时更新送水工位置，useDidHide 停止
  4. 点电话按钮 makePhoneCall 拨打；点路线按钮 openLocation 打开配送地址地图
  5. 下拉刷新；送达后展示「已送达」，停止位置刷新（R-ORD-11）

状态与规则 / 设计要点

空态：「订单不存在」+「返回」按钮；加载态：「加载中...」。

错误态：toast「订单ID缺失」「获取位置信息失败」「加载跟踪信息失败」「位置信息不完整」「更新失败」。

标签：配送中 .weui-tag--deliver / 已送达 .weui-tag--done。

设计要点：地图上双标记必须可区分（送水工 / 收货地址不同颜色与图标）；「已送达」后不得继续刷新位置；状态门控——仅「配送中」可进入（现为 mock 绕过判断，为目标缺口）；用户端仅展示概略位置，不下发精确轨迹序列（隐私）； 目标形态：接入真实轨迹数据源 deliveryTrajectories(orderId) / deliveryWorkerLatestLocation(workerId)，缺口 G02、G65。
