组件与度量

组件体系：微信官方 WeUI 2.x，样式来自 assets/weui.css；主题色经 --weui-BRAND 注入品牌蓝 #3A9BD9，灰阶 / 发丝线 / 排版刻度沿用微信官方值。

关键度量：导航栏 44px + 右上胶囊 87×32；原生 TabBar 高 50px、底 #F7F7F7、图标 27px、文字 10px；单元格 17px 主文字、内缩 16px 发丝线；Tab 选中项带品牌蓝短下划线（20×3px）。

价格：所有金额用 .weui-price（微信电商红 #FA5151），符号 / 小数位缩放。

用色：交互主色品牌蓝（导航 / TabBar / 主按钮）；订单状态一律 .weui-tag--pay / --assign / --deliver / --done / --cancel；本屏未使用强调橙（CTA 交品牌蓝承担）。

页面说明

所属端：用户端小程序

功能：F-ORD-002 订单列表（已实现）；「立即支付」F-ORD-005、「取消订单」F-ORD-006 入口；「再来一单」F-ORD-025（规划中， 缺口 G76）。

入口：「我的」页订单入口；下单成功跳转亦到达。

跳转：点订单卡 → 订单详情；「立即支付」→ 支付发起；「再次购买 / 再来一单」→ 写 pendingOrder 跳确认订单页。

数据：componentDidShow / 下拉刷新重载第一页，pageSize=10，触底加载下一页。

布局结构

  1. 状态 Tab（.weui-tabs）：全部 / 待付款 / 待配送 / 配送中 / 已完成（2026-10 已移除「待收货」Tab）
  2. 订单卡（.weui-cells）：门店名 + 订单号 + 状态标签（.weui-tag--*）
  3. 商品行（媒体项）：缩略图 + 名称 + 规格 + 优惠价 × 数量
  4. 下单时间 + 实付金额（.weui-price，精确到分）
  5. 收货人 + 电话 + 地址一行（截断展示，完整可查）
  6. 操作按钮组（.weui-btn_xs，按状态渲染）
  7. 列表尾「没有更多订单了」（.weui-loadmore）+ 原生 TabBar

关键交互

  1. 切换 Tab 重置分页并按状态过滤；「待配送」口径 = 待派单 + 待配送；statuses 为空 = 全部
  2. 待付款 →「取消订单」+「立即支付」；待配送 →「取消订单」+「查看详情」
  3. 配送中 →「查看详情」+「催单」；已完成 →「评价」+「再次购买」
  4. 「立即支付」调 createOrderPayment；「取消订单」调真实 cancelOrder 后刷新；「再次购买」写 pendingOrder 跳确认页
  5. 触底加载下一页；加载中禁止重复拉取

状态与规则 / 设计要点

状态标签口径（7 态映射）：待付款 .weui-tag--pay / 待配送 .weui-tag--assign / 配送中 .weui-tag--deliver / 已完成 .weui-tag--done / 已退款 .weui-tag--cancel；已取消同样以 .weui-tag--cancel 在「全部」Tab 内呈现。

送达即完成：配送中订单仅「查看详情 / 催单」；送达即完成并直接呈现「已完成」，不得出现「确认收货」中间态（R-ORD-11）。

状态：空态「暂无订单」+「去逛逛」；加载态「加载中...」；错误态 toast「获取订单列表失败」。

设计要点：卡片第一行订单号可截断但需完整可查；金额精确到分；「再来一单」目标形态为读取历史 items + 地址快照 → 校验在售与库存 → 剔除失效商品并提示（缺口 G76），现状为最小实现（仅携带商品写 pendingOrder）；消费者端不做无限滚动长列表，仅分页 10 条/页。
