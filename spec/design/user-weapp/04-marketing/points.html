页面说明

所属端：用户端小程序（Taro）

入口：我的页「我的资产 → 积分」

跳转：兑换 → 券 / 水票 / 配件；确认订单页「积分抵扣」区；到期提醒 → 消息中心 / 订阅消息

数据：积分余额、明细（获取 / 消耗 / 过期）、兑换品、所需积分、抵扣比例与上限

功能状态：规划中（缺口 G81），本页为目标形态。

布局结构

  1. 积分余额卡（.mp-statgrid__num 大号数字）+ 即将过期提醒（.weui-notice）
  2. 积分任务（.weui-cells__title + .weui-cells）：每日签到 / 下单得积分 / 评价得积分 / 邀请好友，各带 .weui-btn_xs「去完成」
  3. 明细 Tab：获取 / 消耗（.weui-tabs）+ 明细 .weui-cells（正负用色）
  4. 积分兑换（.weui-cells__title + .weui-cells 行）：券 / 水票 / 配件，所需积分 +「去兑换」
  5. 空态：.weui-empty「暂无积分」+「去做任务」

关键交互

  1. 订单完成 → 按实付金额计积分入账；退款 → 按比例扣回
  2. 签到 / 活动 → 获积分（防刷）；兑换券 / 水票 / 配件（幂等）
  3. 下单选积分抵扣（≤ 上限与可用积分）
  4. 到期前提醒（消息中心 / 订阅消息）

状态与规则

积分不足：不可兑换 / 抵扣，提示「积分不足以抵扣」；空态：「暂无积分」；兑换 loading：按钮转「兑换中…」；重复兑换提示「请勿重复兑换」。

有效期：按获取批次 / 滚动过期；到期前提醒。

规则：积分获取以已完成订单实付金额计；退款按比例扣回、赠出积分作废；积分不可提现 / 转让。

明细配色：获取用 var(--weui-price) 前缀 +，消耗 / 过期用 var(--weui-FG-0) 前缀 -。

组件与度量

基准：微信官方 WeUI 2.x；积分余额为视觉焦点，明细 Tab 选中态为品牌蓝短下划线。

关键度量：导航 44px + 胶囊 87×32；.mp-statgrid__num 19px；.weui-btn_xs 高 24px；.weui-tabs__item 15px；.weui-empty__icon 84px 品牌 tint 圆。

本页组件：.mp-nav / .mp-capsule、.mp-statgrid__num、.weui-notice、.weui-cells / __title / __tips、.weui-tabs、.weui-btn_xs / .weui-btn_plain-primary、.weui-empty、.weui-tag--goal。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G81。

强调橙禁用：本页属「积分 / 资产」类，禁止把强调橙用于非券元素；积分余额、任务按钮、兑换按钮、明细一律用品牌蓝 / 微信电商红 / 语义色。

积分余额为视觉焦点（大号数字）；兑换区清晰标注所需积分。

叠加顺序（积分抵扣与券 / 满减 / 会员折扣）为开放问题；金额统一用 .weui-price，禁止手拼「¥」字符串。
