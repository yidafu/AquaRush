页面说明

所属端：用户端小程序（Taro）

入口：我的页 →「我的优惠券 / 券包」；领券中心领取后回此

跳转：可用券「去使用」→ 商品列表 / 首页选品；空态「去领券中心」→ coupon-center；确认订单页券选择器（order-confirm）由此读取可用券

数据：券名、面额 / 折扣率、门槛、适用范围、有效期、状态

布局结构

  1. 顶部 Tab：可用 / 已使用 / 已过期（.weui-tabs，可选「已退回」）
  2. 券卡列表（.weui-cells）：券名 + 金额 / 折扣 + 门槛 + 适用范围 + 有效期 + 状态操作（.weui-btn_xs「去使用」）
  3. 底部说明：过期券仅保留历史记录（.weui-cells__tips）
  4. 空态：.weui-empty「暂无优惠券」+「去领券中心」（.weui-cell_link）

关键交互

  1. 切换 Tab 过滤券状态；可用券点击券卡 → 跳商品 / 首页选品
  2. 「去使用」→ 进入选品或下单流程
  3. 已使用 / 已过期券只读，按状态降透明度
  4. 确认订单页据此列表提供可选券（此动作在 order-confirm 页完成）

状态与规则

未使用 / 已使用 / 已过期 / 已退回：四态并存；可用券面额显示橙红，其余置灰降透明（面额区灰底 + .weui-tag--done）。

空态：「暂无优惠券」+「去领券中心」；加载态：Loadmore 双短线 / 骨架屏。

R-MKT-07：确认订单勾选一张券后优惠金额计入应付；一单一券不可叠加。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x，主题色经 --weui-BRAND 注入品牌蓝；Tab 选中态为品牌蓝短下划线。

关键度量：导航栏 44px + 胶囊 87×32；.weui-tabs__item 15px、选中 3px 品牌蓝下划线；券卡圆角 8px；页面底 --weui-BG-0。

本页组件：.mp-nav / .mp-capsule、.weui-tabs、.weui-cells、.weui-tag（--done）、.weui-btn_xs、.weui-loadmore、.weui-empty、.weui-cell_link、.weui-price--lg。

设计要点 / 禁忌

券品牌色例外：券卡金额、类型标签、券图标、「去使用」按钮统一使用品牌橙红 var(--action)，按设计系统 §2.1 不受「强调橙仅限 CTA」限制。

已过期券需与可用券明显区分（置灰 + 中性标签 .weui-tag--done），但保留历史可查，不做删除。

券卡沿用「缺口 / 齿孔」形态（圆形遮罩 + 虚线），保持与领券中心同源识别度。

非券元素（Tab、空态说明、返回导航）使用品牌蓝，不用强调橙；金额统一用 .weui-price。
