页面说明

所属端：用户端小程序（Taro）

入口：首页快捷入口「领券中心」、我的页营销入口

跳转：领取成功 → 我的优惠券 coupon-mine；可用券在确认订单页（order-confirm）券选择器中消费

数据：券名称、面额或折扣率、门槛、适用范围、有效期、领取状态（可领取 / 已领取 / 已领完）

布局结构

  1. 顶部导航：「领券中心」（.mp-nav + 微信胶囊）
  2. 组标题「可领取」/「已领取」（.weui-cells__title）
  3. 券卡列表（白底 .weui-cells 内）：左侧面额区（橙红大字号）+ 券名 / 类型标签 / 适用范围 / 有效期 +「立即领取」
  4. 底部说明：券使用规则（.weui-cells + .weui-cell_vertical）

关键交互

  1. 点击「立即领取」→ 领取成功 toast → 按钮变「已领取」并置灰（.weui-btn_disabled）/ 进入券包
  2. 限领数扣减，领完转「已领完」；已领取 / 已领完不可再点
  3. 券卡金额区、类型标签、领取按钮均为券品牌元素，使用品牌橙红
  4. 下拉刷新重新拉取可领取列表

状态与规则

可领取：按钮可点（橙红实心）；已领取 / 已领完：按钮置灰不可点、券卡面额区转灰底（.weui-btn_disabled）；空态：微信官方空态 .weui-empty「暂无可用优惠券」+ 刷新型描边按钮。

R-MKT-07：用户端确认订单 → 满足门槛的可用券列表 → 勾选一张 → 优惠金额计入应付。

券状态机：未领取 → 已领取 / 已核销 / 已过期 / 已退回；一单一券不可叠加。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x，主题色经 --weui-BRAND 注入品牌蓝；灰阶、发丝线、排版刻度用微信官方值。

关键度量：导航栏 44px + 右上微信胶囊 87×32；页面底 --weui-BG-0；单元格 17px 主文字；卡片圆角 8px（.weui-cells）；发丝线 0.5px。

本页组件：.mp-nav / .mp-capsule（淘宝式胶囊）、.weui-cells__title、.weui-cells、.weui-tag、.weui-btn_mini、.weui-btn_disabled、.weui-empty、.weui-price--lg。

设计要点 / 禁忌

券品牌色例外：按设计系统 §2.1，消费者端优惠券的 券卡金额、类型标签、领券按钮、券选择器、券图标 使用品牌橙红 var(--action)，不受「强调橙仅限 CTA」限制，故本页券卡多处橙红为合规。

券卡使用「缺口 / 齿孔」形态（面额区两侧的分割线上、下各一枚圆形遮罩 + 虚线分割）以体现券的形状，一眼可辨金额与门槛。

非券元素（导航、规则说明、空态按钮）一律使用品牌蓝，不用强调橙；金额统一用 .weui-price，禁止手拼「¥」字符串。
