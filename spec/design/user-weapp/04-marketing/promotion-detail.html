页面说明

所属端：用户端小程序（Taro）

入口：首页 / 商品列表活动位 → 活动详情；商品详情特价展示（product-detail，F-PRO-002）

跳转：底部「去凑单」→ 商品列表 / 首页选品；确认订单页展示「活动已减 ¥x」行（order-confirm）

数据：活动 ID、名称、类型、档位（门槛 / 减免或折扣）、适用范围、开始 / 结束时间、状态

布局结构

  1. 活动头图：.banner（活动主题 + 副标题 + 运营实拍图占位），套 .mp-pad 留白
  2. 活动规则（.weui-cells__title + .weui-cells）：满减档位 / 限时特价倒计时 / 买赠规则
  3. 活动商品（「活动商品」+ .mp-grid2）：活动价 .weui-price--md + 划线价 + .weui-progress「已抢 N 件」
  4. 底部操作栏（.mp-footbar）：活动摘要 +「去凑单」（.weui-btn_primary）

关键交互

  1. 配置活动 → 保存上架 → 下单自动减免（无需领券）
  2. 限时特价按活动期自动计价，到期回退分组价 / 目录价
  3. 买赠 / 满赠：订单达标自动追加赠品行（0 价），随单配送
  4. 点击「去凑单」→ 进入选品补足门槛

状态与规则

活动状态：未开始 / 进行中 / 已结束 / 已停用；过期自动失效并在列表状态体现。

优惠叠加：同一订单命中多活动取优惠最大者，不叠加；首单立减与满减互斥取最大。

订单快照：修改档位 / 时间窗后新订单生效，已生成订单不受影响；确认订单展示「活动已减 ¥x」。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x；满减 / 特价为活动（非券）品牌元素，用品牌蓝 var(--brand)。

关键度量：导航 44px + 胶囊 87×32；.banner 高 148px、圆角 8px；.weui-progress 高 4px；.mp-footbar 底白 + 0.5px 顶线；.mp-grid2 两列间距 8px。

本页组件：.mp-nav / .mp-capsule、.banner、.weui-cells / __title、.weui-tag--brand / --orange、.mp-grid2 + .mp-prod、.weui-progress、.weui-price--md / --origin、.mp-footbar + .weui-btn_primary。

设计要点 / 禁忌

强调橙使用：本页 CTA「去凑单」按微信官方主按钮 .weui-btn_primary（品牌蓝）；满减 / 特价为活动（非券）品牌元素，使用品牌蓝 var(--brand)，不使用强调橙。

特价与划线原价视觉区分明显；「已抢 N 件」进度条（.weui-progress）用品牌蓝填充，直观传递紧迫感。

头图用 .banner +「运营实拍图占位 750×360」，严禁卡通插画；金额统一用 .weui-price，禁止手拼「¥」字符串。

不做无限滚动长列表；活动商品限量展示，底部「去凑单」导流补门槛。
