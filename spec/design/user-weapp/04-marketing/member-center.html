页面说明

所属端：用户端小程序（Taro）

入口：我的页「我的资产 → 会员中心」

跳转：权益跳转（优惠券 / 积分 / 会员专享商品）；完成订单后进度与等级更新

数据：当前等级、累计消费、下一级门槛、权益列表、成长值

功能状态：规划中（缺口 G80），本页为目标形态；用户端账户信息「会员等级」现状为占位（F-USR-003）。

布局结构

  1. 渐变等级卡（.phone-screen.is-brand + .hero）：等级名（银卡徽标）+ 成长值进度（.weui-progress）+ 距下一等级差额
  2. 我的权益列表（.weui-cells）：会员折扣 / 免配送费 / 生日礼包 / 专属客服（已享 / 未达门槛）
  3. 等级权益矩阵（「等级权益」+ .weui-cells）：折扣力度 / 免配送费 / 生日券 / 专属客服 × 银卡 / 金卡 / 钻石卡
  4. 会员专享商品（「会员专享商品」+ .mp-grid2）：2 列网格（会员价 + 划线价）
  5. 积分中心入口（.weui-cell_link）+ 升级说明（.weui-cells__tips）
  6. 未达门槛等级：金卡 / 钻石卡门槛与进度（.weui-cells）

关键交互

  1. 实时展示当前等级与成长进度；完成订单后进度与等级自动更新
  2. 点击会员专享商品 → 商品详情；点击积分 / 优惠券入口跳转对应页
  3. 仅本人可见（R-AUTH-02）

状态与规则

当前等级 / 下一等级：进度条（.weui-progress）+ 差额提示；权益：已享（.weui-tag--green）/ 未达门槛（.weui-tag 中性）；禁用：未达门槛权益置灰不可点。

升级门槛递增：累计消费口径 = 已完成订单实付金额（不含押金、退款）。

会员折扣：仅按未命中单价让利（分组价 / 特价 / 新人价）的商品小计生效，商品维度互斥。

组件与度量

基准：微信官方 WeUI 2.x；等级卡在品牌渐变头图（.hero）内，进度条白色填充。

关键度量：导航 44px + 胶囊 87×32；.weui-progress 高 4px、圆角 2px；.mp-grid2 两列间距 8px；.weui-tag 18px / --md 22px。

本页组件：.hero + .phone-screen.is-brand、.mp-nav is-brand / .mp-capsule、.weui-progress、.weui-cells / __title / __tips、.weui-tag（--green / --brand）、.mp-grid2 + .mp-prod、.weui-cell_link、.weui-price--md。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G80（含 G57 / F-MKT-006 收敛）。

强调橙禁用：等级卡、进度条、权益状态均用品牌蓝 + 语义色，不使用强调橙（避免与券品牌混淆）。

等级卡可适度品牌化（渐变头图 + 徽标）营造会员尊享感，但避免过度装饰；进度条与门槛数字须清晰可读。

会员专享商品图严禁卡通插画，用 .mp-prod__cover 占位并标注「实拍图占位」；金额统一用 .weui-price，禁止手拼「¥」字符串。
