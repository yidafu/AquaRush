页面说明

所属端：用户端小程序（Taro）

入口：我的页 →「我的资产」单一入口（券 / 水票 / 套餐 / 积分 / 水桶聚合，2026-10-09 收口决策）

跳转：水票 → 水票商城 / 票夹；套餐 → 套餐商城；优惠券 / 积分 / 水桶账户各入口；确认订单页新增「套餐卡核销」区（与水票核销区同形态）

数据：套餐卡张数 / 桶数、有效期、状态、核销明细

合规：不做用户储值（2026-10-09 决策）——本页无余额卡 / 充值入口 / 余额抵扣；预收资金由水票与套餐卡（预购货物凭证）承接。

功能状态：规划中（缺口 G79），本页为目标形态。

布局结构

  1. 资产概览（.weui-cells）：水票 / 套餐 / 优惠券 / 积分 / 水桶账户入口（.weui-cell__ft_in-access 摘要）
  2. 我的套餐（.weui-cells）：次卡 / 月卡剩余次数与有效期（可用 .weui-tag--brand / 已过期 .weui-tag--done）
  3. 套餐记录（.weui-cells__title + .weui-cells）：购买 / 核销 / 退款 + 次数增减
  4. 空态：.weui-empty「暂无套餐」

关键交互

  1. 购买套餐 → 微信支付（既有 F-ORD-005 链路）→ 按张数 / 桶数生成套餐卡
  2. 下单 → 核销套餐卡抵扣（幂等，对齐 R-MKT-08）
  3. 各入口跳转对应资产页

状态与规则

套餐卡：可用 / 已核销 / 已过期；空态：「暂无套餐」；禁用：过期 / 已用完套餐不可核销。

退款：未核销且未过期可退（原路），已核销 / 已过期不可退（R-MKT-11，对齐 R-MKT-08）。

R-MON-01：金额以分存储，展示转元（两位小数）。

组件与度量

基准：微信官方 WeUI 2.x；套餐状态、入口图标用品牌蓝 / 语义色，唯一券元素（优惠券入口图标）用品牌橙红。

关键度量：导航 44px + 胶囊 87×32；.weui-btn_mini 高 28px；.weui-cell 0.5px 内缩 16px 发丝线；页面底 --weui-BG-0。

本页组件：.mp-nav / .mp-capsule、.weui-cells / __title / __tips、.weui-cell / .weui-cell__ft_in-access、.weui-cell_link、.weui-tag（--brand / --done）、.weui-btn_mini / .weui-btn_primary、.weui-empty。

设计要点 / 禁忌

本页为规划中目标形态，缺口编号 G79。

禁止出现储值元素：余额卡 / 充值按钮 / 余额抵扣 / 「余额不足」文案一律不得出现（用户储值不做，2026-10-09 合规决策）。

强调橙禁用：禁止把强调橙用于非券元素；唯一例外是「优惠券」入口图标，作为券品牌元素使用品牌橙红（设计系统 §2.1）。

凭证类预购合规提示（有效期 / 退款规则）保留；禁止手拼「¥」字符串。
