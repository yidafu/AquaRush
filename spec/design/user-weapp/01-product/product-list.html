页面说明

所属端：用户端小程序

入口：首页顶部搜索栏 / 分类快捷入口（现状为 TODO 占位）

跳转：商品卡 → 商品详情 ?id=xx；加入购物车 → 本地 cart（F-PRO-004）

数据：按关键词 / 规格 / 水源地 / 排序组合查询，分页每页 20 条

布局结构

  1. 顶部：.mp-status + 白底 .mp-nav（标题「全部商品」+ 返回 + 微信胶囊）
  2. 搜索栏：.weui-searchbar__box.start 左对齐放大镜 + 关键词
  3. 排序：.weui-segmented 综合 / 销量 / 价格（可切换升序降序）
  4. 筛选行：.weui-cells 内「规格 / 水源地」，右侧 .weui-cell__ft_in-access 箭头
  5. 商品网格：.mp-grid2 2 列（封面 1:1 实拍图占位 + 名称 + 描述 + 价格 + 已售 / 库存标签）
  6. 加载更多：.weui-loadmore（加载中 / 点击加载更多 / 没有更多）

关键交互与状态

  1. 搜索框输入防抖后触发查询；切换规格 / 水源地即时重查第 0 页
  2. 切换排序方式重查并回到列表顶部
  3. 触底加载下一页并追加；下拉刷新重置到第 0 页
  4. 点击商品卡 → 商品详情；点击加购圆钮 → 本地 cart 累积

空态：无匹配结果显示「没有找到相关商品」+「清空筛选」；加载态：首屏骨架 / 分页 .weui-loadmore 加载中；错误态：toast「加载失败」+「重试」。

筛选：仅返回在售且库存 > 0 的商品（R-PRO-03）；价格以分存储、展示换算为元两位小数（R-MON-01）。

组件与度量

外壳：.mp-nav 白底高 44px + 微信胶囊 87×32；页面底 #EDEDED。

搜索：.weui-searchbar__box 灰底（黑 5%）高 36px / 圆角 8px，.start 左对齐 + 16px 放大镜 SVG。

分段：.weui-segmented 灰底 2px 内衬 + 选中项白底 6px 圆角。

列表：.weui-cells 单元格 17px / 内缩 16px / 最小高 56px；可点行用 .weui-cell_link（--weui-LINK 蓝）；箭头 8px 由 .weui-cell__ft_in-access 生成。

商品卡：.mp-grid2 2 列（gap 8px），.mp-prod__cover 1:1 占位，价格 .weui-price--md 17px，标签 .weui-tag 18px。

加载更多：.weui-loadmore 双短线（32px）+ 14px 灰字。

设计要点 / 禁忌

交互主色统一品牌蓝 --weui-BRAND；金额用微信电商红 #FA5151；链接用 --weui-LINK。本页不使用强调橙 --action。

商品图严禁卡通插画，一律真实摆拍占位；有优惠才出现划线目录价；消费者端不做无限滚动长列表，加载更多显式分页受控。

首页搜索与分类筛选可用、轮播由后台运营配置（F-OPS-001）；缺口 G18（首页搜索入口为 stub）。
