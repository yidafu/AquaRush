页面说明

所属端：用户端小程序（目标形态 pages/cart + utils/cart）

入口：商品详情页「加入购物车」按钮、首页悬浮购物车按钮、我的页「购物车」

跳转：「去结算」携带勾选商品写 pendingOrder → 确认订单页（复用 F-ORD-004 多商品下单）；空态「去逛逛」→ 首页

状态校准：由原「部分实现」按 1.1 校准说明定为「规划中」

布局结构

  1. 顶部：.mp-status + 白底 .mp-nav（带返回 + 微信胶囊）
  2. 购物车列表：.weui-cells 内 .weui-media-box（.weui-checkbox + 72px 缩略图 + 名称 + 规格 + 单价 + .weui-stepper + 小计 + 删除）
  3. 冲突提示条：部分商品库存不足时用 .weui-notice 置顶提示
  4. 底部结算栏：.mp-footbar（全选 .weui-checkbox + 合计 .weui-price--lg + .weui-btn_primary「去结算」）
  5. 库存不足弹窗：.weui-mask + .weui-dialog（标题 + 正文 + 两按钮）
  6. 空态：.weui-empty 引导去首页逛一逛，结算禁用

关键交互与状态

  1. 详情页「加入购物车」→ 写本地 cart 累积多商品 → toast「已加入购物车」
  2. 调整数量 / 勾选 / 删除 → 合计金额实时汇总（分 → 元）
  3. 「去结算」→ 携带勾选多商品进确认订单页
  4. 数量调整超库存 → 拦截并提示「库存不足」（R-PRO-01）

空态：无商品显示空态引导「去逛逛」，结算不可用；加载态：本地读取瞬时完成（无网络请求）；错误态：本地数据损坏时提示并清空。

禁用态：无勾选商品时「去结算」用 .weui-btn_disabled 禁用。库存校验：各商品分别校验，部分缺货整体拦截并提示缺货项；数量 ≤ 库存；同商品按 productId 合并数量。

组件与度量

复选：.weui-checkbox 22×22 / 圆角 4px，选中 .on 转品牌蓝 + 白色对勾；圆形加 --circle。

列表：.weui-cells 白底上下 0.5px 发丝线；.weui-media-box 内缩 16px、行间 0.5px 发丝线；缩略图 .weui-media-box__thumb 72×72 / 圆角 8px。

步进：.weui-stepper 高 28px（按钮 28×28、数值区 38px、背景 #F7F7F7）。

价格：单价 .weui-price--md 17px、小计 --sm 15px、合计 --lg 22px，一律微信电商红 #FA5151。

底部栏：.mp-footbar 白底 + 发丝顶线，.weui-btn 高 48px / 圆角 8px / min-width 120px。

弹窗：.weui-mask（黑 60%）+ .weui-dialog 宽 280px / 圆角 12px，按钮行 56px 高、左右 0.5px 分隔线。

设计要点 / 禁忌

交互主色统一品牌蓝 --weui-BRAND；金额用微信电商红 #FA5151；危险 / 删除用 --weui-RED；库存不足提示用 .weui-tag--orange。本页不使用强调橙 --action。

R-MON-01：金额以分存储、展示换算为元两位小数，合计走汇总逻辑；统一用 .weui-price，不手拼 ¥。

商品图用 .weui-media-box__thumb 占位并标「实拍图占位」，严禁卡通插画。

目标形态：pages/cart 购物车页、详情页「加入购物车」按钮激活（缺货禁用）、同商品合并数量；缺口 G03 已解决。
