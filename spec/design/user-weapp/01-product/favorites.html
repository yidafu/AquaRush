页面说明

所属端：用户端小程序（BasePageLayout 承载）

入口：我的页「我的收藏」（收藏 / 取消在商品详情页 F-PRO-002 执行）

跳转：商品卡 → product-detail?id=xx；空态「去逛逛」→ 回首页

刷新：useDidShow 检查登录态并刷新；详情页取消收藏后返回自动刷新列表

布局结构

  1. 顶部：.mp-status + 白底二级页 .mp-nav（带 .mp-nav__back + 微信胶囊）
  2. 页头统计：.weui-cells__title「共 N 件收藏」
  3. 收藏列表：.weui-cells 内 .weui-media-box（72px 缩略图 + 名称 + .weui-price + 已售 + 缺货 .weui-tag--orange），整卡可点击进详情
  4. 加载更多区：.weui-loadmore「没有更多了」
  5. 空态容器：无收藏引导空态 / 未登录登录引导空态（.weui-empty）

关键交互与状态

  1. useDidShow 检查登录态，已登录刷新第 0 页；未登录展示登录引导空态
  2. 下拉刷新重置第 0 页；触底加载下一页（每页 20）
  3. 点击商品卡 → 商品详情；返回后 useDidShow 自动刷新

空态：「暂无收藏」「快去收藏喜欢的商品吧」+「去逛逛」；加载态：首屏 loading、加载更多 .weui-loadmore；错误态：toast「加载失败」。

禁用态：未登录时不加载列表、只展示登录引导。缺货：缺货商品标「暂时缺货」且仍可点击进详情。

组件与度量

外壳：二级页 .mp-nav 44px + 返回箭头 .mp-nav__back（左 6px）+ 微信胶囊 87×32，无 TabBar，保留 .home-indicator。

列表：.weui-cells 白底上下 0.5px 发丝线；.weui-media-box 内缩 16px、行间 0.5px 发丝线；缩略图 .weui-media-box__thumb 72×72 / 圆角 8px。

文字：名称 .weui-media-box__title 17px / 行高 1.4 单行省略；描述 14px 灰；时间 / 已售 12px 弱灰。

价格与标签：金额 .weui-price--md 17px（微信电商红 #FA5151）；缺货 .weui-tag--orange 高 18px。

空态：.weui-empty（84px 品牌蓝 tint 圆 + 36px 图标 + 14px 文案 + .weui-btn_plain-primary.weui-btn_mini 28px 描边按钮）。

设计要点 / 禁忌

交互主色统一品牌蓝 --weui-BRAND；金额用微信电商红 #FA5151；危险用 --weui-RED。本页不使用强调橙 --action。

R-MON-01：价格展示换算为元两位小数，统一走 .weui-price；缺货标用 .weui-tag--orange，不复用订单状态色。

缩略图用 .weui-media-box__thumb 占位并标「实拍图占位」，严禁卡通插画。
