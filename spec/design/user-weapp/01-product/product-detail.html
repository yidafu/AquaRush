页面说明

所属端：用户端小程序（Taro）

入口：首页商品卡、我的收藏页、订单相关页携带商品 id 进入

跳转：立即购买 → 购买弹层 → 写 pendingOrder → 确认订单页；客服 → 拨打门店电话；分享 → showShareMenu

容错：无 id / 无效 id → toast「产品ID缺失」后返回

布局结构

  1. 顶部：.mp-status + 白底 .mp-nav（二级页带 .mp-nav__back + 微信胶囊）
  2. 图片画廊：.banner 1:1 实拍图占位 + .banner-dots 分页点（点击可全屏预览）
  3. 商品信息组：.weui-cells__title + .weui-cells（价格区 / 名称 / 副标题 / 已售·剩余 / 规格 / 押金桶 / 配送说明「当日达」）
  4. 详情图文组：.weui-cells 内富文本 + 详情实拍图占位（无详情则隐藏）
  5. 底部操作栏：.mp-footbar（收藏 ♡ / 客服 ☎）+ .weui-btn_primary「立即购买」
  6. 购买弹层：.weui-mask + .weui-half（商品行 + 数量步进 1~库存 + 合计 + 取消 / 确认）

关键交互与状态

  1. 加载详情，网络错误最多重试 3 次（间隔 1s），加载中展示骨架屏
  2. 收藏未登录 → toast「请先登录」；已登录切换 → toast「已添加收藏 / 已取消收藏」
  3. 立即购买 → 打开购买弹层；数量超库存拦截「库存不足」；确认后写 pendingOrder 进确认订单页
  4. 客服直接拨打门店电话；下拉刷新重载详情并停止动画

空态：商品不存在「产品不存在」+「返回」；错误态：toast「产品不存在」「加载失败，请检查网络后重试」。

禁用态：库存 ≤ 0 或非在售时按钮 .weui-btn_disabled 显示「暂时缺货」（R-PRO-01 / R-PRO-03）；有优惠才出现划线目录价（R-MON-01）。

组件与度量

外壳：导航栏 .mp-nav 高 44px，右上微信胶囊 .mp-capsule 87×32（圆角 16）。

列表：.weui-cells 主文字 17px / 行高 1.41 / 白底上下 0.5px 发丝线；.weui-cell 内缩 16px、最小高 56px；组标题 .weui-cells__title 14px 灰。

价格：金额一律 .weui-price（微信电商红 #FA5151），主价 --lg 22px，划线原价 .weui-price--origin 13px 灰划线。

标签：.weui-tag 高 18px，--red（限时特价）/ --brand（熟客价）/ --green（在售）/ --orange（暂时缺货）。

弹层：.weui-mask + .weui-half（圆角 12px、max-height 78%）；数量步进 .weui-stepper 高 28px（数值区 38px）；按钮 .weui-btn 高 48px / 圆角 8px，底部栏 .mp-footbar 白底 + 发丝顶线。

设计要点 / 禁忌

交互主色统一品牌蓝 --weui-BRAND；金额用微信电商红 #FA5151；链接用 --weui-LINK，危险用 --weui-RED。本页不使用强调橙 --action。

R-MON-01：金额以分存储、展示换算为元并两位小数，统一走 .weui-price，不手拼 ¥ 字符串。

商品图严禁卡通插画，一律真实场景摆拍占位；按规格展示可退水桶押金（R-MON-03）。

详情页「加入购物车」按钮（缺货禁用，F-PRO-004，缺口 G03 已解决）。
