组件体系

基准：微信官方 WeUI 2.x，主题色经 --weui-BRAND 注入奔泉品牌蓝 #3A9BD9；灰阶、发丝线、排版刻度用微信官方值。

关键官方特征：导航栏 44px + 右上微信胶囊 87×32；原生 TabBar 高 50px、底 #F7F7F7、图标 27px、文字 10px；页面底 #EDEDED；单元格 17px 主文字、行高 1.41、0.5px 内缩 16px 发丝线；网格用官方 Grids；加载更多用官方 Loadmore 双短线。

价格：微信电商惯例红 #FA5151，货币符号与小数位缩放。

页面说明

所属端：用户端小程序（Taro）

入口：小程序启动默认页；下拉刷新 / 触底加载为页内交互

跳转：商品卡 → 商品详情 ?id=xx；轮播「快速下单」→ 下单流程；TabBar → 订单 / 我的

数据：首屏第 0 页，每页 20 条，创建时间倒序；仅返回在售且库存 > 0 的商品

布局结构

  1. 渐变头图：状态栏 + 导航栏（微信胶囊）+ 定位行 + 搜索框
  2. 运营轮播位：3 张自动轮播，首张 CTA「快速下单」+ 指示点
  3. 通告栏（.weui-notice，橙色 tint）
  4. 快捷入口（.weui-grids 官方四宫格）
  5. 「推荐产品」组标题（.weui-cells__title）+ 商品网格 2 列
  6. 加载更多（.weui-loadmore 双短线）
  7. 原生 TabBar：首页 / 订单 / 我的

商品卡规格

封面 1:1（.mp-prod__cover 实拍图占位）+ 名称最多 2 行 + 描述 1 行 + 价格行 + 加购圆钮。

有营销优惠 → 优惠价 + 划线目录价并存（价格红 + 划线灰）；无优惠则只显示目录价，不出现划线价。

库存偏低用 .weui-tag--orange「仅剩 N 桶」；营销价来源用 .weui-tag--brand「熟客价」。

关键交互

  1. 首屏加载第 0 页；下拉刷新重置；触底且 hasMore 时追加下一页
  2. 点击商品卡 → 商品详情；点击加购圆钮 → 加入购物车（目标形态）
  3. 点击轮播「快速下单」→ 下单流程（地址 → 确认订单）
  4. 加载失败 → 「加载失败」+ 重试；分页失败 → 顶部提示（.weui-toptips）

状态与规则

空态：官方空态（品牌蓝 tint 圆 + 双行文案 + 描边重试按钮）；加载态：「加载中…」与 Loadmore loading；禁用态：hasMore=false 时显示「没有更多产品了」。

R-PRO-03：下架 / 售罄商品用户端不展示，由服务端过滤。R-MON-01：金额以分存储，展示时换算为元。

设计要点 / 禁忌

品牌蓝承担交互主色（导航、TabBar 选中、Grid 图标、加购钮）；价格红 #FA5151 仅用于金额，不用于按钮与图标。

强调橙 --action 仅保留给优惠券品牌元素与最高优先级 CTA（本页仅轮播「快速下单」1 处）。

商品图严禁卡通插画，必须真实场景摆拍；首屏核心信息 ≤ 3 个（定位 / 时效 / 高频购买），不做分类导航、不做无限滚动。

搜索与分类筛选可用（缺口 G18）；轮播图由后台运营配置驱动（F-OPS-001）。
