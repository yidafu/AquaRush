组件与度量

组件体系：微信官方 WeUI 2.x，组件类全部来自 assets/weui.css，壳层（设备 / 标注）复用 ui.css；交互主色经 --weui-BRAND 注入品牌蓝。

本页组件：.mp-nav（二级页，含 .mp-nav__back / .mp-capsule）+ .weui-searchbar__box + .weui-cells__title / .weui-cells / .weui-cell（__bd / __ft / .weui-cell__icon）+ .weui-tag（--brand）+ .weui-radio + .weui-actionsheet（__cell_warn）+ .weui-dialog + .weui-empty + .mp-footbar。

度量：导航栏 44px（右上微信胶囊 87×32）；单元格 17px 主文字、行高 1.41、最小触达 56px；发丝线 0.5px 且左缩 16px；页面底由 --weui-BG-0 提供、单元格底 --weui-BG-2 为白。

配色：交互主色品牌蓝；危险 / 删除用 var(--weui-RED)；本页无金额、无强调橙。

页面说明

所属端：用户端小程序

入口：「我的」页「收货地址」；选择模式由确认订单页地址卡 navigateTo address-list?select=true

跳转：编辑 → address-edit?id=xx；导入微信地址 → address-edit?fromWechat=true；选择模式点「选择此地址」→ 回填确认订单页并 navigateBack

数据：收货人 / 手机号 / 省市区 + 详细地址 / 楼层 / 门牌 / 标签 / isDefault / 地址 id / select 标记

布局结构

  1. 导航栏（二级页）：返回 + 「收货地址」+ 右上微信胶囊
  2. 搜索栏一行：放大镜图标 + 「搜索手机号或地址」
  3. 「导入微信地址」次级小按钮（右对齐）
  4. 组标题 + 地址单元格：默认标签 .weui-tag--brand + 收货人（17px）+ 手机号 + 完整地址 + 楼层/门牌 + 标签；右侧编辑图标
  5. 选择模式：每项右侧 .weui-radio.on 单选 + 「选择此地址」
  6. 吸底主按钮「新增收货地址」（.mp-footbar + .weui-btn_primary）
  7. 删除操作菜单（.weui-actionsheet）+ 删除二次确认（.weui-dialog）

状态与规则

空态：「暂无收货地址」+「添加您的收货地址，方便快速下单」（.weui-empty）；搜索空：「未找到匹配地址」+「试试其他搜索词」；加载态：「加载中...」；错误态：Toast「获取地址列表失败」；授权被拒：「需要获取您的微信地址信息，请在设置中开启授权」。

唯一性：「默认」标签全列表唯一且必须显眼；破坏性：删除红色文案 + 二次确认（.weui-actionsheet__cell_warn → .weui-dialog），确认后不可恢复。

选择模式差异：卡片可点并带明确「选择此地址」按钮 + 右侧单选，非选择模式不出现该按钮；useDidShow 拉取列表（编辑页返回自动刷新），支持下拉刷新。

设计要点 / 禁忌

Web 风旧组件（卡片 / 列表 / 按钮 / 标签 / 开关 / 勾选 / 遮罩弹层等旧类名）一律禁用，全部以 WeUI 等价类实现；本页金额不涉及，状态标签仅用 .weui-tag--*。

删除与「确认删除」用语义红（var(--weui-RED)），不得使用强调橙；触达行高 ≥ 44px（单元格最小 56px）。

删除「最后一个地址」未强制拦截，仅业务期望（缺口候选，R-ADR-01 扩充）；选择模式依赖本地 selectedAddress 缓存与 F-ORD-001 地址卡回显联动。
