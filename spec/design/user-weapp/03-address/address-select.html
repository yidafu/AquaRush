组件与度量

组件体系：微信官方 WeUI 2.x；范围提示用官方 .weui-notice（--brand 通过 / --red 拦截），加载用官方 .weui-loadmore_loading + .spinner。

本页组件：.mp-nav（二级页）+ .weui-cells / .weui-cell（地址选择，右侧 .weui-radio.on）+ .weui-notice--red / --brand + .weui-btn_plain-primary「更换地址 / 联系客服」+ .weui-price（合计）+ .mp-footbar + .weui-loadmore_loading + .weui-tag--goal。

度量：导航栏 44px、胶囊 87×32；单元格最小 56px、17px 主文字；通告栏内边距 10px 16px、14px 文字；按钮高 48px、圆角 8px。

配色：通过态用品牌蓝 tint，拦截态用 var(--weui-RED) 10% tint + 红字；金额一律 .weui-price（微信电商红）；不使用强调橙。

页面说明

所属端：用户端小程序（位于确认订单页地址卡下方校验结果提示区）

入口：提交订单前触发范围校验；范围外「更换地址」跳地址列表选择模式，「联系客服」拉起客服会话

跳转：更换地址 → address-list?select=true；联系客服 → 客服会话

数据：收货地址省 / 市 / 区、是否落入任一启用片区、可达标记 inRange

布局结构

  1. 导航栏（二级页）：返回 + 「确认订单」+ 右上微信胶囊
  2. 地址单元格：收货人 / 电话 / 完整地址 + 右侧选中 .weui-radio.on
  3. 校验结果提示条：范围内 .weui-notice--brand「配送范围内」；范围外 .weui-notice--red「该地址暂不支持配送」
  4. 范围外：不支持原因 + 就近片区提示 + .weui-btn_plain-primary「更换地址」「联系客服」
  5. 商品清单与合计金额（.weui-price）
  6. 吸底「提交订单」主按钮（范围外 / 校验中禁用）

状态与规则

空态：无可达区域时全部地址不可下单；加载态：校验中（.weui-loadmore_loading + 按钮禁用 + 提示「校验中...」）；错误态：校验接口异常时降级放行，避免误拦正常下单；禁用态：范围外时提交按钮 .weui-btn_disabled。

拦截提示必须给出明确出路（换地址 / 联系客服），避免死胡同；范围拦截优先在后端提交链路执行，前端提示与之对齐。

设计要点 / 禁忌

Web 风旧组件（通告栏 / 金额行 / 底部操作栏 / 卡片 / 骨架屏等旧类名）一律禁用，全部以 WeUI 等价类实现；Web 风描边按钮替换为 .weui-btn_plain-primary。

范围警告用语义红（10% tint 底 + 红字），不得用强调橙做警告；金额一律 .weui-price；校验异常必须降级放行（不可误拦正常下单）。

现状 isAddressInDeliveryArea() 恒返回 true（缺口 G07），校验关闭、前端无拦截，本页 UI 全部为规划形态；依赖 F-ADR-013 配送片区数据先落地（缺口 G78），「就近片区」提示依赖片区坐标。
