组件与度量

组件体系：微信官方 WeUI 2.x；表单用官方 .weui-cells + .weui-cell（含 __hd / __bd / __ft），必填标记用 .weui-label--req，箭头用 .weui-cell__ft_in-access。

本页组件：.mp-nav（含 .mp-nav__right「删除」）+ .weui-input + .weui-textarea + .weui-cell_switch（.weui-switch）+ .weui-tag--md 芯片 + .map 选点（ui.css 壳层）+ .weui-toptips + .weui-btn_area / .weui-btn_primary。

度量：单元格最小 56px、17px 主文字、行高 1.41；发丝线 0.5px 左缩 16px；开关 51×31；地图高 200px；按钮区 16px 内边距、圆角 8px。

配色：交互主色品牌蓝；行内校验红字用 var(--weui-RED)；「删除」为语义红；本页金额不涉及，不使用强调橙。

页面说明

所属端：用户端小程序

入口：地址列表「新增收货地址」/「编辑」（?id=xx）；微信地址导入（fromWechat=true）

跳转：保存成功 Toast 后 1.5s navigateBack 回地址列表

数据：收货人 / 手机号 / 省 / 市 / 区 / 详细地址 / 楼层 / 门牌 / 标签 / longitude / latitude（可空）/ isDefault / 地址 id

布局结构

  1. 导航栏（二级页）：返回 + 标题「编辑地址」+ 右侧「删除」（新增态为「新增收货地址」，无删除）
  2. 表单行：收货人 / 手机号 / 所在地区（.weui-cell__ft_in-access）/ 详细地址
  3. 表单行：楼层 / 门牌 / 标签芯片（.weui-tag--md，选中 --brand）
  4. 地图选点区（高 200px，含定位 / 缩放控件与手动点选）
  5. 「设为默认地址」开关行（.weui-cell_switch + .weui-switch）
  6. 底部按钮区 .weui-btn_area 内 .weui-btn_primary「保存地址」

状态与规则

加载态：「正在加载地址详情...」「加载地区数据...」「保存中...」（状态三按钮 .weui-btn_disabled）；错误态：字段校验行内红字（状态二），顶部 .weui-toptips；Toast「保存失败，请重试」「地区加载失败: ...」；禁用态：提交 loading 期间按钮禁用；空态：无。

校验文案：「请输入收货人姓名」「收货人姓名至少2个字符」「收货人姓名不能超过20个字符」；「请输入手机号」「手机号格式不正确」；「请选择省份 / 城市 / 区域」；「请输入详细地址」「详细地址至少5个字符」「详细地址不能超过100个字符」；「请选择省市区」；「请输入详细的收货地址，不少于5个字符」。

地图文案：「地图位置已更新」「已选择地图位置」；保存成功「地址添加成功」/「地址更新成功」。

设计要点 / 禁忌

Web 风旧组件（表单行 / 输入 / 开关 / 卡片 / 底部操作栏等旧类名）一律禁用，全部以 WeUI 等价类实现；行内校验用语义红 var(--weui-RED)，不用强调橙。

三级联动（行政区划）与地图选点（地图坐标）是两个独立通道，须清晰区分；地图选点失败允许手动填详细地址，经纬度可空不影响入库；提交期间禁止重复点击（防重复提交）。

坐标边界转换（gcj02ToWgs84 / wgs84ToGcj02）为既有实现细节；省市区为底部弹层三级联动 Picker，保存与校验以 Toast / 行内红字呈现，不新增独立页面。
