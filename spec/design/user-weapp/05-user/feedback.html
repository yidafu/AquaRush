组件与度量

组件体系：微信官方 WeUI 2.x；类型为可点选 .weui-tag--md 芯片（选中加 --brand），内容用官方 .weui-textarea + .weui-textarea__counter，图片用官方 .weui-uploader。

本页组件：.mp-nav（二级页）+ .weui-cells__title / .weui-cells + .weui-tag--md + .weui-textarea / __counter + .weui-cell「图片（≤3 张）」+ .weui-uploader__file / __input + .weui-input（联系方式）+ .weui-btn_area / .weui-btn_primary / .weui-btn_disabled。

度量：导航栏 44px、胶囊 87×32；单元格最小 56px、17px 主文字；文本域最小高 96px、内边距 16px；上传方块 78×78、圆角 8px；按钮高 48px。

配色：类型芯片选中用品牌蓝；链接「我的反馈记录」用 var(--weui-LINK)；本页金额不涉及、不使用强调橙。

页面说明

所属端：用户端小程序

入口：「我的」页「常用服务 → 意见反馈」

跳转：页脚「我的反馈记录 ›」→ feedback-records；提交成功后清空表单（不跳转）

数据：type（反馈类型）、content（10-500 字）、images（≤3 张 fileUrl）、contact（联系方式，可选）、userId（登录主体）

布局结构

  1. 导航栏（二级页）：返回 + 「意见反馈」+ 右上微信胶囊；副标题「您的意见对我们很重要」
  2. 「反馈类型」组标题 + 类型芯片单选（必选）：产品质量问题 / 配送服务问题 / 小程序使用问题 / 功能建议 / 投诉建议 / 其他问题
  3. 「反馈内容」组标题 + .weui-textarea（≥10 字，≤500 字）+ .weui-textarea__counter（38/500）
  4. 「图片（≤3 张）」组标题 + .weui-uploader（已选 2 张 + 加号）
  5. 联系方式行（选填，.weui-input）
  6. .weui-btn_area 内 .weui-btn_primary「提交反馈」
  7. 底部说明：处理时效 + 客服热线 +「我的反馈记录 ›」入口

状态与规则

空态：表单初始为空，字数统计 0/500；加载态：提交按钮「提交中...」+ .weui-btn_disabled 禁用（状态二）；错误态：提交失败 Toast「提交失败，请重试」；禁用态：提交中禁用按钮防重复（幂等，仅一次提交）。

校验文案：「请选择反馈类型」「请输入反馈内容」「反馈内容至少输入10个字」；成功「提交成功，感谢您的反馈」；图片超 3 张不再增加。提交需登录态（服务端 isAuthenticated() 强制，userId 取登录主体，防越权）。

设计要点 / 禁忌

Web 风旧组件（芯片 / 表单行 / 文本域 / 缩略图 / 卡片 / 底部操作栏 / 按钮等旧类名）一律禁用，全部以 WeUI 等价类实现；类型芯片选中态用品牌蓝，不用强调橙。

类型为胶囊单选（非下拉）；图片区最多 3 张并显示删除角标；客服热线动态读取（文案与「关于页」一致口径）；提交结果以 Toast 轻提示呈现，不弹窗阻断。

类型芯片共 6 类（按规格 07-user.md 状态与标签）；处理结果回传闭环依赖 F-OPS-003 后台处理（12-operations-config.md）。
