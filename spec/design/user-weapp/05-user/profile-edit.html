组件与度量

组件体系：微信官方 WeUI 2.x；表单用官方 .weui-cells + .weui-cell，输入用 .weui-input，选择箭头用 .weui-cell__ft_in-access，反馈用官方 .weui-toast。

本页组件：.mp-nav（二级页）+ .weui-cell（__bd / __ft_in-access）+ .weui-media-box__thumb--sm（48px 圆头像）+ .weui-input + .weui-cells__tips + .weui-btn_area / .weui-btn_primary / .weui-btn_disabled + .weui-toast（含对勾图标）。

度量：导航栏 44px、胶囊 87×32；单元格最小 56px、17px 主文字、行高 1.41；发丝线 0.5px 左缩 16px；头像 48px；按钮高 48px；Toast 136×136、圆角 12px。

配色：交互主色品牌蓝；手机号只读为灰字（--weui-FG-2）；成功反馈 Toast 为深色半透明 + 白字；本页无金额、无强调橙。

页面说明

所属端：用户端小程序

入口：「我的」页用户区弹头像昵称表单（仅头像昵称）；或独立 profile-edit 页（完整资料编辑）

跳转：保存成功 1.5s 后 navigateBack 返回上一页

数据：头像 avatarUrl、昵称 nickname、性别、手机号 phone（脱敏只读）、生日

布局结构

  1. 导航栏（二级页）：返回 + 标题「编辑资料」+ 右上微信胶囊
  2. 头像行：右侧 48px 圆头像 + 箭头（.weui-cell__ft_in-access）
  3. 昵称输入（.weui-input，2-20 字符）
  4. 性别选择（箭头：「男」）
  5. 手机号只读（脱敏灰字，不可改）
  6. 生日选择（箭头：「1995-08-16」）
  7. 底部按钮区 .weui-btn_area 内 .weui-btn_primary「保存」

状态与规则

空态：未登录提示后返回；加载态：「加载中...」/ 保存「正在保存...」（状态二按钮 .weui-btn_disabled）；错误态：校验错误行内展示 + Toast「请修正表单错误」；禁用态：无修改时「保存」置灰，loading 期间表单禁用。

校验文案：「请输入昵称」「昵称至少2个字符」「昵称不能超过20个字符」「昵称只能包含中文、英文、数字、下划线和空格」「请输入手机号」「请输入正确的手机号格式」「没有修改内容」「保存成功」「请先登录」「请修正表单错误」「正在保存...」。

设计要点 / 禁忌

Web 风旧组件（表单行 / 单选行 / 卡片 / 缩略图 / 底部操作栏 / 遮罩弹层等旧类名）一律禁用，全部以 WeUI 等价类实现。

手机号为只读态（灰字 --weui-FG-2），须有明确不可改说明；成功反馈用官方 .weui-toast（对勾 + 白字），非强调橙；触达行高 ≥ 44px；头像区不做卡通插画风占位。

规格中的「账户信息只读区」（用户ID / 会员等级 / 积分 / VIP 到期）因 UserInfo 接口字段已注释、可能为空，是否保留为开放问题（随 F-MKT-011/012 落地时定），本稿暂不呈现；余额字段不再规划（用户储值不做，2026-10-09 合规决策）；手机号键盘为数字键盘。
