组件与度量

组件体系：微信官方 WeUI 2.x；渐变头部（.phone-screen.is-brand + .hero）、资产入口用官方 .weui-cells、订单入口用官方 .weui-grids、服务列表用官方 .weui-cells、授权引导用官方 半屏弹层 .weui-mask + .weui-half。

本页组件：.mp-status / .mp-nav.is-brand / .mp-capsule + .weui-tag（会员等级）+ .weui-cells__title + .weui-panel / .weui-grids（5 列，.weui-badge 角标）+ .weui-cell / .weui-cell__icon--brand / .weui-cell__ft_in-access + .weui-checkbox + .weui-btn_area / .weui-btn_primary / .weui-btn_plain-default + .weui-cells__tips + .weui-empty + .mp-tabbar。

度量：导航栏 44px、胶囊 87×32；TabBar 高 50px、底 --weui-BG-1、图标 27px、文字 10px；单元格最小 56px、17px 主文字；半屏弹层圆角 16px、最大高 78%；按钮高 48px、圆角 8px（WeUI 官方）。

配色：交互主色品牌蓝（图标、TabBar 选中）；金额 .weui-price（微信电商红 #FA5151）；未读 / 角标用 var(--weui-RED)；链接色 var(--weui-LINK)；本页不使用强调橙。

页面说明

所属端：用户端小程序（tabBar 页）

入口：tabBar「我的」

跳转：资产入口 → 04-marketing/assets.html；订单区 → order-list?tab=类型；服务区 → favorites / address-list / subscriptions / member-center / message-center / feedback / feedback-records / about

登录承载：用户端不设独立登录页。需要身份的动作（结算 / 我的订单 / 资产 / 收藏 / 地址）触发半屏授权引导弹层，登录成功后就地返回原动作，不跳页。

与 PRD 的口径调和：PRD 07-user.md §F-USR-001 为「静默登录（免授权弹窗，code 换 token）」。因此登录本体仍是静默的——启动即 code 换 token，不弹窗、不拦截浏览；弹层只承载「手机号 + 订阅消息」这类需要用户手势的授权补充，且仅在用户主动点击需登录动作时出现，关闭后停留游客态。若产品要求严格贴合字面，可把弹层降级为纯 toast +「正在登录...」。

数据：用户信息（头像 / 昵称 / 手机号）；订单统计 total / pendingPayment / pendingDispatch+pendingDelivery（待配送口径）/ delivering / completed / cancelled / refunded；资产汇总 balance / couponCount / ticketCount / points / barrelCount

布局结构

  1. 渐变头部：头像 + 昵称 + 手机号脱敏 + 会员等级标签 + 右箭头

关键交互

  1. 点击渐变头部（头像/昵称区）→ 已登录：弹出头像昵称表单；游客：弹出授权引导弹层（状态三）
  2. 点击「我的资产」单元格 → 进入 我的资产 页，在页内下钻水桶账户 / 水票 / 优惠券 / 积分
  3. 点击订单 5 入口 → order-list 并带上对应 Tab；点击「查看全部」→ 全部订单
  4. 点击服务项 → 对应二级页；未登录时统一先弹授权引导弹层
  5. 弹层内点击「微信一键登录」→ 未勾选协议时 .weui-toptips 提示「请先阅读并同意用户协议」并中止；已勾选则拉起微信授权 → 成功后关闭弹层并继续原动作
  6. 点击「暂不登录，先逛逛」或关闭图标 → 关闭弹层，停留游客态；点击「退出登录」→ 二次确认 → 回游客态

状态与规则

空态：无头像显示默认头像字母（游客态显示「游」）；无订单角标不显示数字；游客态：昵称「游客」+「点击头像授权登录」，资产摘要显示「登录后查看…」、角标全 0（状态二）；加载态：「加载中...」；错误态：获取用户信息失败回退游客态；禁用态：登录中禁用重复触发并显示 loading。

资产口径：无储值余额（用户储值不做，2026-10-09 合规决策，资产入口不显示金额）；角标规则 >99 显示 99+；待配送口径 = 待派单 + 待配送。useDidShow 加载用户信息与订单统计；未登录回退游客态且不发起需登录请求。

授权规则：授权信息仅用于下单 / 配送 / 售后；拒绝授权后降级为「仅站内消息」，订单进度仍可在消息中心查看；订阅消息授权与登录授权分离（见 subscription-auth）。

设计要点 / 禁忌

Web 风旧组件（卡片 / 四列宫格 / 快捷入口 / 旧 TabBar / 缩略图等旧类名）一律禁用，全部以 WeUI 等价类实现；本页不出现强调橙，资产数字与单元格图标一律品牌蓝，角标仅用语义红。

资产区 / 订单区 / 常用服务 / 退出登录自上而下分区清晰；触达行高 ≥ 44px（单元格最小 56px）；「设置」为现状死链，本稿不呈现待清理。

资产入口已收口：水桶账户 / 水票 / 套餐 / 积分 / 优惠券不再在「我的」平铺，统一聚合为「我的资产」一个入口，再在资产页内下钻（04-marketing/assets.html）；本页只保留一个资产入口，避免同一资产出现两处入口；无储值余额（用户储值不做，2026-10-09 合规决策，资产摘要不含余额）。

消息中心入口为 目标形态（F-NTF-002），未读数与消息中心联动；用户端登录以授权引导弹层承载（非独立页面），与 PRD「免授权弹窗、静默登录」口径一致。
