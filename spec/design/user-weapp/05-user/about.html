本页组件：.mp-status / .mp-nav.is-brand / .mp-capsule + .weui-cells__title / .weui-cells + .weui-media-box / __title / __desc + .weui-cell__icon--brand + .weui-cell__ft_in-access（入口箭头）+ .weui-cell__ft（可点电话用 var(--weui-LINK)）。

  1. 渐变头部：水滴标识 + 品牌名 奔泉 + 副标题「像点外卖一样方便地买水」+ 版本号 v1.0.0（居中）

  6. 底部版权

状态与规则

静态页，无加载态 / 错误态 / 空态 / 禁用态；品牌荣誉为标签展示。

客服电话由 CONTACT_INFO.SERVICE_HOTLINE 呈现，服务时间「8:00 - 21:00 (节假日照常服务)」，与意见反馈页口径一致；内容变更仅改常量，不在页面内硬编码业务数据。

设计要点 / 禁忌

Web 风旧组件（列表 / 列表项 / 列表图标 / 箭头 / 分区标题 / 卡片等旧类名）一律禁用，全部以 WeUI 等价类实现。

本页无主 CTA，不出现强调橙；品牌视觉遵循主色（渐变头），页面内不出现裸 hex；客服电话作为可拨打项须有明确可点样式（触达 ≥ 44px），列表项图标统一品牌蓝。

「资质证照」为文档入口占位（依规格品牌荣誉 / 资质展示，无独立页面编号）；内容来自常量，禁止在页面内硬编码版本号以外的业务数据。
