# 营销域(MKT)

> 覆盖客户分组(营销受众)、价格策略(分组商品专属价,熟客价)、优惠券、满减/折扣、限时特价、会员折扣、桶水票(电子票)、买赠/满赠、首单立减(新人专享价)等营销玩法,并集中定义营销计价链路与叠加规则(R-MKT-01~10)。营销计价由订单域应用(F-ORD-023)、用户端商品价展示由商品域消费(F-PRO-002),本域为营销规则与配置的唯一归属。本域范围:F-MKT-001~012(2026-10 新增 F-MKT-010 套餐卡、F-MKT-011 会员等级与权益、F-MKT-012 积分体系;预留 013+);规则:R-MKT-01~13(交叉引用见 §4)。

### 1.2 域内角色与入口

- **管理员**:管理后台,覆盖 F-MKT-001~009——维护营销受众(客户分组)、配置价格策略(分组商品专属价)与营销活动(优惠券、满减/折扣、限时特价、会员折扣、桶水票票种、买赠/满赠、首单立减)。
- **消费者侧(用户/送水工端)**:不直接进入本域,消费营销计价结果——订单域 F-ORD-023 应用计价(确认订单/代客下单),商品域 F-PRO-002 展示熟客价/特价/新人价;优惠券与水票为用户主动参与的玩法(用户端领券/购票、确认订单勾选用券/核销水票),买赠/满赠、首单立减等订单级活动自动应用(确认订单展示赠品/优惠行)。

### 1.3 域级验收清单

- 营销受众可维护:分组增删改、客户分组设置与筛选生效;
- 价格策略生效:分组专属价配置后,订单计价自动应用(R-MKT-01),已生成订单成交价不受影响;
- 营销活动生效:满减/折扣、限时特价、会员折扣按 R-MKT-02 链路自动应用,优惠券可领可核销,叠加与封顶按 R-MKT-07 生效,已生成订单不受后续配置变更影响;
- 桶水票(电子票)闭环生效:电子票种可配置、用户可购票入票包、下单按「一票抵一桶」核销,核销/退回票夹/过期状态正确,**未核销且未过期的票可退**(2026-10 按行业惯例修订),被核销桶收款方式为「水票」并计入送水工日报(06-collection.md §R-COL-04);**票据全局唯一票号、核销留痕(票号 + 使用时间 + 关联订单)与防重复核销生效**(2026-08 已实现,2026-10 核验,R-MKT-08),核销点位支持送达侧扫码为目标增强;实体票(线下纸票)不在本域范围(见 F-MKT-007 业务规则扩充);
- 满赠/首单生效:买赠/满赠达标自动赠品并随单配送,首单用户自动享受立减/新人价,均不影响已生成订单;
- 套餐卡生效(2026-10 新增;储值部分 2026-10-09 决策不做,见 §1.1 合规决策):套餐卡可购/核销/退款,核销幂等(对齐 R-MKT-08);购买页明示有效期与退款规则;
- 会员等级生效(2026-10 新增):等级按累计消费自动升降,权益自动应用(会员折扣/免配送费等),不影响已生成订单;
- 积分生效(2026-10 新增):积分随订单完成获取、退款回退,可兑换与抵扣,超期提醒。

## 2. 域内业务规则

### 2.1 营销计价规则

**R-MKT-01 营销计价规则**: 订单成交价由营销价格策略解析,优先级:① 送水工代客下单手动填写的实收单价(若有)→ ② 下单用户所属客户分组的商品专属价(熟客价,若有)→ ③ 商品目录价;本规则为成交单价基线,优惠券/满减/折扣/限时特价/会员折扣/新人价等在 R-MKT-02 营销计价链路中扩展(限时特价插入为链路③,新人价插入为链路④,目录价顺延为⑤)
| 适用功能:F-MKT-001、F-MKT-002、F-ORD-023、F-ORD-001、F-ORD-012
| 校验与数值:手动实收价仅送水工代客下单可传且 >0、≤2 位小数;金额一律以分计算、服务端计算与校验(R-MON-01,见 01-overview.md §全局约束),前端不传价格
| 并发与边界:价格策略变更不影响已生成订单(成交价按下单时快照);用户自助下单忽略前端传入价格,防篡改;送水工改价须留痕(订单成交单价可查)
| 现状与目标:已实现(2026-08)——促销引擎按 R-MKT-02 链路统一解析(分组价→目录价),订单快照成交单价与来源;手动实收价①仍为开放项
| 缺口关联:G51~G53 已解决(2026-08,见 14-misc.md §细化缺口)

### 2.2 营销计价链路

**R-MKT-02 营销计价链路**: 订单成交价由「成交单价 × 数量」求小计后,再经订单层营销优惠逐级扣减(R-MKT-07)得出。成交单价解析优先级:① 送水工代客下单手动填写的实收单价(若有)→ ② 下单用户所属客户分组的商品专属价(熟客价,若有)→ ③ 限时特价活动价(若该商品处于特价活动期,R-MKT-05)→ ④ 新人专享价(若下单用户为首单新人且该商品配置新人价,R-MKT-10)→ ⑤ 商品目录价。
| 适用功能:F-MKT-001~009、F-ORD-023
| 校验与数值:金额一律以分计算、服务端计算与校验(R-MON-01),前端不传价格;每级优惠金额向下取整到分;优惠后应付金额 ≥ 0
| 并发与边界:活动配置变更不影响已生成订单(成交价按下单时快照);限时特价时间窗过期自动失效;优惠券核销幂等(并发防重复使用);桶水票核销先于现金计价——被水票覆盖的商品数量按单价 0 计入,不参与本链路单价解析(R-MKT-08);买赠/满赠赠品为附加 0 价行,不参与本链路单价解析(R-MKT-09)
| 现状与目标:已实现(2026-08)——促销引擎「单价解析 + 订单层优惠」两级计价(分组价→特价→新人价→目录价 单价链③④⑤,满减或首单立减→优惠券 叠加①③),水票核销先于现金计价,买赠/满赠赠品为附加 0 价行
| 缺口关联:G51~G56、G59、G60 已解决(2026-08);G57 会员折扣未解决(见 14-misc.md §细化缺口)

### 2.3 优惠券规则

**R-MKT-03 优惠券规则**: 优惠券为用户持有的抵扣凭证,确认订单时由用户主动勾选使用,一单一券。
| 适用功能:F-MKT-003
| 类型与形态:现金券(满 X 减 Y)、折扣券(满 X 打 N 折)、无门槛现金券;配置要素——面额/折扣率、门槛(按商品小计判定)、适用范围(全场/指定商品)、有效期(固定区间或领取后 N 天)、发放方式(自动领取/定向发放)、限领数
| 校验与数值:券面额 > 0、折扣券折扣率 0.01-9.99 折、门槛 ≥ 0;券金额以分计;优惠金额按 R-MKT-07 顺序应用
| 并发与边界:一单一券、不可叠加使用;订单取消/退款时未过期券退回(过期则作废);核销幂等
| 现状与目标:已实现(2026-08)——「建券 → 发放/领取 → 核销 → 退回/过期」闭环,引擎自动选最优券、用户可改选/取消
| 缺口关联:G54

### 2.4 满减/折扣规则

**R-MKT-04 满减/折扣规则**: 订单级自动营销活动,满足门槛即自动减免,无需领券。
| 适用功能:F-MKT-004
| 类型与形态:满减(满 X 减 Y)、满折(满 X 打 N 折),支持多档阶梯;适用范围(全场/指定商品/指定分组);时间窗(开始/结束)
| 校验与数值:档位金额递增且互斥;优惠金额以分向下取整;同一订单同时命中多个满减活动时取优惠最大者,不叠加
| 并发与边界:活动配置变更不影响已生成订单;到期自动失效
| 现状与目标:已实现(2026-08)——「配置 → 上架 → 自动减免」闭环,多档取最高、跨活动取最大不叠加
| 缺口关联:G55

### 2.5 限时特价规则

**R-MKT-05 限时特价规则**: 商品级限时活动价,处于活动期的商品按活动价参与单价解析(R-MKT-02③)。
| 适用功能:F-MKT-005
| 校验与数值:特价 0.01-99999 元、≤2 位小数;特价低于目录价(开放问题是否允许上浮);金额以分计
| 并发与边界:时间窗过期自动失效,回退分组价/目录价;已生成订单不受影响
| 现状与目标:已实现(2026-08)——特价活动配置(特价低于目录价、同商品时间窗重叠拦截、停用即时生效)+ 用户端特价展示(划线目录价);活动期自动按特价计价,到期自动失效
| 缺口关联:G56 已解决

### 2.6 会员折扣规则

**R-MKT-06 会员折扣规则**: 按客户分组/会员等级配置的订单级百分比折扣,自动应用,无需领券。
| 适用功能:F-MKT-006
| 校验与数值:折扣率 1%-99%(9 折 = 90%);**按未享受单价让利的商品小计**应用(已命中分组价/限时特价/新人价的商品不计入会员折扣基数);金额以分向下取整
| 并发与边界:**与单价让利按商品维度互斥(2026-10 明确叠加边界)**:同一商品已按分组价(R-MKT-01②)/限时特价(R-MKT-02③)/新人价(R-MKT-02④)计价的,该商品不再计入会员折扣基数;**未命中上述单价让利的商品仍正常享受会员折扣**;会员折扣与优惠券可叠加(R-MKT-07);配置变更不影响已生成订单
| 现状与目标:现状无会员等级/折扣概念;目标为「分组/等级 → 折扣率」配置 + 自动应用
| 缺口关联:G57

### 2.7 优惠叠加与封顶规则

**R-MKT-07 优惠叠加与封顶规则**: 订单层营销优惠按固定顺序逐级应用,优惠封顶不超应付。
| 适用功能:F-MKT-003~006、F-MKT-008~009、F-ORD-023
| 叠加顺序:① 满减/折扣(R-MKT-04)或首单立减(R-MKT-10,仅首单,与满减互斥取最大)→ ② 会员折扣(R-MKT-06,**仅按未命中单价让利的商品小计**应用,边界见 R-MKT-06)→ ③ 优惠券(R-MKT-03);各级优惠金额以分向下取整
| 封顶:总优惠不超过订单小计,优惠后应付 ≥ 0;券门槛按商品小计(未含优惠)判定
| 边界场景:代客下单手动实收价(①)场景默认禁用自动营销优惠(满减/会员折扣/首单立减),优惠券按需选择(开放问题);限时特价商品不参与满减/折扣(避免双重让利),会员折扣与优惠券可叠加;桶水票核销覆盖的商品数量按单价 0 计入,不参与任何现金优惠(R-MKT-08);买赠/满赠赠品按单价 0 计入,不参与现金优惠(R-MKT-09);部分退款按优惠比例分摊,整单退款退券(未过期可复用)
| 现状与目标:已实现(2026-08)——引擎按「满减 → 优惠券」顺序固定、逐级扣减、封顶不超应付;会员折扣②按同链路预留插槽
| 缺口关联:G54~G60

### 2.8 桶水票规则

**R-MKT-08 桶水票(电子票)规则**: 电子水票为线上预购的「桶数凭证」,用户购票入票包、下单时按「一票抵一桶」核销,被核销的商品数量按单价 0 计入应付,不参与现金计价;被核销桶的收款方式为「水票」,计入送水工日报水票数量栏(R-COL-04)。本规则仅覆盖电子票;实体票(线下纸票,送水工上门配送时收取)不适用本规则。
| 适用功能:F-MKT-007、F-ORD-023、F-COL-001/010(日报水票口径)
| 类型与形态:指定商品票(仅抵指定商品)、通兑票(抵限定规格/容量下的全场商品,跨规格不通用,防跨容量套利);配置要素——票种(类型/适用规格或商品)、套餐张数与购票价(元,以分计)、赠送张数(买 N 送 M)、有效期(固定区间或购票后 N 天)、限购
| 校验与数值:张数 > 0、购票价 0.01-99999 元、≤2 位小数;核销张数 ≤ 下单桶数 ∩ 可用张数;金额一律以分计算、服务端计算与校验(R-MON-01),前端不传价格
| 并发与边界:核销幂等(并发防重复使用);被核销桶按单价 0 计入,不参与满减/会员折扣/优惠券(R-MKT-07),券门槛按现金部分商品小计判定;**未核销且未过期的票支持按张退款**(2026-10 按行业惯例修订,原「一经购票不支持退款」作废),已核销/已过期张数不可退;订单取消/退款时已核销的未过期票**退回票夹**可复用,过期作废;票种/套餐配置变更不影响已购票
| 票据唯一性与防重复核销(2026-10 核验):**已实现**(2026-08)——每张电子票有**全局唯一票号**(`user_tickets.ticket_no`,格式 `SP + YYYYMM + 8 位序号`,唯一索引 `uk_user_tickets_ticket_no` + NOT NULL,`ticket_no_sequences` 按月原子取号,跨月重置、重启不丢);核销为**原子条件更新**(`redeemAtomically`:状态 ∈ {未核销,已退回} 且未过期时可核销,受影响行数 = 1 成功、= 0 即已被并发核销/过期),订单创建同事务核销、核销数不足整体回滚,**核销幂等**;核销落 `used_at`/`used_order_id`(带索引),可查询/导出留痕。**残余**:核销凭证为「票记录状态 + 使用时间/关联订单」而非独立扫码凭证;实体票(线下纸票)无系统核销记录

**需求描述**: 管理后台按客户分组配置商品专属价(熟客价),作为价格策略供订单计价自动应用(R-MKT-01)。现状:商品仅一个目录价,无分组价概念;目标形态:为分组设置商品专属单价,订单计价自动应用,价格单位元精确到分,保存转分。

**业务规则扩充**:
- **电子票与实体票区分**:本功能(含 R-MKT-08)仅覆盖**电子票**——线上购票、票张数字化持有于票包、下单电子核销,全流程可查可溯;**实体票**(线下纸质水票,送水工上门配送时收取)不在本功能范围。日报「水票数量」栏现状口径未区分电子/实体:电子票核销自动计入,实体票需送水工手动登记张数。
- 水票为预购桶数凭证,一票抵一桶,核销幂等(并发防重复使用,见 R-MKT-08)。
- 被核销桶按单价 0 计入应付,不参与满减/会员折扣/优惠券;券门槛按现金部分商品小计判定(R-MKT-08)。
- 核销口径与收款日报联动:被核销桶在完成配送时收款方式为「水票」,计入日报水票数量(06-collection.md §R-COL-04),与现金/扫码分栏口径一致。
- **通兑票规格限定**:通兑票按规格限定(如通兑 19L 桶),同一票通兑该规格下全场商品,不同容量桶不通用(跨容量非同一票),防止跨容量套利(决策)。
- **买 N 送 M**:支持赠送张数,赠送票与正常票同池,核销/过期口径一致(决策)。
- **每张票唯一递增票号(决策)**:购票支付入账时按张数逐张生成水票记录,每张带唯一票号 `SP + 入账年月(YYYYMM) + 8 位零填充序号`,按月重置递增(发票式编号,如 SP20260800000001);`(月份, 序号)` 组合全局唯一,落库唯一约束;历史数据按创建月份回填并接续。用户端票夹与后台用户详情展示票号,长按可复制,便于线下核验对账。
- **购票张数批量(决策)**:水票商城支持一次选择 1~10 张购买,按张数生成对应水票记录;单次购票张数上限 10(GraphQL/服务层双重约束),叠加票种限购校验。
- **订单页水票支付展示(决策)**:订单详情支付方式在核销水票时展示「微信支付 + 水票N张」,费用明细展示「水票抵扣(N桶)」行;被核销桶收款方式为「水票」口径不变(R-COL-04)。
- **后台票种销售/使用统计(决策)**:票种列表「详情」展示该票种销售(已支付购票单数/入账张数/销售金额)与使用(核销/退回/过期)按日图表与区间汇总,时间范围可切换;当前可用=未用+未过期退回。
- **未核销可退(2026-10 按行业惯例修订)**:购票款在**未核销且未过期**时支持按张退款(退未核销张数对应的购票款);已核销张数、已过期张数不可退;订单取消/退款时,已核销的未过期票**退回票夹**可复用,过期作废。原「预收不退/一经购买不支持退款」决策作废。
- 开放问题——日报是否分栏/加备注区分电子票与实体票;实体票是否纳入后续扩展(F-MKT-010+);指定商品票停售后已购票处理。
- **水票运营策略(2026-10-11 新增,G97,依调研报告 v2 B1/S4;2026-10 实现)**:票种级配置 引流票/复购激活/单次核销上限(R-MKT-08「运营策略」行),后台票种表单增「运营策略」组(引流票 Switch / 复购激活 Switch+需复购单数 / 单次核销上限,默认不启用),票种列表增策略标签。原开放问题裁决——**激活判定**:购票单落「购票时已完成订单数」基线,当前完成单数 − 基线 ≥ N 自动激活,未满足为「待激活」展示态(不入库)不可核销、置灰提示;**上限计法**:单笔订单 × 票种 ≤ N,计价入口按票种截断 + 超限拒绝;**引流票「拉新首购」判定**:仅无已完成订单的新用户可购(口径同 R-MKT-10 新用户);**运营策略效果区(拉新转化/激活率/上限触发次数)未实现**——拉新转化缺漏斗口径、上限触发缺事件埋点,记为未实现残留(见 spec/design/_spec/10-marketing.md 页面 11)。
**缺口关联**: G58(桶水票体系未实现)已解决(2026-08,F-MKT-007 已实现);核销点位增强见 14-misc.md §G91;运营策略已解决(2026-10,G97 已实现,见 14-misc.md §G97)。
